# 转场系统

## 0. 缺省：一个转场都没有

**镜与镜之间缺省是直接拼接（native 缺省档=逐镜全能参考·一镜一片），全片零转场镜；
只有显式开了章级衔接（`frame_chain: true`）的章才是首尾帧衔接。**
`shots[]` 里出现 `kind:transition`，几乎总是用户在 Studio 槽位点了「＋转场 → 插入转场」，
或跑了 `kinema transition add`（写入口 `studio.actions.transition_add` 与
`cli.cmd_transition`）。

**唯一的引擎自动插入是「孤岛接缝」**（见 §0.5）。守卫
`test_transitions.TestNoImplicitTransitions` 把构造点钉死在这三处，且对第三处再加一条：
它只准造带标记的 `seamless`。

弹层里某个类型被**预选中**（打开时高亮）只影响「你按下插入时插的是哪一型」，
不代表任何镜已经有转场——这两件事写文案时务必分清，混着说等于把「可插的类型」
讲成「已插的结果」（实测投诉过一次：槽位提示写「默认无缝转场」，被读成每镜都已加上）。

## 0.5 唯一的自动插入：孤岛接缝（只在衔接章）

判据与实现全在 `pipeline/framechain.py`（`island` / `sends` / `receives` /
`seam_plan` / `sync_seams`），调用点：`gen-video`（dry-run 与真发同跑）、
`sketch ref` 开关一动、以及手动的 `kinema transition sync`。

**只有章级 `frame_chain: true` 的章才有"缝"的概念**：缺省档（全能参考）里硬切就是
常态，为个别镜插软切只会造出「全片只有那一处有特效」的突兀——`sync_seams` 在
缺省章里只做减法（把历史遗留的自动软切撤干净），镜级结对衔接（`shots[].frame_chain`）
结不成对时也只如实报断因、不补缝。

**为什么必须自动**：一条首尾帧焊缝要两端都成立——上游真把末帧发到下游镜的分镜图上，
且下游真把那张图当第 0 帧硬锁。走**全能参考**（`sketch.reference`）或 **V2V**
（`previz_v2v`）的镜，在 seedance 请求体里根本没有 `first_frame`/`last_frame` 项
（分镜图降级成 `role=reference_image`，开头几帧由几张参考图调和而来）。所以它：

- 发不出末帧 → 它与下一镜之间那条缝断；
- 也接不住末帧 → 上一镜与它之间那条缝**也**断（这一端必须单独判——
  「切点仍近似连续」的说法是想当然）。

于是它在链上是一座**孤岛**：成片里必然是「衔接 → 硬切 → 这一镜 → 硬切 → 衔接」。
引擎在那两处各补一个 `seamless`（0.1s ≈3 帧柔切、`edge=0` 不动相邻镜、缺省静音），
把裸硬切磨成干净的切换——**不是"自动加转场"，是"焊不上的地方磨掉硬边"**。

四条边界（守卫 `test_review.TestIslandSeams`）：

| 边界 | 行为 |
|---|---|
| 身份标记 | `transition.auto = "island"`——同步器只认它，用户手写的转场一个字都不碰 |
| 幂等 | 在位且仍正确的**不重排镜号**（否则 `compose` 的 `shot_<id>_tr.mp4` 缓存每跑一次就换一次） |
| 不叠加 | 那一缝已有（手写的）转场 → 不再补软切 |
| 章首/章尾 | 不插——接缝按定义要有上下游两个正镜；xfade 族单侧邻居会退化成字卡，在这里就是黑闪一下 |

**`previz_last` 不在自动范围内**（`ISLAND_BREAKS` 只收孤岛那三项）：写了 `last_frame_ref`
的镜仍以自己的分镜图第 0 帧硬锁、上游照常焊得进来，断的只是出链那一侧；而 previz 通常
整段连着登记（实测一章 8 镜全带末帧），自动补等于给那一章塞 7 条软切、把既有形态大改样。
那一处照实报 `BREAK_ZH["previz_last"]`，要软化由用户自己插转场。

配置一撤（`sketch ref --state off` / 去掉 `previz_v2v`），下一次同步自己把软切撤走。
手动删掉某个 `auto` 软切只是暂时的：只要相邻镜还走参考模式，下次 `gen-video` 会补回来
（要永久换掉，在同一处手写一个自己的转场——手写的不会被顶掉）。

## 1. 转场即特殊镜

`shots[]` 里这样一条就是一个转场镜：

```json
{"kind":"transition","dur":1.6,"narration":"","transition":{"type":"fade_black","text":"一天后"}}
```

行为：

- 空旁白触发既有静音占位（时间轴 / 字幕 / BGM 自动对齐）；
- 生图 / 配音 / 图生视频**全跳过**——**零 API 成本**；
- 字卡由合成段本地渲染（字体走 `fonts.py` 风格库；纯汉字短文案自动疏排字距 ＋ 同色柔光晕，去生硬感）；
- 相邻镜自动加**边缘淡化**：淡出到字卡底色 → 字卡文字呼吸 → 从底色淡入。

## 2. 九种内置类型

### 2.1 字卡族（总时长 = 淡出 + 停顿 + 淡入）

| 类型 | 说明 |
|---|---|
| `fade` | 极简黑场呼吸。**无字缺省**，总 ~0.5s |
| `fade_black` | 渐黑字卡。**带字缺省**，总 ~1s |
| `fade_white` | 回忆闪回 |

### 2.2 冻结帧 xfade 族

取前镜尾帧 ＋ 后镜首帧做静帧过渡，像素与切点连续、`edge=0` 不动相邻镜。

**段长 ≤`SHORT_MAX_FRAMES`(8) 帧的走短过渡路径**：先 `frame_aligned` 吸附整帧，
再用均匀帧阶梯（duration=(帧数+1)/fps、offset=0、select 丢第 0 帧）——通用公式的
第 0 帧恒是前镜末帧复刻，十几帧的过渡里不可感，三帧长的柔切里就是切点多顿的那一下。
**这条线之上的既有八型一律走原来的通用公式、不吸附帧**，输出与 `seamless` 加入之前
逐字节一致：新增一个类型不该改动任何既有类型的成片。分界按帧数而非类型名——
缺陷源于段长不源于类型。

| 类型 | 说明 | 参数 |
|---|---|---|
| `seamless` | **无缝转场**——≈3 帧柔切，看上去就是直接切换；缺省静音（`sound: off`，音效仅用户显式选择时有）；柔度档 `_DURATIONS`：0.07 利落 / 0.1 标准 / 0.17 柔和（通用注册表，与方向/主色同构）。注册表第一行 ⇒ Studio 弹层打开时**预选中它**——预选只是弹层里高亮哪个芯片，**与「本章有没有转场」无关**（缺省一个都没有） | `--dur 0.07/0.1/0.17` |
| `wipe` | 对角翻页——新画面沿对角线掀入（单段直切无色卡，`--color` 对它无效） | `--direction tl/tr/bl/br` |
| `circle` | 圆形开合 | — |
| `slide` | 横向推移 | — |
| `blur` | 柔焦叠化 | — |
| `scan` | 轮廓扫描——霓虹亮条掠过，扫过处画面解析成发光轮廓线稿 | `--color green/blue` · `--direction up/down` |

`scan` 实现：edgedetect Canny ＋ 双层辉光 ＋ RGB 域 `lutrgb` 染霓虹色（再回 yuv420p 供 xfade），缺省配 riser 音效。**纯 ffmpeg 全图轮廓
而非 AI 人体分割**——人物因对比度天然成轮廓主角。

### 2.3 clip 素材转场

仅用户明确要求 AI 过场动画时才 Seedance 预生成，存 `assets/transitions/`。

## 3. 转场音效

### 3.1 三级声源解析

| 级 | 来源 | 顺序 |
|---|---|---|
| B | 外置音效库 `music/sfx/` ＋ `config/audio.yaml` 注册表 | 优先 |
| A | 缺文件时纯 ffmpeg 合成兜底（riser = whoosh 倒放 · boom = 54Hz） | 回落 |
| C | 用户点名 `sfx gen --kind 键 --yes` AI 生成落库 | 显式 |

起始素材：`python music/download.py` 一键拉 BGM ＋ 音效两套。

> **全库 CC0 / 公共领域·免署名可商用**：BGM 103 首（FreePD 存档 ＋ freesound）、音效 18 枚。
> **署名类 CC-BY 与付费源不进库、脚本里也不留下载逻辑**——引擎按情绪确定性选曲，混进一首就等于
> 哪一集随机背上署名义务。媒体不入 git。

音效走环境音混音通道，kenburns / dubbed 通吃。

### 3.2 音效键全表

| 组 | 键 |
|---|---|
| 基础三键 | `whoosh` 呼（缺省）｜`riser` 吸·上升蓄势（scan 缺省）｜`boom` 咚·低频落点 |
| 纯外置扩展 | `swish` 轻扫｜`deep` 重扫｜`glitch` 故障｜`shimmer` 微光（fade_white 缺省，缺文件回落 whoosh 合成） |
| 内容型打点十一键 | `pop` 啵·弹出（知识点/榜单条目登场）｜`ding` 叮·提示铃（揭晓·序号·结论）｜`page` 翻页（说书·拆书·绘本）｜`paper` 撕纸（剪纸拼贴换页）｜`impact` 砰·重击（战斗落点·标题砸入）｜`slash` 刃·挥砍（漫剧斩击）｜`heartbeat` 心跳（悬疑逼近）｜`wind` 风声（古风空场·时间流转）｜`magic` 术·魔法闪光（仙侠御剑·施法变身）｜`clock` 嗒·钟表滴答（榜单倒数·悬疑紧迫）｜`camera` 咔·相机快门（定格强调·回忆闪回） |
| 关闭 | `off` |

### 3.3 加音效键必须三处锁步

1. `config/audio.yaml` 的 sfx 段；
2. `audio_registry.EMBEDDED_AUDIO`；
3. `transitions._SOUND_LABELS`。

漏 label 则 Studio 选择器直接露英文键名——`test_transitions` 两条守卫钉死。

### 3.4 音效响度归一

`download.py` 侧音效统一**峰值归一到 -3 dBFS**。原始素材峰值横跨 16 dB，不归一就是「有的音效震耳
有的听不见」。

**归一必须量「过完整条滤镜链之后」的峰值**——单声道源经 `-ac 2` 上混会掉 3 dB，只量原文件时
翻页 / 撕纸这类单声道素材会整整轻 3 dB。

## 4. 类型缺省智能选

有素材 = `clip`；有字 = `fade_black`；无字 = `fade`。

### 4.1 单侧邻居（章首/章尾插转场）

xfade 族要求**前后都有普通镜**（要拿前镜尾帧与后镜首帧）。插在章首/章尾时退化为
字卡并告警——全体 xfade 型同一条规则，`seamless` 不搞特例。

## 5. 插拔入口

**CLI**：`transition add` / `rm` / `list`。

**Studio**：分镜列「＋转场」→ 类型选择弹层。数据驱动自 `transitions.catalog()` / `sound_catalog()`，
overview 下发 `transitions_catalog` / `transition_sounds`。弹层内容：9 型网格 ＋ 选中即显该型专属
方向/主色 chip（wipe 四角｜slide 四向｜scan 上下扫 + 霓虹绿蓝｜字卡型底/字成对档黑白）＋ 文案可填可不填 ＋ 音效
缺省随型。clip 需素材，不入选择器。

淡化参数（秒数两位小数 + 底色）进片段文件名 = 缓存键——改转场底色或微调 `--edge` 都必须换键重渲。

## 6. 删除纪律

**转场镜只能用 `transition rm` 删；普通镜仍绝不删除。**
