# 3D 导演控制台与 previz

**入口** `#/stage/<pid>/<cid>` ｜ **实现真源** `pipeline/camera.py` + `kinema/previz.py`

## 1. 做什么

在烧 Seedance 之前，先在浏览器里把戏排出来——摆灰模角色、指派动作、画走位路线、设多机位、选
36 个大师运镜之一，渲出一段**确定性 previz 参考片**，产物落回 `shots[]`。

## 2. 四条产出各锁一样东西

| 产出 | 落点 | 锁住什么 |
|---|---|---|
| 首帧 | 走 supply 轨进 `shots[].image` | 构图 / 走位 |
| 末帧 | `last_frame_ref` | 终态位姿；发 Seedance 末帧时**优先于衔接链的下一镜图** |
| 运镜措辞 | `camera` = preset.phrase | 引擎前置到创作正文首位 |
| 参考视频 | `previz` | opt-in 的 V2V 迁移运动 |

## 3. 确定性是它的立身之本

| 层 | 手段 |
|---|---|
| 前端 | 逐帧步进：`action.time=` 绝对定位 ＋ 确定性正弦代替随机浮动 ＋ 同步 for 循环 |
| 后端 | `-framerate F -frames:v N` 锁 CFR |

同一场景在任何机器上渲出的帧一致，previz 与最终片长 1:1——才谈得上「成片跟随预演」。

## 4. 运镜库是一份数据两个面

同一行 preset 既是 Three.js 相机装备（关键帧 / 缓动 / 跟随模式 / fov 曲线），又是发给 Seedance 的
那句措辞。3D 里飞的和文案里写的天生一致。

## 5. previz 绝不写进 `clip`

compose 视 `clip` 为最终成片。

## 6. 渲染是选镜批量的

工具条「⏺ 渲染 previz」点开选镜弹层：

- 可单镜 / 多镜 / 全选 ＋ 快捷「只选未渲」，缺省只勾未渲的镜；
- 逐镜串行渲染并登记，忙态显示「镜N i/n · 42%」；
- Esc 停在镜与镜之间，且已完成的镜保留不撤；
- 弹层底部「完成后合成全片预演」缺省勾选。

## 7. `previz reel` 全片预演

逐镜渲完得到全片预演——工具条「▤ 全片预演」一个按钮 ＋ 悬停下拉（播放 / 下载 / 重新合成）。

排戏真正要审的是**整场戏连起来的节奏**（上一镜的收势接不接得住下一镜的起势），逐镜点开看不出来。

它同样是**观看物而非成片**，边界见 `previz-v2v.md` ⑦。
