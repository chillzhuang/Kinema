# Studio 三层与前端模块架构

**启动** `python3 -m kinema studio`

## 1. 三层（全 stdlib）

| 层 | 职责 |
|---|---|
| `scanner` | 只读扫描 |
| `server` | HTTP |
| `studio_app` | 原生 JS SPA，**无构建步骤** |

## 2. 前端模块架构（原生 ESM · 免构建，与 `director/` 同范式）

### 2.1 模块清单

`studio_app/app/` 模块清单（增删模块以 DEVELOP.md §四为准——那份受 `test_delivery`
三重对拍守卫钉住，本表只是职责注解、自身无守卫；数量不手抄——手抄的数字会随
模块增删静默失真）：

| 模块 | 职责 |
|---|---|
| `core` | 基座 |
| `components` | **站内 UI 组件单一落位** |
| `widgets` | 通用件 |
| `shell` | 侧栏 |
| `brands` | 服务商品牌标 |
| `overview` / `project-new` / `project` / `chapter` | 视图 |
| `shot-tools` | 分镜弹层 |
| `panels` / `ledger` / `playbook` | 其余面板 |
| `config` | 模型配置中心 |
| `skill` | SKILL 指挥层只读大屏 |

外加 `app/state.js`（跨模块共享可变状态）与 `app.js` **唯一入口**（`<script type=module>`，路由与
启动；顶层按原段序锚定 side-effect import 以保求值顺序）。

**语义命名无序号前缀**，求值顺序由 import 图决定。分层纪律：core → components → 视图。

### 2.2 components 里有什么

`uiSelect` / `uiSegment` / `uiCheck` / `listSearch` / `chip` / `uiDialog` / `uiConfirm` / `uiPrompt`，以及
**弹层骨架工厂 `openShell`**。

`openShell` 是 `.dlg` 家族唯一开启入口，backdrop / Escape / 退场动画三件套只此一份——它是
`director-stage-ui.md` ①「只用站内组件」纪律的锚点。**新弹层一律 `openShell`，绝不手搓骨架。**

### 2.3 `runBusy` 按钮忙态也在 components

行为：点下去转圈 ＋ 禁同组按钮 ＋ 失败还原**点击前那句文案**。

各处手搓 `btn.disabled=true; btn.textContent=…` 有两个通常的疏漏：

1. 还原文案写死——「↻ 重新试音」失败后变成「♪ 生成 5 个试音」；
2. 只禁自己——等待期间还能点同卡另一个「选定」，连发两次请求。

转圈走 `.is-busy::before` 伪元素而非插子节点，因为半数忙态是 `textContent=` 写的，插进去会被冲掉。

## 3. 前端纪律

### 3.1 依赖必须显式 import/export

`director/*.js` 对宿主工具（`api`/`post`/`toast`/`h`/`uiSelect`…）的引用全部显式 import，
不依赖经典 script 加载下的全局泄漏。新代码想用宿主符号，先 import。

### 3.2 core 是基座层，零静态依赖

core 要回调视图（`softRefresh` 系）一律**动态 import 晚绑定**。

静态引视图会构成环 → 视图模块先于 core 求值 → 其顶层 `$()` 撞 TDZ → 直接白屏（实测根因）。

### 3.3 跨模块**重赋值**的状态只进 `state.js`

经属性读写。ESM import 绑定只读，导出裸 `let` 供人赋值 = 语法错误。当前仅 `STATE.chapSig`。

### 3.4 源级守卫一律读全模块拼接文本

tests 的 `_frontend_src()` 范式——断言不关心代码落在哪个模块。

### 3.5 图标一律单色

一个字符是不是彩色 emoji，**不由字符本身决定，由字体栈里有没有它决定**：栈里有就是
单色字形，没有就往下掉，掉到最后是 Apple Color Emoji / Segoe UI Emoji。反例形态：
按钮文案用「✍ 自创正文」——`--font-ui` 的四款字体**都没有 U+270D**，按钮上就会
长出一只黄手；🗑（U+1F5D1）同型。**按 Unicode 的
`Emoji_Presentation` 属性判会恰好漏掉 ✍**（它是 `No`，变彩色纯粹因为苹果文本字体
不收它）——属性表回答不了「这台机器怎么渲染」。

要新图标先复用站内已有的同义字形（写/起草=`✎`、关闭/删除=`✕`、警告=`⚠`、重来=`↻`）；
新字形上屏前在 macOS 与 Windows 各看一眼是不是单色。服务端 `studio/*.py` 的报错文案
会变成网页 toast，同样适用。本条是**书面纪律，不设守卫**——图标的进退不值得连带改测试。

### 3.5b 「下一步」提示写给谁，决定它写不写命令

Studio 的操作面是**跟 AI 说话**，网页只负责看和点。三类文案的口径因此不同，写新区块前
先认清自己在写哪一类：

| 面向 | 落点 | 写什么 |
|---|---|---|
| **用户** | `emptyBlock` 第三参、占位/角标的 `dataset.tip` | **`对 AI 说：…`**，不写 CLI 命令 |
| **AI** | `openDirectiveDialog` 的 `directive` 正文 | **写命令**——那是让 AI 去执行的落地口径 |
| **参考** | `playbook.js` 的 CLI 速查与实战步、`skill.js` 的落地命令面板 | **命令原样**，与 `say()` 双轨并列 |

判据是「这行字读完，人下一步该做什么」：要人去开终端敲，就错了——那正是 AI 该替他做的事。
`playbook.js` 的实战步不适用本条：步骤自带 `who` 标记（`you`/`cl`/`st`），`cl` 步下面的命令
说明的是**AI 会跑什么**，不是叫用户跑。

反例形态：场景俯视区空态贴 `python3 -m kinema project refs abyss` 这样的命令，而同一个
文件里的 `emptyBlock`（章节区、角色区）全是 `对 AI 说：…`——同页两套口径。
本条是**书面纪律，不设守卫**——文案的进退不值得连带改测试（同 3.5）。

### 3.6 筛选工具条两条

跨视图筛选（待审队列 / 看板 / 成本 / 片库）共用一套写法：

1. **项目维度一律 `uiSelect`**，四处同一个选择器——一项目一枚 chip 在项目多起来后会铺满
   两行，且四个页面各长一个样；
2. **控件初值回填持久化 filter**（片库的 `galFilter` 跨视图存活）——只画控件不回填，从别的页
   回来就是「筛选生效着、控件显示全量」。

检索框长度是**跨页同一条 CSS 规则**（`.lib-bar .fsearch, .kb-toolbar .fsearch`）：三处搜的
东西同量级，分两条写就必然只改一处，同一个框在三个页面长短不一。

### 3.7 区块头「更多」与首页截断口径

`secHeader(no, zh, en, count, action)` 的第五参是右端动作位，唯一在用的动作是
`secMore(href)`（widgets 导出，全站共用一个件）。两条口径：

1. **计数恒报全量**，与实际渲染条数无关——区块头显示的是库里有多少，不是这屏画了几张
   （报载荷长度则两头不沾：既不是显示数也不是总数）；
2. **首页截断写成具名常量**（`overview.js` 的 `HOME_RECENT` / `HOME_PROJECTS`，两个数
   各自定：卡宽不同、一行排几张不同），余量由「更多」领去 `#/library` / `#/projects`。
   空列表不挂「更多」——空态卡自己带引导。

「最近成片」不做横向滚动（`.recent-grid` 自适应列数、窄屏折行）：一行看不完的部分去片库，
不在首页横着拖。

总览「风格档」墙不展示 `/kinema`（`HOME_HIDDEN_SKILL`）——它是通用兜底工作流、旗下只有
「口播」一档，摆在画风墙尾会被读成「另一种画风」。两处配套：隐藏组的画风仍要记进
`used`（否则原样落进「独立画风」兜底组＝换个位置继续显示）；区块头计数走 `homeProfiles()`
而不是 `ov.profiles` 全量——这一处是永久隐藏、没有「更多」可去，报全量就与眼前数得出来的
卡片对不上。`#/skill` 大屏是集群目录，恒全量，不适用本条。

### 3.8 只用真定义过的设计 token

`var(--x)` 没有兜底值、`--x` 又没人定义时，**整条声明作废**：不报错、不回退到上一条
规则，什么都不发生。CSS 读起来完全正常，浏览器里那条样式根本不存在——这类漏子只会
被用户当成「没做」报回来（`.cvc-row:hover { background: var(--panel-2) }` 就是一列
分镜行整段时间没有悬停反馈；同一个假 token 还能扩散，`--dim` 一度铺在两张卡的十三处
文字色上）。

**新写样式先在 `:root` 找现成 token**：文字三档 `--text` / `--text-2` / `--text-3`、
悬停底 `--bg-hover`、软填底 `--fill-soft`、面层 `--bg-card` / `--bg-card-2`。同一个
角色不许另铸一个别名——`--dim` 与 `--text-2` 并存就是两个真源。运行时才写上去的
（`--brand` / `--sheet-ar` / `--nc`）不在此列，它们由 JS 设。

守卫在 `test_frontend_integrity.TestNoPhantomCssVariables`：无兜底的 `var()` 逐个对
定义表，JS 里 `setProperty` 与 `--x:` 写过的算已定义。

**模态遮罩只有一档**（`--scrim` / `--scrim-blur`），弹层、图片灯箱、放映厅、命令面板、
垫图参考共用。`backdrop-filter` 与不透明度是一件事的两半：底色一过 .8，糊出来的毛玻璃
完全看不出来，模态浮在自己的场景之上这件事也随之消失——读起来就是一块纯黑板，而 CSS
里明明写着 blur。遮罩糊得看不清时，改的是这一档，不是给自己那一处单写一条更轻的覆盖
（那样症状按住了、其余几处照旧）。守卫在 `TestModalScrimStaysFrosted`。

## 4. 写路径：与 CLI 同一条

**所有写操作与 CLI 走同一条路径**：`Project.load` → 领域模块 → `Project.save`。写入口分两档：表态走 `_mutate`（锁内以磁盘现状为基线），其余一切写入（移动画布产物、作者字段、`shots[]` 结构、合成期参数）走 `_exclusive`（章节操作锁内装载，被生成/合成任务独占时拒绝；派子进程的动作在锁外派）——两档之外不许再有 `_load → save` 的写端点。

## 5. 网页新建项目

入口：`/projects` 工具栏左侧「＋ 新建项目」（检索/筛选靠右），或空态弹层。

只建**确定性空壳**：标题 / 选填项目编号 / 画风 / 比例 / 字幕语言 / 选填卖点 + 主角。

画风按 skill 分组选（组头显 `/kn-xxx` cmd），选中即实时显**绑定 Skill** 并落 `project.skill`。
深度设定（世界观 / 角色 / 分镜）留给 AI。

`actions.create_project` 与 CLI `project new` 同一条 `Workspace.create_project` 写路径
（`/api/project/create`，`skill` 由画风派生、可显式覆盖）。

## 6. 删除项目

入口在**项目详情页最底部「危险区」模块**，不在头部右上角——防误触。`.danger-zone` ＋ 二次确认 →
软删入回收站。

## 7. 长任务与忙态

长任务走 `studio/jobs.py` 异步任务器。任务带 meta 定位名片：project / chapter / shot / kind。
`/api/job` 轮询单任务，`/api/jobs` 对账进行中任务。

### 7.1 分镜卡忙态数据驱动

「生成中」遮罩与「图·生成中」徽章按 GENJOBS 渲染，3s 轮询重绘 / 刷新页面都不丢，完成软刷新换图 ＋
缓存击穿。

**忙态是渲染的一部分，故「登记忙态」与「立刻重绘」必须绑成一件事、收在跟踪函数内部。** 分散到各
调用方就会出现「这条路记得写 `softRefresh`、那条忘了写」——实测：简笔板灯箱「↻ 重新生成」关掉弹层后
毫无动静，而选镜弹层那条正常。

### 7.2 忙态账本按 job 分组，而非按章节去重

`SKGEN: 章节 → (job → 镜号集)`。

否则批量还没跑完时再从灯箱重生一镜，第二个任务会被整个吞掉。

## 8. 分镜卡的两个改稿通道

### 8.1 「↻ 重新生成」

= retake ＋ 后台 `gen-image --only`。

**镜上锚定意见自动带九宫格方位词编译进重生 note**（`actions._regen_note`），走驳回闭环，审核通过
即整体消费删除。

### 8.2 点击画面打开检查器

点击分镜画面打开检查器灯箱，画布为**双模式分段选择器**：

| 模式 | 交互 | 时机 |
|---|---|---|
| ◉ 标注意见 | 点击打点 / 划线圈范围，笔迹 path 随意见入库 | 仅重新生成时进料 |
| ✂ 局部改造 | 框选 ＋ 指令 | 立即手术 |

两通道显式互斥，零歧义。

### 8.3 提示词不在网页改

分镜卡「⧉ 改镜指令」打开指令台，合并需求后复制带定位坐标的标准指令，交 AI。

### 8.4 实发稿里的引用记号可点看

提示词面板展示的是 `video_prompt_preview` 编译出的实发稿，稿里的寻址记号由 `pvRich`
按 `PV_REF_RE` 切出并渲成可点的引用，编号与实体都由同一份预览行下发（`refs` / `videos` /
`anchors` / `dub`），前端不自己数编号：

- `@图片N`：悬停出缩略图，点开大图，归属签（本镜画面 / 设定图 / 场景基准图 / 简笔板）取 `refs[].kind`；
- `@视频N`：点开放映窗播盘上那份控制段或 3D 预演片——控制段带源片同区间的音轨，模型收到的是
  无声副本（`control.send_path`），信息栏写明这一点；
- `@配音N` / `@音频N`：dubbed 试听整镜配音，native 试听说话人的音色锚定，未预热的锚定音可当场合成。

记号不许在行尾折断（`.pv-ref` 是 `white-space: nowrap`）：折成两行的行内元素外接矩形横跨整行，
悬浮提示按矩形居中就落到面板正中而不是记号旁。

## 9. 章节页区块顺序 ＝ 制作阶段顺序

```
TL 时间线
AL 资产视图
SL 分镜脚本
3D 导演台 → DV 深度捕捉 → SK 简笔分镜（各占一整行；kenburns 下合并成 PV 运动预演折叠条）
AU 音频剧本                    （恒展开，与 motion 正交）
控制台双栏
  ├─ 侧栏：FC 放映 → FX 后期［特效 / 水印 / 构建 / 自审］
  └─ 主列：SB 分镜卡 → SV 剧本与声音 → AS 章节资产 → QC 成本与一致性 → DL 交付
```

### 9.0 四个工作台按各自的判据决定在不在场

`previzDesks` 是运动预演三台的门，判据**恒是服务端下发的 `uses_video`**
（= `Project.uses_seedance`，与逐镜生视频入口同一条）：

- 3D 导演台、深度捕捉与简笔分镜的产物只有一个去处——gen-video 请求。kenburns 不发，
  三台配置了也不进成片，而「▦ 生成简笔板」还按 image provider 计费、深度处理还烧
  本机 CPU；
- 故这一档下收成一条 `.pvz-fold` 折叠条（读数 + 展开），**不是不渲染**：盘上真有
  排完 previz 又改回 kenburns 的章节，硬藏会让已有产物在网页上彻底不可达；
- 分镜卡的 ◈ 预演 / ◆ 深度 / ▦ 简笔角标照旧在（产物入口），只有「哪一路胜出」的仲裁
  徽章跟着门一起收——不发请求就无所谓谁胜出；
- **不许按 skill / 画风推**：motion 是章节级字段（同项目 ch01 native、ch02 kenburns
  是常态），且 kn-anime 的 2D 档与 kn-game 的过审档本来就推荐 kenburns。在前端另建
  一张「哪些类型要视频」的表就是第二真源，每加一个 skill 都得回来改。

AU 音频剧本台**与 motion 正交，恒展开**：scored 在 kenburns 与 native 下都成立
（纯 ffmpeg 合成的章节恰恰是整轨买断最典型的搭配），真正与它互斥的只有 dubbed
——那一档由 `dubLock` 在表态处拦住并给出两条出路，判据与引擎硬闸同源。

### 9.1 导演台为什么单独成行

**先把戏排好（走位 / 动作 / 机位 / 运镜），再逐镜细看与看成片。** 塞进任一栏都会被读成那一栏的
附属功能，而它是一整个工作台。

入口卡内容：预演进度 / 运镜数 / V2V 态三格统计 ＋ 已排镜快捷预览 ＋「进入导演台」。

该按钮用**描边 + 软填**而非实心块——全站只有琥珀 `.btn-primary` 一个实心强调体系，再来一块实心青色
会跟它抢主次。

**头部不重复放入口按钮**——区块卡已足够显眼。

## 10. SKILL 指挥层大屏（`#/skill`）

只读档案页，数据是 `/api/overview` 的 `skill_board`（`skills.py` 投影编译 catalog，全部七类 kind 一条不落，
含 route/workflow 之外全部 kind）。前端零硬编码条目：kind 门牌表只管中文名与语序，
未登记的新 kind 落「其他」兜底组，绝不丢条目。

卡片整体**不可点**（与风格档卡不同）——点击语义只落在画风档 code 上，复用总览的
画风详情弹窗看提示词 DNA。编辑不在网页：页尾「自定义与增强」指路 `agent/` 源码
与 `agent_assets.py compile/check`，口径与 DEVELOP.md 二开配方对齐。

页尾那一段与 01 区**同构**：两块内容各自装进 `.sp-group` 门牌面板（增强路径 / 落地命令），
组间距由 `.sp-groups` 统一给。若让 `.gd-loops` 网格直接跟一张 `.gd-card` 平铺，
两个兄弟块之间零间距，且与上半页的面板式分组不是一套观感。命令行体复用
`.gd-cmd`/`.gd-say`，竖排间距走面板内的 `.sk-cmds`（`.gd-card` 自带内边距，
套进面板会叠两层）。
