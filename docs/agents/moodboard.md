# 参考库 / 风格垫图

## 1. 默认全局套用

项目一旦有垫图（`project moodboard <id> --add 图`，或网页项目页「参考库」上传），**后续一切生成默认
自动把默认启用（`on=True`）的垫图转 base64 喂 API**，整体锁死模块风格。

覆盖范围：设定图 `project refs`、分镜图 `gen-image`、局部改造 `refine`、封面 `cover`——CLI 与 Skill
与网页同。

## 2. 关闭只有三条路

| # | 路径 | 操作 | 作用域 |
|---|---|---|---|
| 1 | 命令行 | 对 Claude 说「不要垫图」→ 命令加 `--no-moodboard` | 一次性 |
| 2 | 项目级 | 网页项目页点某图 ✓/○ 切换「默认启用」，等价 `project moodboard --off 图` | 留库不删 |
| 3 | 镜级 | 网页分镜卡「⛭ 垫图」勾选/取消，或手写 `shots[].refs`（`[]` = 本镜只靠提示词） | 单镜 |

**别手写整条 moodboard 数组**——用 `project moodboard` 子命令或网页。

## 3. 角色设定图现行版式：三区两视

三区两视：左 40% 锁骨以上正面肖像特写｜中 30% 正面全身｜右 30% 背面全身，同地平线等高等比。
不设侧视、细节格与色板；武器不上角色表（归独立武器设定图），全身像无条件空手。

另注：写实档（`image.identity_sheet`）的角色身份图走纯文生图，**不垫 moodboard 也不垫蓝图**
（合规要求，见 `photoreal-face.md`）。

## 4. 设定图逐张独立垫图

设定图（角色/场景/道具）也支持逐张独立垫图，与逐镜同范式。

**网页路径**：设定图灯箱「⛭ 垫图参考」勾选 →「保存并重新生成」→ 落
`characters[].refs`/`props[].refs`/`scene_refs` → 走 `project refs --only kind:名 --force` 单张重生。

**三态语义**（同 `shots[].refs`）：

| 值 | 含义 |
|---|---|
| `None` | 跟随默认 |
| `[]` | 不用垫图 |
| `[路径…]` | 精确指定 |

各设定图互不影响——给林深单独喂张脸参考不污染魔王。CLI 侧手动等价：
`project refs <id> --only character:名`。
