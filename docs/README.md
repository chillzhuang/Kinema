# Kinema Documentation

[English](README.md) · [简体中文](README.zh-CN.md)

This directory holds the repository's **reference documentation**: Markdown and
specification text only. Media (images, video, fonts) always lives in `assets/` —
a test guard enforces the split.

## Layout

| Path | Contents |
|---|---|
| [`agents/`](agents/) | **Detail layer of the engineering guide** — one doc per module. Indexed by the root [`AGENTS.md`](../AGENTS.md) §7 reading map; coding agents open a file here on demand, right before touching the corresponding module — never as default context. Full map below |
| [`kinema/`](kinema/) | **Architecture & data contracts** — see the file map below |
| [`skills/`](skills/) | **Tool-neutral skill index** `INDEX.md` for agents that don't adopt the skills standard (Windsurf / Aider / Zed) and for browsing on GitHub. Generated by `tools/agent_assets.py`; do not hand-edit |
| [`sql/`](sql/) | **MySQL schema script** `kinema.sql`, generated by `python3 -m kinema db schema` from `engine/kinema/storage/mysql.py::_SCHEMA`. Do not hand-edit; regenerate |

## Conventions for `agents/` docs

Adding or editing a file under `agents/` follows three rules:

1. **Each doc opens by naming its truth source.** A title, then a bold line giving
   the implementation truth source, guard tests or scope — whichever apply. Body
   text is the full rule; `AGENTS.md` §7 only links here and never restates it.
2. **Never renumber circled section headings.** `previz-v2v.md` and
   `director-stage-ui.md` are cited from code and tests in the form
   `previz-v2v ⑦` / `director-stage-ui ⑩`. Renumbering silently breaks those
   references.
3. **Docs must not outrank code.** When a doc and the implementation disagree, fix
   the single truth source and add a behavioural guard — do not paper over it here.

Each topic has exactly one home; nothing here duplicates another document:

- Engineering discipline & stable conclusions → root [`AGENTS.md`](../AGENTS.md) (the Agent Kernel)
