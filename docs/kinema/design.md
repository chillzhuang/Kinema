> **本文是当前架构的一页式地图**——看完这一份，就知道整个系统怎么长的、数据怎么流的、

## 1. 一句话与设计铁律

**给一个主题，出一条成片。** 指挥层（编码 agent）负责一切需要判断的环节，本地引擎负责一切
确定性的环节，云 API 是可插拔的能力层。

三条铁律贯穿整个设计：

1. **引擎里没有 LLM。** 检索、写作、分镜设计、提示词全归指挥层；引擎只做生成、合成、重试、
   记账。两层之间靠一份 `project.json` 契约对话。
2. **主链是确定性 DAG + 人工关口，不上多 Agent。** token 该花在写好一句分镜上，
   不是花在让五个 agent 互相讨论。
3. **成本是一等公民。** 逐镜报价在前、预算闸在发送前、幂等在失败后——账单为零而不是烧了一半。

## 2. 三层架构

```
① 指挥层 · 编码 agent（Claude Code / Codex / Cursor / Copilot …）
│  18 份能力包（.claude/skills/）：kinema 流程真源 · 11 个画风入口 · 项目化/小说/分镜板/音频/素材复用/环境向导
│  联网检索 → 文案 → 拆分镜 → 双语提示词 → project.json → 调度引擎 → 人工关口
│
│        project.json 数据契约 ＋ kinema CLI（53 子命令）
▼
② 执行引擎 · engine/kinema（本地 Python · 内核零依赖 · 唯一硬依赖 FFmpeg）
│  ModelRouter（能力 × 画风）        pipeline/（提示词装配 · 生图 · 配音 · 字幕 · 运镜 · 转场 · 混音 · 合成）
│  lint 40 维静态体检               review 五态审阅状态机 × versions 版本栈 × 血缘 lineage
│  framechain 衔接仲裁              sketchboard 简笔分镜板 · previz 3D 导演台预演
│  voicebank 音色档案库             budget 事前闸 ＋ 预估/实际双轨台账
│  Studio 制作台（scanner 只读 / server HTTP / jobs 异步 / 原生 ESM 前端免构建）
│  storage/（本地 JSON ⇄ MySQL ⇄ 对象存储）
│
│        REST / SDK · 密钥 env ＞ secrets.local.json ＞ secrets.yaml · 本机覆盖层 models.local.json
▼
③ 能力层 · 云 API（config/models.yaml 唯一真源 · 18 个 provider 别名 · 一文件一适配器）
   图像 Seedream（备选 Nano Banana · 通义万相 · MiniMax）      视频 Seedance 2.0 mini / 2.5（备选 Veo · MiniMax-H3）
   语音 seed-audio-1.0 定制音色（缺省）＋ seed-tts-2.0 模版音色    音乐 ElevenLabs（缺 key 自动降级本地 CC0 曲库）
   口型 火山视频改口型（dubbed 对白镜可选增强步）
```

换厂商是一行改动：代码只绑定能力（图像/视频/语音/音乐），从不绑定厂商；同厂新模型＝加一个
别名，换默认厂商＝改 `defaults.providers` 一行，44 个画风档全部跟随。

## 3. 数据契约 project.json

- 指挥层填 `script / style / shots`，引擎回填 `image / audio / output / cost`——字段级契约
  钉在 `project.schema.json`，守卫防「代码写了字段、契约没同步」。
- `shots[].status` 让每次运行可断点续跑：失败只重渲那一镜；锁定由 `review.<stage>=done`
  表达，`--force` 也不覆盖。
- 组织三层：**工作区 → 项目 → 章节**。小说改编遵循**一章一集**：episodes 与原著章节
  一一对应，绝不合并（合并会丢情节与设定）。

## 4. 制作管线（从主题到成片）

```
小说/主题
 └ 原创正文（kinema-novel：十章一批 · 七门复核 · 伏笔账本回写）
    └ 剧本改编（一章=一集）→ 分镜脚本 shots[]（景别/运镜/台词/情绪/双语提示词）
       └ lint 40 维零成本体检（运镜雷同 · 景别单调 · 场景连续性 · AI 腔 · 提示词过薄 · 制式错配…）
          └ 设定集：角色三区两视 · 道具结构三视 · 场景主视觉＋俯视布局图（恒配对） ＋ moodboard 垫图 · 色板/seed 快照
             └ 分镜图（style_prefix 画风前缀 ＋ 单帧契约 ＋ 设定图绑定 ＋ 防字地板）
                └ 运动预演（可选）：3D 导演台灰模排戏出 previz ／ 简笔分镜板 beats 拆拍
                   └ 配音（定制音色双锚 ／ 模版音色直出 ／ 音频剧本整轨）
                      └ 视频化（三种渲染模式，章级单入口）
                         └ 合成：镜间直拼零特效（转场显式 opt-in）＋ 字幕烧录 ＋ 混音归一
                            └ verify 本地自审（黑屏/哑音/削波/响度/时长漂移/字幕条数）
                               └ 交付包 zip ＋ 提案书 ＋ 免登录审阅页 ＋ 水印
```

每一道产物落盘、停下等确认，只有显式 `run` 才一口气跑完。这条链刻意**先便宜后贵**：
在零成本的静图版上定节奏与构图，再花钱动态化，且只动态化签过字的镜。

## 5. 一致性体系（为什么脸能稳住）

范式：**身份创建与运动创建解耦**——身份只生成一次，之后作为输入复用，不靠文字反复重新描述。

六重锚：① 设定图随请求附发（图锁脸）＋ 文字锚只留名字绝不复述外貌（复述即漂移）；
② moodboard 全局垫图；③ style_prefix / seed / 色板建章快照；④ `scene_continuity` lint
拦相邻镜取景地跳变；⑤ consistency scan 三段协议（引擎产料 → 指挥层多模态判定 → 回填打回）；
⑥ 血缘 lineage——设定图一改，下游分镜当场标为过期。

## 6. 视频化（三种渲染模式 · 全能参考缺省）

| 模式 | 画面 | 视频成本 |
|---|---|---|
| **kenburns**（须显式） | 静图八种缓动运镜 | 零 |
| **dubbed** | Seedance 图生视频，闭唇出片、配音上主轨——全旁白解说章的制式 | 按秒计费 |
| **native** | Seedance 原生音画，模型自声 ＋ 音色锚定——对白上镜章的制式 | 按秒计费 |

- **渲染档章级单入口**：未表态按内容定档（有对白 → native，全旁白/无词 → dubbed，
  scored → native），kenburns 须显式写。native 混烧（`native_voiceover`）按镜分治：旁白镜
  闭声出演、TTS 上主轨，对白镜仍由模型发声。

- **全能参考是缺省档，一镜一片**：@图片1 为该镜分镜图，其后简笔板（在盘即附）与
  角色→场景→道具设定图按序附发（设定图配额 ≤7，板与尾帧各占一席），引擎逐张生成
  @图片N 职责绑定句。写实档（`image.identity_sheet`）被人脸审核拒绝时自动降级：
  @图片1 换成场景基准图、分镜图不进请求，构图由简笔板承载、身份由受信身份图承载
  （判据与阶梯见 `docs/agents/photoreal-face.md`）。
- **首尾帧衔接是显式 opt-in**（章级 `frame_chain` / 镜级结对），不是默认行为；
  合成时镜间直拼零特效，要转场用户自己点名。
- **提示词按增量编译**：引擎自动前置契约句（按任务类型六分措辞）、结构锁、运镜首位、
  动力学地板（重量/惯性/衣发跟随）与防字负面串；`video_prompt` 只写这一镜的动作设计
  （动作链十条铁则详 `kinema/references/video-prompting.md`，强制规范）。

## 7. 声音体系

- **定制音色**（seed-audio-1.0 生成式，缺省路径）：按角色卡 `voice_prompt` 生成一条演绎并
  立档，之后每次合成都带**声线描述文案 ＋ 参考音频**双锚定，缺参考音硬拦不发；native 的
  锚定绑定句带同一段描述。真发前的选角闸点名没有音色引用的说话人。
- **模版音色**（seed-tts-2.0，显式例外）：官方固定 speaker，`voice audition` → `voice use`
  立档；同 speaker 零漂移，但没有描述可发给视频模型。
- **音频剧本**：整章声音写成一段自然语言（声线/逐句演绎/配乐/音效，@音频N 参考音对位），
  生成式模型一次出已混好的整轨——与逐镜三轨混音（配音+BGM+音效）双路线并存，章级切换。
- **混音收尾**：BGM 让路 EQ ＋ 自动闪避，末级响度归一 −16 LUFS 配真峰限幅。

## 8. Studio 制作台

三层全 stdlib：`scanner` 只读扫描 / `server` HTTP / `jobs` 异步任务器；前端原生 ESM
免构建。写路径与 CLI 同一条（`Project.load → 领域模块 → Project.save`）。

一屏工作面：总览 · 待审 · 看板 · 片库 · 成本 · 模型配置中心（能力路由 + 服务商货架 +
密钥三态 + 零成本自检 + 控制台直达）· 项目页（原著/分集/角色）· 剧本工作台 · 人物关系图谱 ·
章节制作台（五关口 + 时间线 + 资产血缘）· 3D 导演台（灰模排戏 · 36 档运镜库 · 可复现
previz）· 简笔分镜板 · 音频剧本。

人机分工：五态审阅 × 版本栈 × 像素锚定批注 × 宫格候选选优 × 局部框选改造 × 跨镜批量编辑
——agent 出方案，人做判断，每次判断留痕可回滚。

## 9. 成本模型

`--dry-run` 逐镜报价 → `budget` 事前闸（整批预估超额**一镜都不发**）→ 逐镜幂等
（失败不重复计费）→ 预估与实际分两本台账。kenburns 零视频成本，是「先审后花钱」
的地板路线。

## 10. 配置与存储

- **`config/models.yaml` 是模型与画风唯一真源**；本机覆盖层（`models.local.json` 连接段、
  `secrets.local.json` 密钥，均不入库）走 `config_overlay` 三态深合并，网页与 CLI 同一条
  写路径；密钥只写不读、永不回显。
- **存储**：缺省本地 JSON（文件即数据库）；可选 MySQL（保存双写、新者赢同步）与对象存储
  （阿里云 OSS / 腾讯云 COS / 火山 TOS，URL↔本地路径纯函数映射）。`db pull` ＋ `oss pull`
  即可在新机器恢复全部。

## 11. 质量守卫

2,700 余个离线守卫用例（stdlib unittest · 零依赖 · 一分半跑完），覆盖请求体、提示词装配、
剪辑合成、台账、数据契约与配置语义。**守卫收敛纪律**：新守卫只加在引擎行为层，前端只收
竞态与资源两类，不为文档措辞/数字/图标设守卫。

## 12. 合规边界

工具链止步于成片交付，**不承接发布**——真要接也只走各平台官方 API ＋ 人工确认，
**绝不 RPA、绝不群控、绝不逆向**。素材：图像走付费 API 授权，内置音乐/音效全 CC0，字体免费
商用；AI 生成披露自动附在交付 manifest 与平台文案。许可证 AGPL v3 ＋ 商业授权双轨。

## 附 · 立项取舍存档（2026-07-15）

以下决策在立项期定下，至今仍在约束设计——结论句在别处都能看到，**为什么这么选**只记在这里：

- **三层混合系统而非纯 Skill**：Skill 层承接"最需要智能"的活，本地引擎承接"调 API +
  拼接 + 重试"的机械活——把贵的智能和便宜的机械劳动分开计价。
- **不上多 Agent**：多 Agent 并行合并会让 token 成本暴涨 4~15×，而产物质量取决于单镜
  描述写得好不好，不取决于讨论的热闹程度。
- **不碰 RPA/逆向发布**：任何"一键发国内 60+ 平台"的工具底层都是群控/逆向，处在平台
  封号红线内。
- **身份与运动解耦**：AI 视频单链条 15~20 秒后质量下滑；身份靠图锁、运动靠提示词，
  每段短生成再拼接。
- **逐镜幂等控成本**：每镜 checkpoint、失败不重复计费，是"敢把生成交给自动化"的前提。

立项设想与最终实现的主要偏差（读到旧设想时以右列为准）：

| 立项设想 | 实际落地 |
|---|---|
| 合成走 MoviePy + FFmpeg，以 MoneyPrinterTurbo 为基座 | 引擎零 Python 依赖，纯 FFmpeg filtergraph，全自研 |
| MVP 不做图生视频 / Web 前端 / 任务队列 | 三者皆已落地（dubbed/native 模式 · Studio · jobs） |
| 默认 9:16 竖屏、两种视频形态、三道人工卡点 | 默认 16:9，三种渲染模式，逐节点确认 ＋ 五态审阅 |
| 角色三视图设定图 | 三区两视（正面肖像特写｜正面全身｜背面全身） |
| 首尾帧衔接为主的镜间连贯 | 全能参考一镜一片为缺省，衔接降为显式 opt-in |
| 核心 CLI 含 `kinema publish` | 未实现，发布归规划中的独立 skill |
