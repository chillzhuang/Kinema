# board-craft · 拆拍工法与标注规范（kinema-sketchboard 细则）

## 一、从分镜脚本到 9 拍（拆拍工法）

分镜脚本的五层结构（主体表演/微表情/次要运动/光影/收束）是**空间分层**，beats 是
**时间分层**——把同一份设计沿时间轴展开：

1. **先定两端**：拍 1 = 上一镜末态的延续动作（入拍即动），拍 9 = `end_state` 的
   画面。两端定了，中间 7 拍只是插值。
2. **主动作切段**：把 `action`/`video_prompt` 里的主体表演按"一拍一个主动词"切开
   （俯身→喷涂→核对→转夹具→直身→搁枪），动词之间不留跳变——相邻拍的姿态必须
   能自然连续（板上读起来是同一个人在动，不是九张随机姿势）。
3. **次要运动与微表情挂拍**：漆雾沉降、报纸轻颤、单眼微眯这类五层设计里的细节，
   挂在最相关的主动作拍上（`action` 里带一笔，或进 `sound`/`light`）。
4. **camera 按段配**：整镜的 `camera`（运镜措辞）仍是总纲；beats 的 `camera` 写
   该秒段的机位细化（起幅/推进中/定格），**不与总纲打架**——总纲说"缓慢推近"，
   拍级就写"推近起幅/推近中段/收在近景"，绝不写反向运镜。
5. **秒段**：缺省引擎按 `dur/9` 均分（`0-0.6s` 式一位小数）；节奏不均匀的镜写显式
   `t`（如爆发拍 0.4s、余韵拍 1.2s），但必须首尾相接覆盖全时长。

**依据**（timeline prompting）：Seedance 2.0 对"0-2s 做什么、2-4s 做什么"的分段
结构远比一大段散文听话；多步动作按时间顺序列出，模型才按脚本"剪辑"而不是自由发挥。
参考图必须**声明职责**（板=动作脚本、首帧=画面基准）——不声明，模型不会自己猜对。

## 二、箭头标注规范（画进板里的语言）

行业惯例（StudioBinder / Toon Boom / Mark Simon《Storyboards: Motion in Art》）：

| 标注 | 颜色 | 画法 |
|---|---|---|
| 人物/物件运动轨迹 | 红箭头 | **紧贴主体**画出，沿动作方向 |
| 摄影机运动 | 蓝箭头 | **线条更粗、贴面板边缘**：推近=四角向内的箭头；横移/跟踪=沿边直箭头；环绕=弧线箭头；上摇/下摇=竖直箭头 |
| 取景/构图笔记 | 绿色标记 | 内框矩形（终构图）、三分线、负空间提示 |
| 灯光方向 | 橙色标记 | 光源方向箭头/光束示意 |
| 声音/情感强调 | 紫色波浪线 | 节拍点、情绪爆发处 |
| 编号与笔记 | 黑色文本 | 每格左上角「1. 0-0.6s」+ 四~八字动作标题 |

**双编码**是行规：箭头 + 文字标签并用，机位与主体动作绝不歧义。板底部一条窄图例
横条列出五色含义（引擎契约句已含，质检时确认它在）。

## 三、板提示词契约（引擎 `sketchboard.board_prompt` 逐段）

引擎确定性拼装，顺序即权重——**指挥层不手写板提示词**，只写 beats：

1. 版式行：16:9 · 3×3 · 9 格编号 · 从左到右从上到下；
2. 素描契约：铅笔素描灰阶排线/线条果断/细节以看清动作为度/强轮廓；仅发光体/能量/关键识别色可少量点缀，
   绝不整幅上色；板头标题钉「镜 N」防样板人名外流；
3. 参考图职责声明（与附图顺序一一对应）：内置样板图（只学版式与画法）→ 该镜分镜图
   （画面基准，转译为素描）→ 出场角色设定图（外观锁定，素描后仍可辨认，每格每人
   至多一次）；
4. 本镜信息：场景名 + 出场名（只报名字——外貌归设定图，复述即漂移）；
5. 面板内容：9 行「1. 第0-0.6秒：动作｜镜头：…｜构图：…」；
6. 运动规则：每格可见运动、禁静态站姿、相邻格连续推进、内容绝不跨格重叠；
7. 五色图例 + 底部图例条 + 无水印。

板生成的参考图组合由 `cli._sketch_refs` 定死：样板图 + 分镜图（有则附）+ 角色
设定图（`lineage.required_refs` 同源，≤4 张）。**无画风前缀、无 moodboard**。

## 四、消费侧（gen-video 时发生什么）

- guide=sketch 的镜：`_shot_plan` 仲裁——previz 末帧与 V2V **一律不参与**；
  板文件在盘且 provider 支持（seedance/mock）才作 `role=reference_image` 附发；
- 提示词注入顺序：增量契约句 → 运镜总纲 → **时间轴**（beats 逐秒段）→
  【板附发时】职责声明+风格防护句 → delta 骨架 → 正文 → 防字地板；
- 风格防护句（生命线）："画面风格、色彩、材质与光影一律以首帧/参考图为准，绝不
  输出铅笔素描或草图质感画面，绝不把标注箭头与文字画进画面"——成片变素描的唯一
  防线，与 V2V 契约句防灰模配色同一个药方；
- dry-run 与真发同源（`_shot_plan` 一处定死）；dry-run 行尾「参考图=简笔分镜板」
  即板会附发的标记。

## 六、艺术身份板（选用，不替代工程三区两视设定表）

英雄角色可另出一张**艺术身份板**（电影感角色研究，非网格版式）：大型英雄全身像
偏心作锚 + 周围散布中性全身/背面/侧面/坐蹲/俯仰视角研究 + 剪影研究区 + 表情研究区
+ 细节研究区 + 简约 ID 块（名称+核心情绪标志），黑白铅笔素描。样板图：
`references/templates/identity_board_template.png`。

**边界**：它是给人看的艺术资产与给板生成的补充参考，**不写进 `characters[].sheet`**
——工程设定图（三区两视铁律，`project refs` 产）才是引擎一致性链路的锚，身份板不入
血缘、不参与 `design_refs` 挂载。要用就手动放进该镜 `shots[].refs` 或角色
`characters[].refs`。
