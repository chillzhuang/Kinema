# kn-anime · 动漫（十五大画风总入口）

**一个入口，十五种动画传统。** 动画是本仓库覆盖题材最宽的形态——从 80 年代赛璐璐的
胶片浪漫、上海美影厂的水墨气韵、荒木飞吕彦的迷幻撞色、美漫的墨线网点，
到皮克斯的次表面散射与一支铅笔的涂鸦能量，每种画风背后是一整套被验证过的美学体系。
本 skill 的职责：**帮用户选对传统，然后把该传统执行到骨子里**。

## 直接启动整套流程（`/kn-anime <故事/主题>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律：
   建项目 → 文案分镜 → 设定单+设定图 → 生图先首镜 → 配音 → 合成 → 动态化）。
2. **选定画风**（见下《画风选择协议》）→ 建项目显式 `--profile <画风>` 并全流程绑定
   同一 profile：设定图/分镜图/封面每次生图都经该 profile 的 `style_prefix` 注入画风
   前缀，这是全片风格统一的机制保障；逐镜混风格仍走 `shots[].profile` 例外。
3. 默认横屏 16:9（剧场版画幅语感）；抖音/快手竖版投放用 `--aspect 9:16` 或 `--both` 双出。
   动态化：对白剧推荐 `c`(dubbed 对口型)；空镜/氛围多推荐 `b`(native)。

## 画风选择协议

用户**点名了**（"宫崎骏那种"/"80年代赛璐璐"/"像你的名字"）→ 直接用对应 profile。
没点名 → **直接用缺省画风 `anime`（现代新番·数字作画，本 skill 默认），不再询问**；
仅当题材与现代新番明显相斥（水墨诗词/童话绘本/复古怀旧）才一句话建议更贴的档并
等确认。画风一经立项即由引擎快照进 `project.style_prompt`（全片生图统一取用，
中途换风代价最大）；后续用户仍可 `project set --style-prompt` 换画风重做：

## 十五大画风视觉 DNA（写提示词前逐条内化）

### anime_80s · 80年代日漫剧场版（"经费爆炸"的赛璐璐黄金期）

AKIRA / 王立宇宙军时代 OVA 的美学——那个"每一帧都烧钱"的年代：
- **胶片体质**：整体过一层胶片——细腻颗粒、暗部偏青、高光柔溢出（profile 自动叠
  `film_grain + vignette`）；色域是**复古印刷感**的，饱和但不荧光。
- **手绘密度**：背景是厚涂手绘——城市夜景每一扇窗都亮着不同色温的灯，机械每一颗
  铆钉都在；提示词要主动喂细节密度（"街道布满霓虹管线与蒸汽管道"）。
- **人物造型**：写实比例（7~8 头身）、厚重衣褶、**鼻梁高光线**与锐利的阴影二分——
  与现代萌系彻底相反，脸是"画出来的成年人"。
- **演出气质**：长镜头凝视 + 爆发性动作镜；夜戏是主场（霓虹雨夜/机库/天台）。
- ✅ `低角度仰拍，穿皮夹克的男人站在天台边缘俯瞰霓虹都市，风衣下摆被夜风掀起，
  远处高速路车灯拖成光带，手绘厚涂的密集楼宇每扇窗透出不同色温的光`

### ghibli · 吉卜力/宫崎骏（水彩里的田园诗）

- **背景即主角**：水彩晕染的手绘背景——蓝天下**巨大的积雨云**（吉卜力签名）、
  被风吹成波浪的草地、旧木屋与石板路；背景永远比人物"更用力"。
- **光**：温暖的自然光——午后斜阳穿过树叶的碎光、屋内昏黄灯泡；没有戏剧性打光，
  只有"生活里的光"。
- **人物**：圆润亲切、红润脸颊、比例真实但线条柔化；表演靠**日常动作的郑重感**
  （认真吃饭、用力蹬自行车、逆风奔跑）。
- **"间"的哲学**：吉卜力允许"什么都不发生"的镜头——云飘过、水壶冒汽、猫翻身。
  每 3 镜给一个这样的呼吸镜，节奏就对了。
- **风是常驻角色**：video_prompt 多写风的痕迹——`发丝与裙摆被风轻轻掀起，草浪从远处滚来`。
- ✅ `全景，少女骑自行车冲下乡间坡道，两侧稻田被风压出波浪，头顶巨大的积雨云
  在蓝天里堆成山，水彩质感的远山层层淡去`

### anime（默认）· 现代新番（数字作画的华丽时代）

- **线条**：数字作画的高精度锐利线条，粗细有呼吸（外轮廓粗、内部细）。
- **色设计**：高饱和 + 明暗二分干脆利落；角色有**标志性配色**（写进设定集）。
- **光效演出**：技能光效、粒子飞散、镜头光斑、色收差（ufotable 式）；`bloom`
  由 profile 自动叠。高光镜头允许"画面被特效吃掉一半"。
- **构图张力**：大胆透视（鱼眼仰拍/俯冲镜）、斜线构图、决斗式对峙站位。
- ✅ `鱼眼仰拍，少年挥刀劈下的瞬间，蓝白色刀光轨迹撕裂画面，粒子光点四散，
  背景速度线放射，明暗二分的脸上只有眼睛在发光`

### shinkai · 新海诚（光才是主角）

- **天空占一半**：饱和度拉满的黄昏渐变天（橙→紫→深蓝）、层叠积云、飞机云——
  构图里天空常占 50%+，人物是天空下的剪影。
- **光的物理学**：强逆光、镜头光晕（lens flare）、雨滴上的高光、光斑 bokeh——
  每一镜都问"光从哪来、在哪反射"。
- **都市精度**：电线、路牌、站台、便利店灯箱——城市细节精确到能认出街道；
  "写实到一步之遥，又比现实美一度"。
- **情绪=色温**：想念是暖橙、错过是雨青、释怀是晨蓝——色温曲线跟情绪走。
- ✅ `中景逆光，女孩站在天桥上回头，黄昏的橙紫色渐变天空占画面上方三分之二，
  镜头光晕从她发梢炸开，脚下城市街道的电线切割着天空，一列电车拖着灯光驶过`

### pixar · 皮克斯 3D（表演的艺术）

- **造型语法**：圆润+夸张比例（大头/大眼距/粗手指），但**材质写实**——皮肤次表面
  散射、毛衣纤维、金属磨损；"卡通造型 × 真实材质"是皮克斯公式。
- **表演戏**：皮克斯的灵魂是微表情——挑眉、抿嘴、眼神游移；每个反应镜都是表演机会，
  image_prompt 写具体到"左眉挑起半分，嘴角努力憋住笑"。
- **光讲故事**：暖色叙事光（家/回忆）vs 冷色危机光；三点布光柔和，浅景深聚焦表演。
- ✅ `近景，圆滚滚的小机器人歪着头，单只眼部镜头光圈缩放了一下表示困惑，
  举起磨损的机械手指了指自己，暖黄色车库光从背后窗户洒入，浅景深`

### disney3d · 迪士尼 3D（华丽的舞台）

- **角色美学**：大而明亮的眼睛（占脸 1/3）、精致五官、公主级发丝渲染
  （每根发丝有高光）；反派有华丽的轮廓剪影。
- **材质盛宴**：丝绸裙摆的光泽流动、魔法粒子、冰晶/花瓣/星尘——画面永远"值回票价"。
- **舞台布光**：音乐剧式——主角登场自带追光感，魔法时刻体积光从天而降；
  `bloom` 由 profile 自动叠。
- **场景**：城堡尖顶、魔法森林、极光夜空——空间本身是奇观。
- ✅ `全景，少女在冰晶宫殿中央旋身，裙摆的丝绸光泽随动作流动，魔法粒子
  从指尖螺旋升起，体积光从穹顶洒下如舞台追光，周围冰柱折射出蓝紫色光谱`

### anime_xianxia · 国漫仙侠（东方古典审美的二次元表达）

魔道祖师 / 天官赐福那一代国产 2D 动画确立的国风语法——工笔的骨，水墨的魂：
- **线与晕的分工**：人物与器物走**工笔勾线**（衣纹/发丝/佩饰精确利落），
  远景与天空走**水墨晕染**（山如黛染、云似墨洇）——一硬一软是国漫仙侠的签名。
- **衣袂即表演**：广袖、束发玉冠、腰间绶带——**没有风也要有风**；每镜写衣袂
  与发带的动势（`广袖翻卷`、`发带逆风扬起`），静止的仙侠角色是失败的。
- **灵力可视化**：施法不是"发光"——是**流光**（灵力沿剑身游走）、**符箓**
  （金色篆文悬浮）、**气浪**（衣袍鼓荡尘土外推）；色彩用青白/鎏金，忌荧光紫。
- **东方色彩体系**：黛青、绯红、月白、鎏金——大面积低饱和底色 + 一处高饱和
  点睛（红衣/金符/灯笼）；场景是飞檐斗拱、云海仙山、竹林月洞门。
- ✅ `中景仰拍，白衣剑修立于云海之上的孤峰剑碑前，广袖与发带被罡风掀起，
  指尖灵力化作青白流光沿剑身游走，远景水墨晕染的群山在云涛中沉浮，一轮
  淡金落日为衣缘镀上金边`

### anime_mecha · 机甲热血（钢铁的浪漫）

EVA / 宇宙世纪高达 / 天元突破一脉的机械作画传统——机甲的说服力全在密度：
- **机设密度**：装甲分件线、铆钉、喷口、涂装编号、警示标——机体每一块装甲
  都要"能拆下来"；提示词主动喂机械细节（`肩部装甲分件带部队编号与磨损掉漆`）。
- **尺度感**：机甲的巨大靠参照物——人类站在脚边、机库钢架、被踏碎的路面；
  仰拍 + 广角畸变是尺度的镜头语法。
- **出击仪式**：弹射轨道、锁扣依次解除、驾驶舱 HUD 亮起、喷口点火——
  **出击镜是本画风的招牌**，值得花 2~3 镜铺垫一次起飞。
- **战损叙事**：装甲崩裂、单眼闪烁、断臂喷火花——战斗的代价要画在机体上；
  胶片颗粒与暗部偏青（profile 自动叠 film_grain+vignette）给战场厚重感。
- **驾驶舱正反打**：机战的情绪在舱内——头盔反光里的爆炸、汗珠、怒吼；
  机外大战与舱内表演交替剪。
- ✅ `低角度广角仰拍，白蓝涂装的重型机甲单膝砸落在废墟街道，地面龟裂尘土
  炸开，肩部装甲分件上的部队编号在火光中可辨，单眼传感器扫过镜头亮起红光，
  背后建筑燃烧的浓烟被夜风撕扯`

### anime_jojo · JOJO的奇妙冒险（荒木飞吕彦的浓烈美学）

David Production 动画化定型的荒木语法——"画面在吼"是这个画风的常态：
- **线与影**：粗硬有力的轮廓线 + **漫画式剖面线/排线阴影**（脸颊、颈侧、衣褶
  用密集斜线塑体积，不是柔和渐变）；轮廓允许比常规动画更"重"。
- **撞色哲学（招牌）**：**非自然配色**——紫发金衣、品红皮肤、青绿天空都合法；
  同一场景可随情绪**整体反转色调**（对峙时突变紫底金轮廓、觉醒时品红闪场）。
  提示词直接点名色组（`紫金撞色`、`品红与青绿的迷幻反转色`），忌"日常写实配色"。
- **JOJO立ち（站姿即演出）**：时装模特般**拧转脊柱、反关节手势、指向镜头**的
  夸张定格 pose——每集至少 2 镜纯站姿定格；静止镜在本画风不是偷懒，是高潮。
  人体是健美写实系（宽肩窄腰、肌肉线条清晰），时装走荒木式奇异剪裁
  （露腹装/心形挖空/垫肩/满身铆钉与链条）。
- **替身演出**：异能对决题材给角色身后浮现**半透明守护灵体**——
  `角色身后浮现半透明的人形灵体，通体紫水晶质感，双拳前伸`；替身与本体
  异色（本体金、替身紫），动作同步或护主格挡。
- **凝视与嘴角**：爆发前必有**长凝视对峙**——双人侧脸对切、眼部大特写、
  上扬嘴角特写（"这可真是太逗了"式自信）；蓄势的压迫感用**紫色气场涌动 +
  放射速度线 + 网点渐变背景**表达。⚠️ ゴゴゴ 拟声字效**不进画面**（本体无字
  铁律），压迫感全靠气场与构图，金句交给字幕层的金字紫边样式。
- ✅ `低角度仰拍定格，金发男人背对夕阳站在废墟顶端，脊柱夸张拧转回眸，
  一手反关节搭在帽檐一手指向镜头，身后浮现通体紫水晶质感的半透明人形灵体
  双拳交叉，品红与金的撞色天空下放射状速度线聚焦，剖面线阴影刻出肌肉轮廓`

### anime_american · 美漫（漫威/DC 的墨与网点）

金银时代漫画印刷美学 × 现代动画能量（蜘蛛侠：平行宇宙证明了它能动起来）：
- **墨线为王**：粗重有力的**墨线勾边**（外轮廓比日漫粗一倍）+ **交叉排线**塑造
  肌肉与阴影——阴影是"画"出来的线，不是柔和渐变；下颌线、眉弓、颧骨永远锐利。
- **网点与套印**：半调网点（Ben-Day dots）铺中间调，轻微**套印错位**（红蓝边缘
  分离）致敬印刷时代——提示词点名（`半调网点质感`、`轻微套印错位`）。
- **英雄语法**：强透视缩短（拳头怼向镜头比头大三倍）、低角度英雄落地
  （landing pose 砸裂地面）、斗篷与剪影（背光只留轮廓）、都市天际线俯瞰——
  每集至少一镜 **splash page 级**的冲击构图。
- **色彩**：红蓝黄高饱和原色打底，反派用紫绿；明暗切割走**戏剧舞台光**

- **表演**：硬汉下颌特写、咬牙、握拳青筋——情绪外放，忌日漫式符号化汗滴。
- ✅ `低角度仰拍，披风英雄单膝砸落在雨夜街道，地面放射状龟裂，强透视的拳头

### anime_pixel · 像素动画（一格一格垒出来的世界）

不是"低清"，是**像素纪律**——每一颗像素都是有意放置的（游戏对话框叙事请走
kn-game，这里是纯像素美术动画，无任何游戏 UI）：
- **调色板纪律**：有限调色板（16~48 色）是像素美学的骨——渐变靠 **dithering
  抖色**（棋盘格过渡），天空/光晕/水面是抖色的主场；提示词点名
  （`有限调色板`、`dithering抖色渐变的黄昏天空`）。
- **像素颗粒**：方正清晰的大颗粒像素、pixel-perfect 锐利轮廓——拒绝模糊与
  抗锯齿的"假像素"；人物 3~5 头身的 sprite 比例。
- **场景纵深**：多层视差感（前景剪影/中景主体/远景抖色天空）；霓虹像素都市的
  每扇发光窗户、像素田园的逐格摇摆麦浪——细节密度是像素动画的"经费"。
- **光的像素表达**：光晕是同心色阶环、光斑是亮色像素簇、雨是斜线像素条——
  一切光效都"数得出颗粒"。
- **定帧感**：每一镜构图完整得像一张可收藏的像素画壁纸；空镜价值极高
  （像素落日/雨夜屋檐/亮灯便利店）。
- ✅ `全景，像素艺术的雨夜便利店街角，暖黄的发光窗户映出货架色块，
  dithering抖色的深蓝夜空压着霓虹招牌的青品红光晕，斜线像素雨条掠过路灯，

### anime_doodle · 涂鸦线稿动画（一支笔的能量）

草稿箱里逃出来的动画——线稿不是半成品，**手绘的呼吸感就是完成品**：
- **线条即生命**：铅笔/钢笔的粗糙速写线，**保留起稿辅助线与修正痕迹**；
  线条允许抖动与"沸腾感"（boiling line）——完美光滑的线是这个画风的死敌。
- **纸是舞台**：笔记本纸/方格纸/牛皮纸的纸纹永远在场，允许纸角卷边、
  橡皮擦痕、咖啡渍——画面就发生在"一页纸上"。
- **点睛色事件**：大面积单色线稿（铅笔灰/钢笔蓝黑）+ **一两处高饱和马克笔

- **稚拙表演**：简笔画角色靠**夸张的挤压拉伸**演戏（惊讶时眼睛弹出三倍、
  跑动时腿画成风车圈）；涂鸦装饰元素（箭头、星星、爆炸圈、汗滴符号）
  可入画——但**任何文字字母不进画面**（本体无字铁律，梗字幕交给字幕层）。
- **转场天赋**：翻页、笔刷涂改、橡皮擦掉重画——video_prompt 写
  `画面像被一只看不见的笔实时画出来`。
- ✅ `中景，方格笔记本纸面上的简笔画小人撑着一把高饱和的黄色雨伞，
  铅笔速写的雨丝斜织整页，小人周围画着三个下坠箭头与一圈爆炸线涂鸦，

### anime_fairytale · 童话绘本动画（会动的童书跨页）

凯尔经的秘密 / 狼行者（Cartoon Saloon）确立的平面装饰美学 × 童书绘本质感：
- **纸是底色**：水彩与色铅笔的纸纹肌理永远在——画面像画在有齿纹的水彩纸上，

- **平面装饰性**：不追求透视纵深——森林是**图案化**的（螺旋树冠、对称蕨叶、

- ✅ `全景对称构图，小女孩提着灯笼站在图案化森林的中央小径，螺旋状的树冠

### anime_ink · 中式水墨动画（美影厂的活水墨）

小蝌蚪找妈妈 / 山水情——上海美术电影制片厂把水墨画"救活"的世界级独门：
- **笔墨即造型**：形体靠**笔触**概括而非轮廓线——虾须是一笔中锋，山是几笔

- **人是点景**：远景小人立于天地之间；特写只给器物与手（执笔/抚琴/斟茶），
  水墨人脸不给大特写。
- ✅ `远景，一叶扁舟自画面左下缓缓入画，蓑笠翁执竿的身影以淡墨数笔概括，

## 共通分镜法则（动画演出文法）

- **开场 ≤2s 必须有画面钩子**：主角特写、奇观空镜（shinkai 的天空/迪士尼的城堡）
  或标志性动作入画。
- 对白：正反打 + 反应镜三连；2D 系表情可符号化夸张，3D 系（pixar/disney3d）
  走写实微表情——**两套表演体系不要混**。
- 每集至少一个**该画风的招牌镜**：80s 的霓虹夜景、吉卜力的云、新海诚的逆光、
  皮克斯的表情戏、迪士尼的魔法时刻——观众为这一镜转发。
- 双语提示词按 [`../kinema/references/storyboard.md`](../kinema/references/storyboard.md) 规范：中文主、英文辅（`image_prompt_en`
  用对应传统的地道术语：cel animation / watercolor background / subsurface
  scattering / volumetric light / lens flare）。

### 2D 作画运动语法（3D 档 pixar / disney3d / anime3d / anime_ldr 不适用）

`storyboard.md` 的运镜库是**电影摄影机语法**，对 3D/CG/真人档直接成立；
但 2D 手绘动画**没有摄影机也没有物理**，它的"运动"是逐张画出来的作画 + 摄影台图层位移。
拿摄影机语法硬套 2D 档，出来的就是"3D 味的日漫"——最典型的失败是丝滑插值 + 写实景深。
故 2D 档（anime / cel / 80s / ghibli / shinkai / xianxia / mecha / jojo / american /
pixel / doodle / fairytale / ink）按下面这套写，**3D 档一条都不适用**。

**一、节拍：一拍二，不是丝滑**
日式手绘的基准是**一拍二**（同一张画连续两帧，≈12 张/秒；慢镜与静态段落用一拍三 ≈8 张/秒），
只有跑动、打斗的爆发帧才上一拍一。写 `video_prompt` 要的是**有顿挫的作画感**——
中文写「手绘作画感，动作有顿挫、关键姿势有停顿，避免平滑补间」，
英文写 `hand-drawn animation on twos, held key poses, no smooth interpolation`。
**别写 `smooth motion` / `fluid 60fps` / `motion blur`**——那三个词直接把 2D 拽向 3D 渲染味。

**二、姿势优先（pose to pose），中割能省则省**
2D 演出靠**关键姿势本身好看**，不靠中间过程。所以：动作镜写清**起势与定势两个姿势**
（`action` 写起势、`end_state` 写定势），中间过程留给模型；
爆发瞬间用**定格 pose**（止め絵：画面定住 + 摄影台缓推），比让它一直动更像日漫。

**三、2D 专属的四种"运动"**（这些才是该写进 `video_prompt` 的东西）
| 手法 | 中文措辞 | 英文措辞 | 用在哪 |
|---|---|---|---|
| 速度线 / 集中线 | 背景转为放射状集中线，主体定格前冲 | speed lines / radial focus lines, subject held mid-lunge | 冲刺、出招、震惊反应 |
| 残像 / 多重残像 | 动作留下若干层半透明残像，尾随主体轨迹 | multiple afterimages trailing the motion arc | 高速移动、瞬身、连击 |
| 摄影台推拉（止め絵） | 定格画面，仅摄影台缓慢推近／横移，人物保持不动 | held cel with slow camera push-in on the artwork, character motionless | 决意台词、名场面、金句镜 |
| 布料与发丝飘动 | 发梢与衣摆被风持续吹动，其余保持静止 | hair and cloth drifting in the wind, everything else still | 静场镜的"活着"感（2D 唯一该持续动的东西） |

**四、摄影台不是摄影机**
2D 的"运镜"实为图层平移/缩放（撮影処理），所以 **2D 档天然与 `kenburns` 模式最合拍**——
静图 + 缓慢推拉本来就是日漫的正宗做法，不是省钱的妥协。要动起来才成立的镜再上 `dubbed`/`native`。
`camera` 字段仍可用运镜库的●稳定档（推/拉/摇/移/固定）与「库布里克对称推进」「老男孩横移」
这类**平面感强**的条目；**希区柯克变焦、卢贝兹基漂浮、FPV 穿越、子弹时间**这几条依赖真实光学
与三维空间，2D 档别用（要"眩晕"就用集中线 + 荷兰角）。

**五、表情与光**
表情走**符号化夸张**（汗滴 / 井字青筋 / 瀑布泪 / 白眼 / 头顶黑线 / 脸颊斜线红晕）——
具体 retake 措辞见下文《共通重做意见词典》「表情没戏」行，**此处不重复列词**。
光走**平涂二值**（亮部/暗部两阶 + 一条高光边），不写次表面散射、不写物理景深、
不写焦段（`lens` 字段留空，见 `storyboard.md` 字段表该行）。

## 共通重做意见词典（review retake 用，各画风专属从上文 DNA 反推）

| 症状 | `--note` 建议写法 |
|---|---|
| 画风混了 | `严格回归<画风名>体系：<该画风 DNA 的 2-3 个关键词>，去掉<混入元素>` |
