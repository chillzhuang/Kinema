# kn-miniature · 微缩世界

**俯瞰一个玩具般的小世界**：移轴镜头把真实拍成模型、把模型拍成宇宙。
微缩美食/微缩工地/小人国日常是短视频的长红解压品类——"大变小"的视觉魔术自带完播。

## 直接启动整套流程（`/kn-miniature <主题>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律）。
2. 全程 `profile=miniature`；分镜/提示词按本文件的移轴法则写。
3. 默认横屏 16:9（竖版投放用 `--aspect 9:16`）；动态化推荐 `b`(native)——微缩世界里的"小动静"
   （小吊车转动/小人搬运）配原生环境音，解压感拉满。

## 类型定位

- 三条内容线，戏眼各不同：

| 内容线 | 戏眼 | 视觉母题 | 招牌镜 |
|---|---|---|---|
| 小人国日常 | 微缩小人在真实物体上劳作 | 在西瓜上开挖掘机 · 草莓采收工地 · 键盘上的清洁队 | 微距特写小人干活 |
| 微缩场景漫游 | 袖珍世界的镜头巡礼 | 微型城市街区 · 袖珍厨房 · 铁道沙盘 | 极缓下潜靠近街道 |
| 尺度魔术 | 真实场景移轴化 | 城市变沙盘 · 港口变浴缸玩具 · 车流变玩具轨道 | 高空俯瞰全景 |
- 解压逻辑：秩序感 + 精致感 + "被我尽收眼底"的掌控感——画面必须**井然有序**，
  杂乱的微缩只是杂物。

## 视觉语言 DNA（移轴光学法则）

- **移轴三要素**（缺一不像）：**斜俯视 30~45°**（人低头看桌面模型的角度；
  平视破功、垂直正俯也破功——那是地图不是模型）+ **上下重虚化中间锐利**
  （焦平面只有一条水平窄带）+ **饱和度略拉高**（玩具感来自艳丽与无深阴影）。
- **尺度对比是戏眼**：微缩小人 × 真实巨物（一颗草莓=一座山、一枚硬币=广场）——
  提示词里必须写出这个对比锚点；没有锚点，观众读不出"小"。
- **小人要"少细节"**：微缩人是模型涂装感的色块小人（安全帽一点黄、工装一块蓝），
  写实的五官与布料细节反而穿帮——真模型的人偶本来就没有脸。
- **光**：人造暖光（模型棚灯感）或清晨低角度阳光；影子要短而柔——
  深长的影子会把"玩具"拍回"实景"。
- **秩序构图**：俯瞰网格感（街道/农田/货架的规律线条），主体动线清晰；
  一切排列都比现实更整齐一点（模型师摆的，不是生活长的）。
- `vignette` 特效由 profile 自动叠加（观察窗感）。
- **抽象词兑现表**（写了左列的意图，正文必须落出右列的物理内容）：

| 想要的感觉 | 必须写出的物理内容 |
|---|---|
| 玩具感 | 斜俯视 45° + 上下重虚化 + 高饱和 + 短柔影（四件套） |
| 解压 | 规律排列的秩序线条 + 单一清晰动线 + 明亮无深影 |
| 小人国魔术 | 微缩小人 + 真实巨物锚点 + 劳作动作（采收/搬运/施工） |
| 精致 | 涂装般干净的表面 + 整齐一致的元素间距 |

## 分镜法则（上帝视角文法）

4~8 镜，4~7s/镜：
- 开场镜=**高空全景**（整个小世界尽收眼底）→ 逐镜下潜：中景（一个街区/工位）→
  微距特写（小人细节动作）→ 收回全景（世界继续运转）。
- "下潜—特写—拉回"的呼吸结构是微缩片的标准节奏。
- 每镜给一个"小动静"：吊车转、小车流动、炊烟升——静态微缩是照片，动的才是世界。
- 全部镜头保持**同一套光与饱和度**（同一张桌上的同一组模型）；
  下潜到特写时焦平面窄带跟着变窄，虚化更重。
- video_prompt：`微型吊车缓缓转动，小人们排队搬运货物` / `镜头极缓下降靠近街道，车流灯光流动`。

## 提示词公式

正文四段式：**斜俯视机位 + 巨物与小人的尺度对比 + 动线与秩序 + 移轴光学特征**：

- ✅ `斜俯视45°移轴摄影，一颗巨大草莓被脚手架环绕，微缩工人小人们在表面采收果肉，微型吊车吊起一块果肉，上下重虚化中间锐利，高饱和玩具感，人造暖光`
- ✅ `高空斜俯视移轴全景，清晨的微缩港口，集装箱按色块整齐码放，玩具般的吊桥正吊起一只集装箱，货车沿单一车道排队行进，上下重虚化，短而柔的影子`
- ✅ en 辅：`tilt-shift 45° overhead, giant strawberry wrapped in scaffolding, miniature workers harvesting on its surface, tiny crane lifting fruit chunk, heavy top-bottom blur with sharp focal band, saturated toy-like colors, warm artificial light`
- ❌ `一个小模型的照片`（没有尺度对比、没有动线、没有移轴特征）
- ❌ `俯视航拍城市地图`（垂直正俯是地图视角，移轴要 30~45° 斜俯）
- `negative_prompt` 常备：`平视视角, 垂直正俯, 全画面清晰, 灰暗色调, 深长阴影, 杂乱堆放, 写实人物细节`
- `image_prompt_en` 取词：tilt-shift miniature effect / narrow horizontal focal
  band / heavy top-and-bottom blur / saturated toy-like colors / neat orderly
  rows / tiny figurines with minimal detail / warm modeling light / short soft
  shadows。

## 声音设计

- 旁白描述用词：「治愈女」「温柔文雅」轻声调（解压 ASMR 气质），写进
  `voice custom --narrator --prompt … --adopt 1` 定制立档；要官方模版音色再 `voice audition` → `voice use`。
  纯环境音路线（无旁白）→ 在章节顶层显式写 `voiceover: none`（缺省语态是 lead，
  不声明会被 lint 按解说驱动来判）。
- BGM：calm 低音量；native 模式的微小机械声/环境声是解压的主角。

## 重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 不像微缩像实景 | `强化移轴特征：上下1/3重虚化，中间窄焦平面锐利，饱和度提高` |
| 没有尺度魔术 | `加入真实巨物作尺度锚点：小人与硬币/水果/餐具的大小对比` |
| 画面杂乱 | `重构为秩序感俯瞰构图：规律的街道/队列线条，主体动线单一清晰` |
| 视角太平 | `机位抬高到斜俯视45°，俯瞰整个微缩场景` |
| 视角太正 | `从垂直正俯降到斜俯视30~45°，露出建筑侧面与纵深` |
| 小人太写实 | `小人改为模型涂装感色块小人，去掉五官与布料细节` |
| 影子太重 | `光改为人造暖光或清晨低角度阳光，影子短而柔，去掉深黑阴影` |

## 何时不用

粘土手作感 → `kn-clay`；游戏微缩布景 → `kn-game`（hd2d）——
判据：本 skill 是**移轴摄影的实景/沙盘**（光学魔术），`kn-clay` 是**摆拍的玩具定格**
（材质魔术），hd2d 是**游戏录屏感**（介质魔术）。
