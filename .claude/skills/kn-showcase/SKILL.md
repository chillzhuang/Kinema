# kn-showcase · 素材复用型解说（无角色 · 资产图拼接）

**一小组 AI 资产图，讲完一整条片。** 本模式的生产哲学：视觉资产**先生产、后复用**——
AI 按文案生成固定场景图与几张资产图（产品三视角/图表/细节特写），分镜靠**复用这组图 +
换运镜 + 换资产**制造动态感，旁白解说驱动节奏。生图成本从「每镜一张」降到
「每资产一张」，且资产在片内多次出现天然强化记忆点。

## 直接启动整套流程（`/kn-showcase <主题/文案>` 即可）

1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律，
   本 skill 只覆写视觉生产方式）。
2. 立项：`project new --title "X" --id <英文词> --profile explainer --skill kn-showcase`
   （简洁信息图画风，用户点名其他画风照常换；**`--skill kn-showcase` 必带**——
   explainer 画风默认派生 kn-explainer，漏了它「报项目名接着做」会路由错 skill、
   丢掉本模式的资产复用工法）→ **无角色，不建 character**；
   `project set <id> --scene "固定场景一句话" --skip-design`（纯复用模式不需要设定集
   宫格，场景作为资产之一在首现镜生成）。
3. 默认横屏 16:9；旁白按账号定位写声线描述定制：`voice custom <id> --narrator --prompt "<声线描述>" --adopt 1`；
   要官方口播音色（「云舟」「Vivi」「渊博小叔」）作品牌声纹再 `voice audition <id> --narrator` → `voice use`。

## 核心工法：资产首现镜生图 → 后续镜 supply 复用

**① 资产清单先行**：从文案里提炼「本片需要几张图」——固定场景 1 张 +
资产图 2~5 张（如：产品正面全景 / 侧面细节 / 数据图表 / 使用场景）。
**每张资产 = 一个首现镜**，提示词写干净构图（居中、留白、无杂物；解说视频忌花哨）。

**② 分镜复用矩阵**：写分镜时给每镜标注用哪张资产。首现镜正常 `gen-image`；
复用镜用 `supply` 引用首现镜的产物（**同图换运镜**制造动态：推近看细节、
拉远看全貌、左移右移扫视）：

```bash
python3 -m kinema gen-image --chapter x/ch01 --only 1,3,5      # 仅资产首现镜生图
python3 -m kinema supply --chapter x/ch01 --shot 2 --file project/x/chapters/ch01_work/images/shot_1.png
python3 -m kinema supply --chapter x/ch01 --shot 4 --file project/x/chapters/ch01_work/images/shot_1.png
# 直供同走版本栈+待审；provider=supplied，生图阶段自动跳过这些镜（零生图成本）
```

- 复用镜的 `camera` **必须写不同运镜语义**（缓慢推近/拉远揭示/左移/凝视呼吸——
  a 模式有真实效力），同图不同动，观感即"多机位"。
- 复用镜不写 `image_prompt`（画面已定，写了也不会用）；`narration` 照常写解说词。
- **系列级复用资产**（多章共用的产品图/LOGO 图）：登记为 prop 走 `project refs`
  生成，存 `assets/refs/prop_X.png`，各章 supply 引用——跨章零重复生图。
- 混合模式合法：氛围空镜/过渡镜照常逐镜生图，复用镜与生成镜自由穿插。

**③ 动态拼接**：每 3~4 镜换一张资产防视觉疲劳 + 合成前按题材选 1~2 层氛围特效
（light_sweep 质感 / bloom 柔光）。**转场镜不在自动件里**——复用镜之间直接硬切是
缺省形态，用户点名要分段字卡时才插（fade_black/wipe 翻页/slide 推移，零成本）。

**④ 成本口径**：生图 = 资产张数 ×¥0.3（非镜数）；TTS 按字；其余零成本。
10 镜解说片典型成本 ≈ 3~4 张资产图 + 配音，约 ¥1.2。

## 资产图视觉纪律（本模式的画风职责：每张资产都是"复用件"）

资产会被推近、拉远、扫视各用两三次，所以**一张资产的构图质量 = 三个分镜的质量**；
按资产类型各有一套棚拍语汇：

| 资产类型 | 构图纪律 | 可直接入词的术语 |
|---|---|---|
| 产品全景 | 主体居中占 2/3 · 四边留白（推近才有余量）| 干净渐变底 · 45° 主光 · 边缘轮廓光 · 底部微反光 |
| 细节特写 | 局部大特写 · 焦点钉在卖点部位 | 材质纹理清晰（金属拉丝/织物编织/玻璃通透）· 单侧光强化立体 |
| 数据图表 | 一图一结论 · 关键数字放大 | 平涂底色 · 两三色配色 · 无装饰网格 |
| 使用场景 | 产品在环境中 · 环境虚化让位 | 生活化场景 · 浅景深 · 暖调氛围光 |

- **组内一致性锁定**（资产间不可漂移项）：同一底色域、同一主光方向、同一透视
  高度——几张资产要像**同一个摄影棚同一场拍的**；混拍感一出，"素材感"就露馅。
- **留白是复用的前提**：每张资产四边留 15% 以上——推近镜要余量、字幕要落位、
  转场要呼吸；顶天立地的构图复用一次就穿帮。
- **画面不写字**（数据图表的关键数字除外）：解说词走 narration+字幕，
  资产图上的文字复用第二次就变成"读过的旧字"。
- 换绑其他画风（`--profile` 换档）时，资产纪律不变，质感词换该画风 DNA——
  棚拍语汇只适用于缺省 explainer/产品路线。

## 提示词公式（仅资产首现镜需要写）

正文三段式：**资产类型声明 + 主体与卖点 + 构图与光**：

- ✅ 产品全景：`产品摄影，一台银灰色便携咖啡机居中立于浅灰渐变底上，45°主光加右侧轮廓光，底部微反光，四边大面积留白`
- ✅ 细节特写：`微距特写，咖啡机顶部的金属拉丝旋钮，单侧光强化刻度立体感，背景虚化成浅灰`
- ✅ 数据图表：`极简信息图，米白平涂底，中央巨大的"3秒"数字，下方三个小图标横排：注水、加热、出杯`
- ❌ `咖啡机的宣传海报，高端大气`（"高端大气"是评价不是画面；海报感=画面里有字的冲动）
- ❌ 复用镜写 image_prompt（画面已由 supply 定死，写了也不会用——把力气花在 camera 与 narration 上）
- `negative_prompt` 常备：`画面内文字标语, 杂乱背景物件, 顶天立地无留白, 多主体并列, 水印`
- `image_prompt_en` 取词：product photography / clean gradient backdrop /
  centered composition with generous margins / studio key light / rim light /
  subtle floor reflection / macro detail shot / minimal flat infographic。

## 分镜法则（解说节奏）

- 开场 ≤2s 抛结论或反常识钩子（配全景资产图）；每镜一个论点，narration ≤ 25 字。
- 「总-分-总」资产调度：开场全景 → 分论点逐资产特写 → 收尾回全景 + CTA。
- 复用镜运镜要**服从论点**：讲卖点→推近该部位；讲全貌→拉远；比对项→左右移；
  数据停留→凝视呼吸。运镜与解说词对不上，观众立刻察觉"图不对题"。
- 字幕走 caption（音字一致，配音念什么字幕写什么）；数据类论点把数字写进
  narration（字幕即重点板书）。
- Studio 支持：分镜卡「⇪ 素材直供」打开直供选择器——复用本章其他镜画面/
  设定资产（同图换运镜零成本），或上传本地图片；直供镜带「⇪ 直供」绿标、
  不显示 AI 重生按钮（无提示词），「✂ 素材改造」照常可用。

## 声音设计

- 旁白即节目：`voice custom --narrator --prompt … --adopt 1` 定制立档为账号声纹；要官方口播系
  「云舟」「Vivi」「渊博小叔」再 `voice audition` → `voice use`；
  语速中等（产品讲解要"介绍给你"不要"念参数"）。
- BGM：upbeat 低音量（解说词为主）；产品质感片可换 calm 配 light_sweep 特效。

## 重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 资产没留白复用穿帮 | `主体缩小至2/3居中，四边留白15%以上，给推近与字幕留余量` |
| 资产间混拍感 | `与资产1保持同一底色/同一主光方向/同一透视高度，仅换主体` |
| 画面里出现文字 | `去掉画面内标语文字，信息走旁白与字幕（图表关键数字除外）` |
| 产品像贴图 | `补 45° 主光与边缘轮廓光，底部加微反光，材质写清（金属拉丝/磨砂）` |
| 图表太花 | `压缩为一图一结论：放大关键数字，配色两三色，去掉装饰元素` |
| 背景抢戏 | `背景简化为干净渐变底，去掉可辨识杂物` |

## 何时不用

要角色出镜演剧情 → kn-anime / kn-anime3d 等风格 skill；纯知识图解且每镜
画面都不同（无复用价值）→ kn-explainer。
