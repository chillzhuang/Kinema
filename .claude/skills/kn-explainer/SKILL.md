# kn-explainer · 知识解说

**把一个主题讲明白**——全平台占比最大的爆款母题。它的生死线不是画面，是
**信息增量**：观众看完必须"知道了一件之前不知道的事"。

## 直接启动整套流程（`/kn-explainer <主题>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律）。
2. 全程 `profile=explainer`；**阶段1 联网检索是本风格的强制步骤**（见下）。
3. 知识类常投 B站/YouTube：建议 `--both` 竖屏+横屏双出。角色设定集可跳过
   （`--skip-design`，解说类无固定角色），场景设定也非必需。动态化通常不需要（a 模式足够）。

## 类型定位（信息增量公式）

- **增量 = 具体数字 + 反常识 + named 案例**。"很多人不知道"是空话，
  "97.5% 的人答错这道题（剑桥 2024 实验）"才是钩子。
- 阶段1 WebSearch 必做：抽 **3~6 条**可核查事实（数字/年份/人名/实验）写进
  `script`，每个分点至少压一条事实。**没有事实增量的解说 = 白噪音，宁可换题**。

## 工业参照（取词库）

| 面向 | 参照 | 可直接入词的术语 |
|---|---|---|
| 编辑插画 | 新闻杂志的社论配图传统 | 概念隐喻具象化 · 单一视觉焦点 · 大面积平涂底色 |
| 信息设计 | 扁平化设计体系（flat 2.0） | 受限色板 2~3 色 · 几何形状构成 · 网格对齐 · 细腻印刷颗粒 |

## 视觉语言 DNA（信息设计）

- **一镜一图一观点**：画面是"视觉助记"不是装饰——观众暂停截图这一帧，
  应该能只看图就复述出这一点讲了什么。做不到就重画。
- **视觉句式表**：观点是什么句型，图就用什么图式——这是本风格的核心翻译表：

| 观点句型 | 图式 | 正文写法示例 |
|---|---|---|
| A 与 B 不同 | 左右分屏对比 | `左右分屏：左侧灰色…，右侧金色…` |
| A 导致 B | 箭头链 | `三步箭头链：图标A → 图标B → 图标C，横贯画面` |
| A 占比惊人 | 放大数字 + 面积对比 | `中央巨大的"97.5%"，脚下是按比例缩小的人群剪影` |
| A 的内部结构 | 剖面示意图 | `建筑剖面图式，逐层标注的色块分区` |
| A 随时间变化 | 时间轴 | `水平时间轴，三个节点各立一个图标` |
| A 被放大细看 | 放大镜局部 | `画面主体旁一个放大镜圈出局部细节` |
- **受限色板纪律**：全片 2~3 色 + 中性底，写进 `style.palette`——信息图的"专业感"
  一半来自色板克制；每加一种颜色，可信度降一档。
- **数字可以直接画进图**（Seedream 中文渲染强）：`画面中央巨大的"97.5%"字样`。
  数字是本风格唯一该进画面的"字"——句子仍走字幕。
- 避免真实人物肖像；历史/公司题材用象征物（王冠/logo 形状的抽象几何）。
- **平面世界无摄影机**：本画风是平面设计不是摄影——不写焦段/光圈/景深/体积光
  （写了就把画风拽向写实），空间层次靠色块前后与大小对比表达。
- **抽象词兑现表**（写了左列的意图，正文必须落出右列的物理内容）：

| 想要的感觉 | 必须写出的物理内容 |
|---|---|
| 干净专业 | 2~3 色平涂 + 网格对齐 + 大面积留白 |
| 一目了然 | 单一视觉焦点 + 观点对应的图式（见视觉句式表） |
| 有分量的数据 | 数字放大为画面主体 + 面积/数量的可视对比 |
| 严肃权威 | 深色底 + 单强调色 + 几何构成（去掉圆角卡通感） |

## 分镜法则（讲清楚的结构）

8~14 镜，2~3s/镜，结构固定：
1. **钩子镜（≤3s）**：反常识结论先行——"你以为 X，其实 Y"或清单预告"三个原因，最后一个最狠"。
2. **路标镜**：一张总览图告诉观众"接下来讲什么"（完播率的保险丝）。
3. **分点镜 ×3~5**：每点 = 观点镜 + 事实镜（数字/案例可视化）。
4. **回收镜**：一句话总结回扣钩子。
5. **CTA 镜**：具体动作（"关注看下一个反常识"），别用万金油"点赞关注"。

## 提示词公式

正文三段式：**图式声明 + 元素逐件点名（含数字内容）+ 色板归属**：

- ✅ `极简信息图，左右分屏对比：左边灰色小人堆成的"多数人"，右边金色小人独立的"2.5%"，中央巨大百分比数字`
- ✅ `深蓝底信息图，水平时间轴横贯画面，三个节点各立一个白色线条图标：帆船、蒸汽机、芯片，当前节点用橙色高亮`
- ❌ `一个知识渊博的教授在讲课`（无信息、有肖像风险）
- ❌ `精美的科技感数据大屏`（"科技感"是评价不是图式；数据大屏是装饰不是助记）
- `negative_prompt` 常备：`伪3D立体效果, 写实照片元素, 复杂渐变阴影, 装饰性花纹, 真人面孔`
- `image_prompt_en` 取词：flat vector infographic / limited color palette /
  geometric shapes / editorial illustration / clean negative space / bold
  oversized number / diagram with arrows / subtle grain texture。

## 声音设计

- 旁白即节目：描述用词「解说男」（权威）「磁性解说」（沉稳）「悬疑解说」（事件复盘）——
  写进 `voice custom --narrator --prompt … --adopt 1` 定制立档，一个账号固定一把声音即品牌声纹；
  要官方模版音色再 `voice audition` → `voice use`。
- 语速可 +10（知识密度感）；BGM upbeat 低音量（字幕跟读为主）。

## 重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 画面与观点无关 | `重画为该知识点的示意图：用箭头链表达"输入→转化→输出"三步` |
| 信息图太花 | `压缩为两色配色+单一视觉焦点，去掉装饰性元素` |
| 数字不突出 | `把"73%"放大为画面主体，占画面1/2，其余元素弱化` |
| 出现伪3D/写实混入 | `回归纯平面矢量语言：平涂色块+几何形状，去掉立体渐变与照片元素` |
| 色板膨胀 | `收敛回全片色板的2~3色+中性底，多余颜色统一归入最近的板内色` |
| 图式选错 | `该观点是对比关系，改为左右分屏图式（参照视觉句式表重选）` |
| 数字/文字渲染错 | `数字"<正确内容>"作为唯一画面文字居中放大，其余文字元素全部去掉` |
