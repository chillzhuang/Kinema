# kn-game · 游戏画面（十一大风格总入口）

把内容做成**看起来像游戏**的视频：观众以为你在玩游戏，其实全是 AI 生成。
这是本仓库**最强叙事形态族**——游戏对话框天然解决"谁在说话"，像素/低模天然掩盖
AI 瑕疵，怀旧滤镜天然带情绪加成，HUD 一出现观众立刻进入游戏语境。
本 skill 的职责：**帮用户选对"哪一款游戏"，然后把那款游戏的味道执行到骨子里**。

## 直接启动整套流程（`/kn-game <故事/主题>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**——完整节点工作流（阶段0 建项目 →
   节点① 文案分镜 → ①.5 设定单+设定图 → ② 生图先首镜 → ③ 配音 → ④ 合成 → ⑤ 动态化）
   与全部铁律（产物落 project/、防烧钱、审阅闭环）。
2. **选定风格与机制**（见下《风格选择协议》）→ 建项目显式 `--profile <风格>` 并全流程
   绑定同一 profile：设定图/分镜图/封面每次生图都经该 profile 的 `style_prefix` 注入
   画风前缀，这是全片风格统一的机制保障；逐镜混风格仍走 `shots[].profile` 例外。
3. 默认横屏 16:9（游戏画幅天然横向）；竖版投放用 `--aspect 9:16`；渲染模式先 `a`(kenburns) 出片过审；动态化按风格表推荐。

## 风格选择协议

用户**点名了**（"八方旅人那种"/"我的世界风"/"像 Galgame"）→ 直接用对应 profile。
没点名 → **推荐缺省风格 `hd2d`（HD-2D，叙事泛用第一档），并在立项前一句话二次确认**
（立项唯一阻塞点：画风确认后由引擎快照进 `project.style_prompt`，全片生图统一取用）；
确认后开工，用户仍可 `project set --style-prompt` 换风重做。点名/换选时先定**机制**再定**画风**：

| Profile | 风格 | 机制 | 一句话 DNA | 最适题材 | 动态化 |
|---|---|---|---|---|---|
| `hd2d` | HD-2D | 叙事·对话框 | 像素精灵×3D微缩×体积光 | 武侠/奇幻/师徒小剧场 | c |
| `gba` | GBA 掌机像素 | 叙事·对话框 | 有限调色板+瓦片地图 | 童年回忆/轻快冒险 | c |
| `snes` | SNES 16-bit | 叙事·对话框 | 饱满像素+Mode7 伪3D | 王道 JRPG/时空史诗 | c |
| `dark_fantasy` | 暗黑奇幻像素 | 叙事·对话框 | 哥特冷调+火把幽光 | 恐怖/悬疑/黑暗童话 | c |
| `game_vn` | 视觉小说 | 叙事·对话框 | 半身立绘+唯美背景 | 恋爱/校园/悬疑推理/乙女 | c |

| `game_arcade` | 街机像素 | 实况/叙事皆可 | 粗壮精灵+CRT扫描线 | 格斗/对决/热血整活 | c |

**机制说明**：
- **叙事·对话框**：profile 已内置 `dialogue_box` 或适配字幕；`speaker` 填角色名驱动
  名牌+音色，像在玩游戏剧情。
- **实况·HUD**：`game_sim` 由特效层自动叠 `hud + scanlines`——**image_prompt 绝不画 UI**。
- **画面通用**：底部 caption 字幕，叙事/解说皆可；要对话框可项目级覆盖
  `"subtitle": {"mode": "dialogue_box"}`。

纯像素**动画**（无游戏语境，MV/氛围向）→ `kn-anime` 的 `anime_pixel`；动画非游戏 → `kn-anime`。

## 游戏叙事文法（叙事系共通，JRPG 过场的骨架）

**一镜 = 一个游戏画面 + 一句对白**，6~14 镜，节奏像逐句对话推进：
- 开场镜：广角建立镜头（场景全貌，无对白或旁白引入）——玩家"进图"的感觉。
- 对话交替用**过肩/正反打**：A 说话给 A 中景，B 反应给 B 近景，别两人同框到底。
- 每 3~4 镜插一个**反应镜**（惊讶后跳/流汗/头顶符号——游戏的夸张表情语言）。
- 高潮镜允许**特写 + 光爆/震屏语义**（image_prompt 写"身后金光大放"，video_prompt 写"光芒炸开"）。
- `speaker` 填角色名（驱动对话框名牌+音色）；旁白镜留空；`caption` 可空（对话框已显示台词）。
- **角色即音色**：按人设为每个角色写 `voice_prompt`（年龄段/音区/语速/气质），
  `character add --voice-prompt` 即定制立档、引擎写入 `voices` 表，全系列零漂移；
  要官方模版音色再 `voice audition` → `voice use`。
- **像素 / 视觉小说档的运动语法**：hd2d / gba / snes / dark_fantasy / pixel 类与
  game_vn 立绘同属**非摄影机的平面演出**——一拍二的顿挫感、止め絵（定格 + 摄影台缓推）、
  速度线与残像、发丝布料飘动这套 2D 作画语法完全适用，写法直接照
  `kn-anime/SKILL.md` 的《2D 作画运动语法》一节（**别在此重复维护第二份**）；
  其中像素档另加一条硬约束：**运动必须整像素步进，绝不写平滑亚像素位移**（会糊掉像素网格）。

## 实况文法（game_sim / arcade 实况向）

6~10 镜，快切，像精彩集锦：
- 开场=**任务触发**（过肩视角+目标在远处，旁白"系统提示：新任务"）→ 中段交替
  **探索移动镜**（追背跑动）/**遭遇镜**（正面对峙）/**技能镜**（特写+特效光）→
  高潮=**Boss 镜**（低角度仰拍巨大化对手）→ 结尾=**结算语义**（定格+旁白"成就达成"，
  CTA 顺势"点关注解锁下一关"）。
- 母题公式：**「现实事物 × 游戏化」**——任务弹窗、血条扣减、成就跳出，
  信息差与幽默感来自"游戏语法翻译现实"。

## 十一大风格视觉 DNA（写提示词前逐条内化）

### hd2d · HD-2D（八方旅人式"游戏录屏"）

**2D 像素精灵 × 3D 纵深布景 × 现代光效**，三者缺一就不像：
- 角色 16-bit 精灵质感、2.5~3 头身、硬边像素、JRPG 表演式夸张动作。
- 场景 3D 立体透视微缩布景（tilt-shift 移轴景深）：前景虚化遮挡+中景舞台+远景大虚化。
- 光：体积光/bloom 泛光/暖氛围光——黄昏/火把/晨雾是三大安全光源；粒子（樱瓣/尘埃/萤火）让静帧有"引擎在跑"的活感。
- ✅ `中景，徒弟猛地指着面前半透明发光的系统面板，扭头难以置信地看向师父`

### gba · GBA 掌机像素（硬件限制即美学）

- **调色板穷**：单屏低色数大色块平涂，**无渐变无泛光**（有 bloom 就穿帮）；光影用亮/暗两阶色块。
- 硬边 1px 轮廓+点阵抖动过渡；角色 2 头身 Q 版，表情靠头顶符号（！？💧）。
- **瓦片地图感**：tile 拼接的俯视/侧视平面，**没有 3D 纵深**（与 HD-2D 的最大区别）。
- 机位只用三种：俯视全景 / 侧视对话 / 头像特写；运动要小（原地小跳/轻微震屏）。
- ✅ `俯视45°瓦片地图，像素小人徒弟在石阶下方原地跳了一下，头顶冒出感叹号`

### snes · SNES 超任 16-bit（像素美术巅峰期）

- 比 GBA 富裕、比 HD-2D 复古：饱满调色板、细腻像素渐变、大型精灵与多层卷轴视差。
- Mode7 伪 3D 允许"地图旋转俯冲"语义的空镜；光效是像素化的放射线与闪白，不是柔光。
- 超时空之轮/FF6 的审美基准：史诗感构图+细腻像素云海/星空。

### dark_fantasy · 暗黑奇幻像素（恐惧靠氛围）

- 哥特低饱和冷调、火把幽光、高对比明暗、血色点缀；Blasphemous/暗黑地牢参照系。
- 完播靠"下一秒会发生什么"：阴影里的轮廓、半开的门、烛光外的黑暗。
- profile 自动叠 `vignette + film_grain`；对话框血红名牌深底。

### game_vn · 视觉小说（立绘的情绪艺术）

- **立绘构图铁律**：角色半身立绘居画面中下（对话框上方），背景独立成景——
  一镜=一张"立绘×背景"组合；换情绪=换表情姿态，不换构图语法。
- 背景是第二主角：教室黄昏光、雨夜站台、樱花坂道——色温直接写情绪
  （暖橙=心动、雨青=压抑、夜紫=悬疑）。
- 表情精度是本风格的"经费"：image_prompt 写到眉眼（`垂眸浅笑`、`瞳孔微缩`、`别开视线耳尖泛红`）。
- 空镜价值高：每 3~4 镜插一个无人景物镜（风扇/晃动的窗帘/远去的电车）承载内心独白。
- ✅ `半身立绘构图，黑长直少女站在黄昏教室窗边，逆光轮廓金边，垂眸浅笑欲言又止，身后窗外晚霞与飞鸟`

### game_isometric · 等距 CRPG（上帝视角的史诗）

- **45° 等距投影**是唯一机位语法：地城/城镇的精细俯瞰，角色微缩于宏大场景。
- 光即叙事：火把与法术是场景里的点光源，投出戏剧性长影；暗色油画质感打底。
- 人物小 → 表演靠**场面调度**（队伍列队推进/敌群从四门涌入/法阵在地面亮起）。
- 旁白是 DM（地下城主）腔：深沉念白推动，对白进羊皮纸文本框。
- ✅ `等距45°俯瞰，四人小队举着火把穿过哥特地城长廊，火光在石柱间投出摇曳长影，前方黑暗中一对红眼亮起`

### game_sim · 实况 HUD（3A 引擎渲染）

- UE5 式实时渲染：PBR 材质反光、屏幕空间反射、体积雾光柱——比写实"干净"、比动画"立体"。
- **第三人称过肩追背**是游戏感第一签名（角色背影占左/右下 1/3，目标在纵深处）。
- **HUD 由特效层自动叠**（`hud + scanlines`）——image_prompt 绝不画血条/地图/文字 UI。
- 关键物品写"发光描边"（游戏的可交互高亮语言）。

### game_ps1 · PS1 复古低模（低保真恐惧）

- **低模纪律**：粗糙低多边形角色、硬直棱角轮廓、低分辨率贴图的扭曲颗粒感——
  "看不清"就是恐惧的来源，脑补比高清更吓人。
- 浓雾与黑暗吞没视距（当年是机能限制，如今是氛围武器）；顶点光照的生硬明暗。
- **固定机位语法**：诡异的高角度俯视/门缝视角/走廊尽头凝视——生存恐怖的镜头传统；
  运动只用慢横移与缓推。
- profile 自动叠 `film_grain + vignette + fog`（VHS 三件套）。
- ✅ `固定高角度俯视，低多边形的走廊尽头站着一个轮廓模糊的人形，浓雾吞没走廊另一端，低分辨率贴图的墙面颗粒扭曲`

### game_voxel · 体素方块（数字乐高）

- 一切由立方体构成：方块地形分层、体素树木云朵、立方体雨滴——**圆的东西是穿帮**。
- 明快高饱和方块色板+柔和方向光与方块投影；建造过程感（一层层垒起/一块块拆除）
  是本风格的招牌运动语义。
- 俯瞰大世界与贴地方块视角交替，尺度反差出奇观。
- ✅ `俯瞰体素小镇，方块屋顶铺满白雪，体素炊烟一格一格升起，远处方块群山与像素化的落日`

### game_celshade · 卡通渲染开放世界（旷野的呼吸）

- cel-shading 三要素：清晰描边轮廓+平涂色阶+风格化光（塞尔达旷野之息参照系）。
- **旷野语法**：广袤草原被风压出波浪、远山与风格化积云、山顶眺望构图——
  "想去远处那座山"的开放世界情绪。
- 运动写探索动词：奔跑/攀爬/滑翔/驻足眺望；`bloom` 由 profile 自动叠。
- ✅ `广角，卡通渲染的少年立于山崖边眺望，描边清晰的草原在脚下延展成绿海，远处风格化积云投下缓慢移动的云影`

### game_arcade · 街机像素（机厅的黄金年代）

- 粗壮有力的**大型像素精灵**（比 JRPG 精灵大一号，肌肉与轮廓夸张）、动作定格的打击感姿态。
- 高对比霓虹街头：涂鸦墙/夜市招牌/机厅灯光；饱满浓烈的街机调色板。
- 侧视横版卷轴构图是默认机位；对决用**双雄对峙侧构图**（左右各据一边）。
- profile 自动叠 `scanlines + vignette`（CRT 显像）；KO/连招定格是招牌镜。
- ✅ `侧视横版构图，两名粗壮像素格斗家在霓虹夜市街头对峙定格，左侧角色摆出出拳蓄力姿态，背后涂鸦墙与闪烁的机厅招牌`

## 提示词公式（全风格共通）

`image_prompt` 只写**这一镜不同的**：机位 + 角色动作/表情 + 该镜专属道具（风格/场景/外貌由引擎前置）：
- ❌ `HD-2D风格像素少年在山门庭院里说话`（风格重复、场景重复、无表演）
- ❌ `画面里有血条和小地图`（UI 是特效层的事，画了会重复叠加）
- ⚠️ **点名的道具若已建设定图，用其设定集 `name` 措辞（或给 prop 配 `keywords`）点名——引擎按 `design_refs`（显式 `shots[].props` ∪ image_prompt/narration 文本命中）
  自动挂该道具设定图保持跨镜一致；措辞与注册名不符/重名时，本镜显式挂 `"props":["道具名"]` 兜底，
  否则模型会瞎编道具外观（水杯魔王变陶瓷杯类事故）。**

`video_prompt` 只写运动，**一律 slow/smooth**（快速运镜必劣化）：
- ✅ `师父捋须的手轻抬，衣袖微动，花瓣飘过` / `镜头从背后缓缓推向角色肩部`

## 声音设计

- 叙事系角色对白按人设写 `voice_prompt`，`character add --voice-prompt` 即定制立档；
  旁白 `voice custom --narrator --prompt … --adopt 1`，描述用词建议（写进 `--prompt`）：
  hd2d/snes→「儒雅旁白」，gba→「温柔文雅（-10 语速）」，dark_fantasy/ps1→「悬疑解说」，
  vn→「纯真少女/温柔学长（内心独白多，emotion 随剧情标注）」，isometric→「醇厚低音（DM 念白）」，
  sim/arcade→「解说男/热血少年（高能量，+10 语速）」，voxel→「开朗弟弟」，celshade→「清爽少年」。
- BGM 情绪已按 profile 配置；ps1/dark_fantasy 的环境音（脚步/风声/低鸣）与
  celshade/voxel 的自然音用 `b`(native) 让模型原生生成最佳。

## 重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 角色不像同一人 | `严格按角色设定图的发色/服装绘制，不得改变配色` |
| 不够"游戏感" | 按风格给：hd2d`增强像素颗粒与移轴微缩景深` / sim`增强PBR反光与体积雾光柱` / ps1`降低模型面数，贴图更粗糙，加浓雾` |
| 画风串味 | `严格回归<风格名>体系：<该风格 DNA 的 2-3 个关键词>，去掉<混入元素>`（如 gba 出现渐变泛光/voxel 出现圆形物体/vn 立绘构图跑偏） |
| 画了假 UI | `画面中不要绘制任何血条/地图/对话框/文字 UI，界面由后期叠加` |
