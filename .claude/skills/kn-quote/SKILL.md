# kn-quote · 语录 / 励志 / 治愈

**一句金句 × 一个唯美画面**。收藏率之王——观众存下来当壁纸/发朋友圈，
算法把收藏权重给足。成本最低的量产格式，胜负全在**文案质感**与**画面留白**。

## 直接启动整套流程（`/kn-quote <主题/情绪>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律）。
2. 全程 `profile=quote`；无角色，`--skip-design` 跳过设定集。
3. 默认竖屏 9:16（收藏向主场），立项汇报交代画幅；动态化不需要（a 模式 + 缓推即高级）。

## 类型定位（收藏向逻辑）

- 收藏的心理是**"这说的是我"**：金句要具体到场景（"凌晨两点改完第七版方案的你"），
  不要抽象口号（"努力就会成功"没人收藏）。
- 一条视频一个情绪主题（释怀/坚持/告别/自洽），4~8 句层层递进，最后一句最狠。
- 署名规则：真实名人名言必须核实出处；原创文案署账号名或不署——**绝不伪造名人语录**（失败高发区）。

## 工业参照（取词库）

| 面向 | 参照 | 可直接入词的术语 |
|---|---|---|
| 留白构图 | 极简主义摄影 · 日式侘寂 | 负空间占 2/3 · 地平线压在下 1/3 · 单一小主体 · 视觉重心离心 |
| 氛围光 | 风光摄影的 blue hour / golden hour | 破云光柱 · 薄雾漫射 · 逆光剪影 · 水面碎金 · 暖黄窗光一格 |
| 质感底 | 高级印刷品的哑光语感 | 细腻胶片颗粒 · 低对比柔和渐变 · 雾面质感 |
| 情绪色 | 电影调色的单色倾向 | 近单色蓝灰 · 低饱和暖橘 · 大光比黑金 |

## 视觉语言 DNA（留白美学）

- **画面是文字的背景板**：中央 60% 必须"安静"（天空/海面/雾林/窗光/纯色渐变），
  视觉重心压在上 1/3 或下 1/3，给居中大字让位。文字区之外才是画面的领地——
  构图先给字留位，再摆主体。
- **三档色调是三套完整色板规则，不是三个滤镜**。选一档写进 `style.palette`
  全片统一（换色调 = 换账号视觉），每档的底色域/强调色/光源逻辑都要成套走：

| 档 | 底色域 | 强调色 | 光源逻辑 | 适配情绪 |
|---|---|---|---|---|
| 暖橘治愈 | 奶油白 · 浅杏 | 落日橘（仅一处） | 黄金时刻逆光 / 暖窗光 | 治愈 · 感恩 · 陪伴 |
| 蓝灰释怀 | 雾蓝 · 青灰 | 无（近单色） | 阴天漫射 / 破晓 blue hour | 释怀 · 告别 · 孤独 |
| 黑金高级 | 炭黑 · 深灰 | 暖金（一线光） | 大光比单一光源 | 坚持 · 野心 · 深夜 |

- 有人时只要**背影/剪影/远景小人**（"我"的投射对象，不能有清晰五官——五官会排他）。
- **质感底破廉价感**：图库感的来源恰是"太干净的渐变"——纯色/渐变底补一层
  细腻颗粒与雾面语感，画面立刻从"素材"变"作品"。
- **一处强调色纪律**：全画面只允许一个强调色落点（一盏灯/一线夕阳/一把伞），
  两处以上视线就开始打架，字的地位被抢。
- 字幕系统自动居中大字 + 金色署名斜体（`subtitle.mode=centered`），文字质感引擎兜底——
  **画面里绝不再画字**。
- **抽象词兑现表**（写了左列的意图，正文必须落出右列的物理画面，光写左列无效）：

| 想要的感觉 | 必须写出的物理内容 |
|---|---|
| 空灵 | 薄雾漫射 + 大面积留白 + 低对比 |
| 治愈 | 暖光有明确落点（窗台/杯沿/肩头）+ 柔和渐变天空 |
| 高级 | 大光比 + 单一光源 + 近单色低饱和 |
| 孤独 | 远景小人 + 尺度悬殊的空间（海/天/楼群）+ 冷色域 |

## 分镜法则

4~8 镜，一镜一句，5~7s/镜（给阅读+回味时间）：
- 句子节奏：**场景句开场**（"凌晨的城市…"）→ 递进 2~3 句 → **反转/释怀句收尾**。
- 字段：金句放 `narration`（TTS 朗读+居中显示）；署名放 `attribution`。
- 画面随句子情绪走：压抑句配阴天车窗，释怀句配破云光——**画面亮度曲线=情绪曲线**，
  最亮的一镜留给最后一句。
- 收尾镜是收藏动作发生的地方：全片最空、最美、字最狠的一张放最后。

## 提示词公式

正文四段式：**场景与小主体 + 光的来向与落点 + 色调归属 + 留白位置**，
控制在一句 60~120 字（画面越空、词越少越对）：

- ✅ 蓝灰：`远景，清晨薄雾的海面，一个小小的背影坐在防波堤上，画面上2/3是留白的天空，蓝灰色调`
- ✅ 暖橘：`中远景，黄昏的窗台上一杯冒着热气的茶，落日余晖把窗框内侧染成暖橘，画面左2/3是柔和渐变的墙面留白，低饱和`
- ✅ 黑金：`大远景，深夜天台边缘一个剪影，身后唯一一盏暖金色路灯照亮雨后地面的反光，四周沉入炭黑，大光比`
- ❌ `一个悲伤的女孩哭泣的特写`（五官排他+画面太满没处放字）
- ❌ `唯美意境的风景`（"唯美"是评价不是画面——写雾、写光的落点、写留白在哪）
- `negative_prompt` 常备：`清晰人脸, 画面拥挤, 高饱和艳丽, 文字水印, 多个光源`
- `image_prompt_en` 取词：negative space / muted palette / soft diffused light /
  lone silhouette / fine film grain / minimalist composition / atmospheric haze /
  single warm light source。

## 声音设计

- 音色描述用词：「治愈女」「温柔文雅」「磁性男嗓」，语速 -15~-20（一字一顿才有分量）；
  写进 `voice custom --narrator --prompt … --adopt 1` 定制立档为账号声纹，要官方模版音色再
  `voice audition` → `voice use`。
- BGM calm（钢琴/氛围），音量压低——句与句之间的静默是设计的一部分。

## 重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 画面太满压字 | `中央60%留白，主体缩小移至下1/3，天空占画面2/3` |
| 出现清晰人脸 | `人物改为背影剪影，不得出现五官` |
| 色调不统一 | `统一为蓝灰释怀色调，去掉暖黄元素` |
| 太像图库照片 | `增加雾气与光晕的氛围层次，补细腻胶片颗粒，画面更空灵` |
| 渐变底廉价 | `底色加雾面质感与细腻颗粒，降低对比，去掉塑料感的光滑渐变` |
| 光没有情绪 | `光源收敛为一处并给明确落点（窗台/肩头/水面），其余沉入低亮度` |
| 强调色打架 | `只保留一处强调色落点，其余统一回底色域` |

## 何时不用

要讲道理 → `kn-explainer`；要故事 → `kn-storybook`；要盘点 → `kn-ranking`。
要的是"氛围场景陪伴"而非"金句卡"（无文字主体、纯环境音）：本 skill 去掉金句字幕、
章节顶层写 `voiceover: none` 并点名天气特效即可，不必换 skill。
