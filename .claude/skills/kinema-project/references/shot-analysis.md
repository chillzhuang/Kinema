# shot-analysis · 参考片拉片工法（3.7 参考片立项模式的读片手册）

> 引擎半（`study` 命令族）只交数：切点全表、逐镜时长清单、静音区间、等间隔抽帧、
> `rhythm` 汇总。本文件是**你（指挥层）那一半**的工法——怎么把这堆数字和帧读成
> 一份能指导立项的节奏结论。motion 判定规则表、算账口径、反照抄两栏表、版权铁律
> 都在 SKILL「3.7 参考片立项模式」，本文不重复；这里只管**读的过程**。

## 一、读片顺序（五步，顺序不换）

1. **先读 `rhythm` 汇总**（cuts_per_min / avg·min·max_shot_sec / silence_ratio /
   media 时长分辨率）——先建立全片体感，再进细节。silence_ratio 为 `null` 是
   「无音轨」不是「零静音」，两者结论完全不同，别读混。
2. **抽帧归镜**：把 `frames/` 的每一帧按时刻归进 `shots` 逐镜清单的所属区间
   （帧时刻落在哪个 `[start, end)` 就属于哪个镜）。归完才有"这一镜长什么样"的
   证据底座——跳过这步直接看图，读出来的是幻灯片不是片子。
3. **切点复核**（第二节）——场景检测有已知误报源，表载切点不等于真切点。
4. **逐镜记录**（第三节口径）。
5. **输出结论**：节奏骨架 + 两栏表 + motion 判定与算账（格式与铁律回 SKILL 3.7）。

## 二、切点复核（引擎会错在哪，你怎么核）

场景检测按帧间差分打分，有四类**已知误报**：爆闪/闪光（亮度突变≠换镜）、前景
大物横穿遮挡、快速摇镜的中间帧、曝光突变（进出隧道/开关灯）。核法：切点两侧的
帧若**同景同机位**、只是亮度或遮挡不同，就是同一镜——从你的镜数结论里合并掉。

反向还有三类**已知漏报**：叠化与渐隐（缓变不过阈值）、匹配剪辑（前后构图相似）、
甩镜藏切。核法：相邻两帧**景别或场景明显不同**而切点表里没有对应切点，就是漏切
——往你的结论里补。

两条纪律：
- **digest 是引擎产物，不改**。复核只修正你自己的镜数结论，读片笔记里记一行
  「表载 N 切，人核约 M 镜（合并 x 处爆闪误报，补 y 处叠化漏切）」。
- 抽帧密度不够看不清切点两侧时，`study import` 同 slug 加 `--frames` 重导
  （幂等重算，旧目录整体替换），别对着模糊证据硬判。

## 三、逐镜记录口径

- **时间码**：区间前闭后开 `[start, end)`；首镜从 0 起、相邻镜首尾相等、末镜
  收在总时长；全篇同一精度（0.1s 足够）。抽帧间隔摆在那里，**绝不伪造逐帧级
  精度**——写 12.3s 可以，写 12.34s 就是编的。
- **每镜四件套**：景别（按 `kinema/references/storyboard.md` 的 12 档对照表归档）/
  机位角度（平视/俯/仰/鸟瞰/荷兰角）/ 运镜（同镜两帧的构图位移方向推断：主体变大
  =推近、背景平移=横移；推断不出就记**疑似**或**无法判定**）/ 画面事件（一句话，
  只写"发生了什么类型的事"）。
- **证据纪律（本文件的脊柱）**：只记帧里**看得见**的。同镜两帧之间的运动方向可以
  推断（标"疑似"），剧情因果不许推断；「疑似」「无法判定」原样进结论——**诚实的
  空白比编造的完整值钱**，它还告诉你哪里该加密抽帧。
- **声音侧**：你读得到帧，**读不到音轨**。声音证据只有两件：digest 的静音区间
  （哪些段落有声/留白——这就是配音节奏骨架）与外挂字幕（`--subs` 导入时，按字幕
  时间轴记台词密度）。没有字幕就只记有声/静音分布，**绝不按口型、构图或剧情去猜
  对白内容**——猜出来的"台词节奏"会把整个 motion 判定带偏。

## 四、从记录到结论（交付物形状）

- **节奏骨架**：开场/中段/收尾的镜长分布（前 10s 是否切得更密）、最长镜与最短镜
  各在哪、静音呼吸位落在哪几处——这三条就是"参考片好看在哪"的可迁移部分。
- **两栏表**（保留什么 / 必须改什么）：格式与四行底线在 SKILL 3.7 反照抄铁律，
  缺一栏不许进节点①。
- **motion 判定 + 镜数 + 成本量级**：判定规则表与单价口径在 SKILL 3.7；把「疑似/
  无法判定」的条目原样留在结论里，一句人话交用户确认。

## 五、禁区（与 SKILL 3.7 版权铁律同一条根）

- 记录只到「景别/机位/节奏/事件类型」这一层，**不到**「人物长什么样/台词原文/
  美术细节」那一层——逐镜临摹式的记录本身就是抄内容，哪怕一个字都没进提示词。
- 参考片与抽帧不进任何生成请求、不做垫图、不进 `shots[].refs`、不进交付目录；
  读完出结论即 `study rm`。这四条引擎有守卫，但第一道闸是你落笔的那一下。
