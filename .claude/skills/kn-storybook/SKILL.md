# kn-storybook · 绘本 / 睡前故事

**像翻一本水彩绘本那样讲故事**。亲子/睡前是刚需场景（每晚都要新故事），
用户忠诚度极高；寓言外壳也常被成年人转发（"讲给孩子，说给自己"）。

## 直接启动整套流程（`/kn-storybook <故事/主题>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律）。
2. 全程 `profile=storybook`；**主角设定图必做**（绘本主角 IP 是复购的核心——
   节点①.5 至少给主角出设定图（三区两视））。
3. 默认竖屏 9:16，立项汇报交代画幅；动态化可选 `c`(dubbed)——水彩画面的轻微动画（衣角/树叶）非常加分。

## 类型定位（睡前内容的纪律）

- **目标是让孩子睡着**：节奏必须递减——开头轻快、中段舒展、结尾一句比一句慢；
  绝无 jump scare、无冲突升级到吓人（狼可以坏，但不能可怕）。
- 结构走**寓言弧**：小主角 + 一个小缺点/愿望 → 三次尝试（三段式是儿童叙事铁律）→
  温柔的领悟 → 晚安句收尾（"月亮说，该睡了"）。
- 家长是买单人：结尾一句给家长的"寓意"（不说教，一句即可）。

| 面向 | 参照 | 可直接入词的术语 |
|---|---|---|
| 水彩工艺 | 童书插画的透明水彩传统 | 湿画法软边晕染 · 透明色层叠加 · 纸纹肌理 · 边缘留白呼吸 |
| 造型语言 | 低龄绘本的圆形语法 | 一切去尖角 · 2 头身 · 圆头圆手 · 简笔表情（弯眼/一滴泪） |

| 安睡色温 | 童书夜景的处理惯例 | 深蓝夜空 + 暖黄窗光/灯笼 · 奶油黄/藕粉/薄荷绿低饱和 |

## 视觉语言 DNA（水彩绘本美学）

- **水彩质感三件套**：湿画法的软边晕染、透明色层的叠加透光、纸纹肌理与留白——
  profile 前缀自带基调，正文写的是**这一页哪里晕开、哪里留白**；
  提示词别写"精细渲染/锐利细节"（数码感一进来，水彩就死了）。
- **暗部纪律（水彩的命门）**：水彩的暗不是黑——夜晚森林是**深蓝里透着群青**，
  影子是**偏紫的蓝**；写"深蓝色的夜"永远对，写"黑暗/阴影笼罩"必出脏黑。
- **圆润造型**：一切造型去尖角（云是棉的、树是团的、狼也是圆的）；主角 2 头身，
  表情简笔但明确（弯眼=开心，一滴泪=难过）。
- **暖色温**：奶油黄/藕粉/薄荷绿低饱和；夜晚场景用**深蓝+暖黄窗光**（不是黑）。
  `warm` 特效由 profile 自动叠。
- 每镜像**一页跨页插图**：单一情节点、大面积留白、视线动线从左到右（翻页感）。
- **绘本世界无摄影机**：不写焦段/光圈/景深/体积光（写了就把画风拽向 3D 写实）——
  空间层次用绘本自己的语言：近大远小、远景淡成一抹水痕、主体细笔背景晕染。
- **抽象词兑现表**（写了左列的意图，正文必须落出右列的物理内容）：

| 想要的感觉 | 必须写出的物理内容 |
|---|---|
| 温暖 | 暖黄光源有落点（窗/灯笼/萤火）+ 奶油色域 + 大留白 |
| 安心 | 圆润轮廓 + 低饱和 + 主角与依靠物的接触（抱着/靠着/盖着） |
| 夜而不怖 | 深蓝透群青的夜空 + 一处暖光 + 星星/月亮在场 |
| 手绘感 | 湿边晕染 + 纸纹肌理 + 边缘留白（而不是"手绘风格"四个字） |

## 分镜法则（一页一情节）

6~12 镜，4~6s/镜（旁白慢，画面停留要够）：
- 开场镜=主角亮相（姓名+特点一句话："小刺猬阿团，最怕黑"）。
- 三段尝试各 1~2 镜；领悟镜给最柔的光；**晚安镜收尾**（主角睡着+月亮/星星）。
- `speaker` 通常不填（全程旁白）；角色对话写进 narration 用引号（"妈妈说：'别怕'"），
  由同一位讲述者演出来——**绘本是"一个人讲的故事"**，不是配音剧。
- 画面亮度曲线随节奏递减：开场最亮，晚安镜只剩一窗暖光与星空。

## 提示词公式

正文四段式：**跨页构图声明 + 主角与情节点 + 光与色 + 留白位置**：

- ✅ `跨页水彩插画，小刺猬抱着一盏萤火虫灯走进深蓝色的夜晚森林，暖黄光晕照亮脚下小路，大面积留白`
- ✅ `跨页水彩插画，小刺猬把最后一颗浆果分给小田鼠，两团圆滚滚的身影坐在蘑菇伞下，藕粉色晚霞晕染天空，画面右侧留白`
- ✅ 晚安镜：`跨页水彩插画，小刺猬蜷在树洞里睡着了，洞口一弯暖黄色月亮和两三颗星星，深蓝夜色柔和晕染，大面积留白`
- ❌ `恐怖的黑暗森林里狼在嚎叫`（吓人违规+脏黑暗部）
- ❌ `皮克斯3D渲染`（画风打架）❌ `85mm浅景深特写`（绘本世界无摄影机）
- `negative_prompt` 常备：`3D渲染, 锐利数码边缘, 黑色阴影, 恐怖氛围, 写实人体比例, 尖锐造型`
- `image_prompt_en` 取词：children's picture book watercolor / wet-on-wet soft
  edges / transparent washes / paper texture / rounded shapes / warm lamplight /
  deep blue night sky / generous white space。

## 声音设计

- 讲述者描述用词：「绘本女」「温柔长辈」「和蔼奶奶」，语速 **-20**，`speech_rate` 全片统一；
  写进 `voice custom --narrator --prompt … --adopt 1` 定制立档，要官方模版音色再
  `voice audition` → `voice use`——孩子认声音，换声=换账号。
- BGM calm 音量极低；结尾两镜 BGM 淡出只留旁白（哄睡的收束）。

## 重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 画风变精细/3D | `回归手绘水彩：湿边晕染+纸纹肌理+大面积留白，去掉3D光影` |
| 主角走形 | `严格按设定图：小刺猬圆形轮廓+奶油色肚皮+红色围巾` |
| 夜景太黑太吓人 | `夜晚改为深蓝透群青色调+暖黄窗光/灯笼光，整体柔和不阴暗` |
| 画面太满 | `保留单一情节点，四周留白30%以上，构图如绘本跨页` |
| 暗部发黑发脏 | `暗部改为偏蓝紫的透明色层，去掉纯黑，保留纸的透光感` |
| 造型出尖角 | `全部造型圆润化：云是棉团、树冠是圆团，去掉锐利边缘与棱角` |
| 表情太复杂 | `表情回归简笔语法：弯眼表示开心、一滴泪表示难过，去掉写实五官` |

## 何时不用

成人向暗黑童话 → `kn-game`（dark_fantasy）；知识 → `kn-explainer`；游戏感叙事 → `kn-game`；
凯尔经式平面美术动画（要"动起来的绘本动画"而非"翻页绘本"）→ `kn-anime` 的
anime_fairytale 画风；水墨气韵 → `kn-anime` 的中式水墨。
