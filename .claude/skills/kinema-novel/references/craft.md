# craft · 一章怎么搭（每章写正文前读）

本文件只规定**功能**与**核对形式**（怎么知道这条做到了），**不规定配额**——不写「接占
15%」「每章至少 N 个新专名」这类硬指标：配额本身会变成新的套路，和「每章都用格言收尾」
是同一种病。四拍可以交错、可以某一拍占掉大半章，只要各自的功能都成立。

## 一章四拍：接 / 推 / 转 / 钩

| 拍 | 这一拍要办成的事 | 核对形式（一句话回答得出才算做到） | 坏形态 |
|---|---|---|---|
| **接** | 用一个**具体动作或实物**接住上一章的尾钩 | 遮住上一章，本章第一句仍是**正在发生的动作**或**看得见的东西** | 摘要句开场：「经过昨晚的事」「自从那天起」「他想起昨晚」 |
| **推** | 本章目标遭遇阻碍，且**至少升级一次** | 能指出一处「**比进来时更糟或更复杂**」，并说出是哪一句让它变糟的 | 阻碍被一次性解决；或来回拉扯但离场时局面与进场时相同 |
| **转** | 局面翻面：他手里的牌变了 | 一句话说出「**这一章他没拿到的是什么**」 | 全拿到了（爽而无势）；或什么都没发生，只是过场 |
| **钩** | 把读者交给下一章 | 见下方「删尾测试」 | 情绪落地之后再补一句格言／总结 |

**接**：第一句禁止摘要句——摘要是写给自己的备忘，读者要的是继续看戏。上一章尾钩的东西
（那把刀、那扇门、那句话）在本章**前 3 段内**必须出现或被处理（见 §断章七型 的回应纪律）。

**推**：升级有四种可数的形态，任选其一即可交差——**代价出现**（赢一步赔一样）·**新情报
翻案**（原以为的前提错了）·**新势力入场**·**时限缩短**。"升级"必须能落到具体的一句上；
说不出是哪一句，就是氛围写得像升级、其实没升级。

**转**：三种合法形态，都能回答"没拿到什么"——① 被挡住（没拿到）② 拿到了但代价超预期
③ 拿到了，但拿到的东西不是他以为的那个。**转之后的反应—两难—决定**（他怎么受、他被夹在
哪两难之间、他决定怎么办）在中文长篇里通常放到**下一章的「接」**，不必挤在本章尾——这正是
下一章第一句能写成具体动作的原因。

**钩**：只占最后 **150~300 字**，断在**高潮前一秒**——门开了但还没看见谁站在门外；不是等
情绪落地、把话说圆之后再收。
**删尾测试**（核对形式）：删掉最后一段再读——若这一章反而更完整，说明钩子是赘尾，删了它换一个
断点；若明显缺一口气，钩子成立。

## 断章七型

正面清单，取代「章末必金句」。**声明后引擎才查得动**：`novel save` 时带 `--hook`。

| 型 | 范式（一句） | 反例 |
|---|---|---|
| **决定** | 做出一个不可撤回的选择**并付诸动作**：他把自己的名字写了上去 | 只写「他终于下定了决心」，不写他做了什么、赔了什么 |
| **发现** | 一个改变已知格局的实物或信息进入视野：名单最后一行是他自己 | 发现的东西读者早就知道——那是补课不是钩 |
| **误判** | 角色给出一个**读者看得出是错的**结论并据此行动 | 误判在本章内就被纠正（张力当场泄掉） |
| **代价** | 目标达成的同一秒收到账单：赢了，但那条线断了 | 代价是抽象的「他心里空落落的」 |
| **险境** | 具体威胁进入可触距离，且**退路被切断** | 泛化的「危险正在逼近」，没有具体的东西在靠近 |
| **逼近** | 距离缩短**一格且这一格可量**：三天变成今晚 | 只喊「时间不多了」，前后两章的余量其实一样 |
| **错位** | 读者知道而角色不知道：读者已经看见门后站着谁 | 需要作者跳出来解释才成立的错位 |

**两条纪律**

1. **同型不得连用 3 章**——声明 `--hook` 后引擎自动查 `hook_monotone`，`novel lint` 报出来。
2. **上一章的钩必须在本章前 3 段有回应**。回应 ≠ 解答：被反应、被打断、被推迟都算，唯独不许
   装作没发生。核对形式＝读本章前 3 段，能圈出一句直接指向上一章钩子的文字。

**改钩工法：钩不行只动最后 150~300 字，不重写整章。** 换型优先于加戏——多数时候把断点往前
挪半页就到位；整章重写会连带作废已登记的 digest / state / 伏笔账，代价不成比例。

```bash
cd engine
python3 -m kinema novel save <pid> --no 67 --file ch0067.md --title "…" --hook 误判
python3 -m kinema novel save <pid> --no 67 --file ch0067.md --hook 险境   # 改完同章号重登记，旧稿自动进版本栈
python3 -m kinema novel reindex <pid> --no 67                            # 只在磁盘稿上改了几行时重算指纹
python3 -m kinema novel lint <pid> --from 61 --to 70 --level warn        # 看 hook_monotone 有没有报
```

不重登记的后果是 `novel lint` 报 `manuscript_drift`（正文改了没登记），批次也就不算写完。

## 对白三步

**步① 开口前先写三件套**（不写进正文，写在草稿旁）——每个要开口的人各一份：

| 三件套 | 取自 | 取不到就当场补登记 |
|---|---|---|
| 他这一章**要什么**（场景目标，可以与全局目标不同） | `personality` + `arc` 的**当前阶段** | `character set --personality` / `--arc` |
| 他**不能说什么**（硬禁区 + 他知道而别人不知道的事） | `taboo_lines` + 上一章 `state` | `character set --add-taboo` |
| **句长与词域**（长句还是短句、书面还是市井、口头禅） | `speech_style` | `character set --speech-style` |

```bash
cd engine
python3 -m kinema novel brief <pid> --chars 陆昭,燧      # 只取这场戏在场者的人设卡
python3 -m kinema character show <pid> --name 燧         # 单人复核，省 token
python3 -m kinema character set <pid> --name 燧 \
  --speech-style "短句·军令腔·从不用比喻" --add-taboo "绝不解释自己的动机"
```

**取不到就不许硬写**：人设卡不全时，人设门的盲测在物理上是空转的——遮住名字也没有判据可比。
核对形式＝这场戏每个开口的人，你都能当场说出他的三件套；说不出的那个人先补登记再写。

**步② 有隐瞒 / 试探 / 示弱的对白，先写「字面 vs 意图」两行对照**（写完删掉，不进正文）：

```
字面：我没事。
意图：别再问了，再问我就撑不住。
```

两行**一样**即 on-the-nose（把心里话直接说出口）。三个改法：换成**动作**（他把杯子挪开）·
**沉默**（不答，起身去关窗）·**答非所问**（"你吃饭了没有"）。

**步③ 写完就地盲测三句**：随手挑三句台词遮住说话人，问自己"这是谁说的"。答错或答不出，说明
这句只是信息、不是这个人说的话——改法是加他的**句长／词域／禁区**其中一项，而不是加语气词。
核对形式＝三句里至少两句能凭口吻认出人。

**本节收口核对形式：一章里至少有一场对白的字面与意图不一致。** 全员有话直说不是对白，是问答。

## 开篇三章（只在开新书时用）

用**读者预期问题**验收——读完这一章，读者心里该冒出的是哪个问题：

| 章 | 读者应该问 | 答不上来说明 | 修法 |
|---|---|---|---|
| 1 | 他接下来怎么办？ | 没给出一个**必须马上应对**的麻烦 | 把麻烦提到最前，世界观往后挪 |
| 2 | 为什么比想象中更难？ | 阻力只是第 1 章那堵墙又来一次 | 换一种阻力（人／规则／他自己），或让代价第一次显形 |
| 3 | 后面能看到什么？ | 只有眼前困境，没有纵深 | 露出更大的对手或一条长线伏笔（`novel thread-add --tier mid` 或 `long` 当场记账） |

**钩子的递进方向是更贴身，不是更炸**：

| 方向 | 从 → 到 |
|---|---|
| 风险具体化 | 「世界要毁灭」→「今晚要交出他的名字」 |
| 关系贴身化 | 陌生人的死 → 他必须依赖的那个人的死 |
| 选择不可撤回 | 还能反悔 → 做过就回不去 |

核对形式：把三章的钩子并排写成三句话，看是否**一句比一句离主角更近**；三句都停在同一个距离上
（都是外部大事件），那是在加音量不是在推进。

**开篇 3 句内必须出现一个具体的麻烦，不许先铺世界观。** 核对形式＝数到第 3 句，若仍在写天气 /
世界史 / 系统设定，就往前删到麻烦为止——设定信息在麻烦发生之后按需给，读者那时才有理由记住它。
