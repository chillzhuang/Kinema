# prose-rubric · AI 味判据与改写工法

两处用它：**每章第③门自检的 AI 味那一遍**（自查，只看刚写的这一章）· **检查点第④门**
（复核，看整批 10 章）。核心主张：**AI 味的根在写法不在词**——十条症状清单只到「把 X 换成
Y」这一层，换完词仍然一读就是机器写的。先过 §1 的四条工法，§2 才是查漏索引。

引擎只交数（口癖计数、复读原句、带区读数），**「这一处该不该改」永远是你的判断**。

```bash
cd engine
python3 -m kinema novel lint <pid> --from N --to M          # 文体窗口体检（零成本·不落盘）
python3 -m kinema novel recap <pid> --from N --to M         # 口癖全表 / 复读全表 / 带区读数
python3 -m kinema novel sweep <pid> --term "那是后话"        # 全书逐层检索一个说法，带章号行号
```

## §1 四条改写工法

情绪先说后演、段落节拍雷同、信息密度均匀、解释过度，是同一种病的四个外显：
**模型在替读者完成体验**。四条工法各拆一面，每条都给出「改完怎么核对」。

### 工法一 · 把状态词换成身体反应

| | |
|---|---|
| **症状长什么样** | 「他心中一凛，不由得后退了一步，忍不住感到一阵恐惧。」——情绪被命名了三次，动作只有一个。凡出现「感到/意识到/心中/一阵 X 意」就是模型在替读者下结论。 |
| **手上怎么动** | 删掉全部情绪名词与副词，只留**动作＋生理反应＋他此刻注意到的那个具体物件**。「他退了半步，后背抵上门框，才发现掌心的杯子还在。」情绪由读者自己算出来。 |
| **改完怎么核对** | ① 段落里 `不禁 / 不由得 / 忍不住 / 下意识 / 心中一凛 / 心头一震 / 瞳孔骤缩 / 复杂的情绪` 一个不剩；② `novel lint` 的 `prose_slop` 里这些词的计数下降；③ 遮住情绪结论读一遍——读者仍能说出他现在什么心情，才算改成了。 |

### 工法二 · 打乱三件套节拍

| | |
|---|---|
| **症状长什么样** | 连着五段都是「动作句 → 心理句 → 环境句」，或段首连着三个同一主语（「他……／他……／他……」），或列举永远三项（「刀、灯、和那封信」）。节拍一致比用词雷同更容易被读出来，因为它是**整页的形状**。 |
| **手上怎么动** | 每三段里改掉一段的形状：把心理句并进动作句；让某段只有一句对白；把三项列举砍成两项，或让第三项以动作出现（「刀和灯——那封信他捏在手里没放下」）。 |
| **改完怎么核对** | `novel lint` 的 `parallel_triple`（三连同起头）与 `prose_head_repeat` 归零或明显下降；`prose_bands` 的 `tri_list_per_k` 回到 ≤2.0/千字。人工核对法：把这一页的段落各自缩成一个词（动/心/景/白），看序列有没有重复模式。 |

### 工法三 · 把均匀密度改成快慢有别

| | |
|---|---|
| **症状长什么样** | 每段都在推进信息，每句都是 15~25 字，没有一句让人喘气的长句，也没有一处停下来只写一个动作的慢镜。读起来「哪儿都有内容，但哪儿都不重要」。 |
| **手上怎么动** | 一章挑 **1 个高潮点**做慢镜（三到五句只写一件事的分解动作，允许一句话跟着人物呼吸走完整个动作，40 字以上）；挑 **2 处过渡**做快切（半句、单句成段、只给结果不给过程）。信息密度必须有波形。 |
| **改完怎么核对** | `prose_bands` 的 `long40_ratio` ≥0.02（全篇一句长句都没有＝节奏只有一档）；肉眼核对：能指出本章哪一段是慢镜、哪两处是快切，指不出就是还没做。 |

### 工法四 · 删掉解释，信任读者

| | |
|---|---|
| **症状长什么样** | 一个设定刚出现就配一段说明；对白后面跟一句「他这是在提醒她别再问下去」；场景结尾一定有一段总结这件事意味着什么。**解释过度是 AI 味最难自察的一条**，因为每一句单独看都通顺。 |
| **手上怎么动** | 把解释段整段删掉，只留触发它的那个动作或实物；确实必须交代的规则，改成**一件事例**让读者自己得出（不写「灵体不能碰铁」，写他伸手又缩回来、袖口冒了白烟）。场景结尾停在动作或实物上。 |
| **改完怎么核对** | `definition_sentence` 一章 ≤1；本章没有任何一段是「纯说明」（每段至少含一个动作或一句对白）；把删掉的解释拿给自己：不看它，剧情仍然读得懂，就该删。 |

## §2 十二条症状索引

改完 §1 之后拿它扫尾。**每条一行，看到就改，别写读后感。**

| # | 症状 | 长什么样 | 改成什么 |
|---|---|---|---|
| 1 | 情绪先说后演 | 「他感到一阵愤怒」 | 动作＋生理反应＋他注意到的那件东西 |
| 2 | 万能开场 | 章章以天气/光线/「XX的清晨」起手 | 从**动作中段**切入，或从一句没头没尾的对白起 |
| 3 | 段落节拍雷同 | 动作→心理→环境无限循环 | 每三段打乱一段的形状（工法二） |
| 4 | 解释过度 | 设定刚出现就配说明段 | 删掉，换一件事例（工法四） |
| 5 | 信息密度均匀 | 每段都在推进，无慢镜无快切 | 一章一个慢镜＋两处快切（工法三） |
| 6 | 全员一个腔 | 摊主、执法者、少年语法句长完全一致 | 按 `speech_style` 分嘴：句长、忌讳、口头语、答不答问 |
| 7 | 写景与情节脱钩 | 环境描写可以整段搬到任何一章 | 景里必须有**本章要用到的东西**（路线、遮蔽、时间证据） |
| 8 | 章末必金句 | 每章结尾一句概括性感悟 | 停在动作/实物/一个没解决的问题上（见 §3 铁律 4） |
| 9 | 泛化量词 | 「一丝」「一股」「某种」「一阵」 | 给具体的量或来源：「三指宽」「从领口灌进来的风」 |
| 10 | 无名之物 | 从不写具体地名/食物/牌子/招式名 | 起名字。**具体名物是真实感的主要来源**：不写「他吃了点东西」，写「他把那半块冷了的芋头咽下去」 |
| 11 | 抬价翻案 | 「你以为…其实…」「看似…实则…」「不是…而是…」——先替读者虚构一个他并没有的误会，再靠推翻它抬价 | **判断从正面下**，依据摆在旁边。翻案是修辞动作不是字面，换一套字仍是同一个姿势（`pivot_rhetoric` 按句式族数）；只有正文真走过「误解→修正」过程的段落配得上这个形状 |
| 12 | 动词名词化 | 「对伤口进行了处理」「实现了突破」——动词被压成名词挂在「进行/实现」后面 | 还原成动作：「把伤口包了」「一剑破开了阵眼」。公文腔是 AI 草稿的第一指纹，人写的叙事不会自然长出这种句子（`nominalization` 数） |

## §3 对白与金句十铁律

| # | 铁律 | 怎么核对（做得到才算数） |
|---|---|---|
| 1 | **身份定嘴** | 摊主谈钱只谈轻重真假找零，不谈意义。**盲测**：遮住名字读一段对白，说得出是谁才过；说不出就回 `character show <pid> --name X` 对 `speech_style` 重写。 |
| 2 | **金句配额** | 一章**至多一句**想被记住的话，且只能出自**有资格说它的人**、在他**挣到它的时刻**。数一下本章有几句「像题词的话」，超过一句就删到一句。 |
| 3 | **禁对白定义句** | 「X 不是 Y，是 Z」「这叫……」一章合计 ≤1；名词加引号玄化（「所谓的『规则』」）**零容忍**。lint 的 `definition_sentence` 直接数。 |
| 4 | **禁升华收尾成瘾** | 场景结尾停在动作或实物上。**连续两场以感悟收尾即违例**——回头把其中一场的结尾整段砍掉，往前收到最后一个动作。 |
| 5 | **句长要乱** | 允许半句、重复、口头语、答非所问、没接住的话。人话有毛边：一段对白里若每句都是完整主谓宾，就是没写对。 |
| 6 | **粗体只给面板** | 收工判据：**非面板整段加粗 = 0 段、`**` 不成对 = 0 行**（`novel lint` 的 `prose_markup` 会报；面板行留着粗体是对的，它不计污染）。写岔了不必手改：`novel normalize <pid>` 剥掉非面板加粗，逐章走 save 故旧稿进版本栈可回滚。强调靠写法不靠字体——这是要交出去的稿件。 |
| 7 | **叙事套话限额** | 「那是后话」「后来他们才知道」**全批次 ≤1 次**。核对：`novel sweep <pid> --term "那是后话"`，看命中的章号行号。 |
| 8 | **宏大词离对白** | 本源/文明/时代/意义/智慧 只留给面板文本与极少量叙述。角色嘴里出现即删——除非他就是那种爱讲大词的人，而这一点写在他的 `speech_style` 里。 |
| 9 | **禁章号自指** | 角色不知道自己活在一本书里。「第三章那次」→ 世界内锚点（第几天、地点、那件事本身）。lint 的 `self_reference` 扫。 |
| 10 | **排版也是文风** | 对白一律中文弯引号「“…”」、标点全角。直引号与半角逗号是机器排版最明显的指纹。lint 的 `ascii_quote` 扫，上限 0。 |

## §4 lint code 分诊表

`novel lint` 的每条 finding 都是**读数**，不是判决。按下表分四档处置，**别逐条写读后感**。

**A 档 · 必修**（当场改，改完重跑 lint 确认归零）

| code | 意思 | 处置 |
|---|---|---|
| `gap` | 章号断档 | 补写缺的章，或确认是编号错误 |
| `digest_missing` | 缺精简大纲 | `novel digest <pid> --no N --text "…"`（检查点前必须清零） |
| `state_missing` | 缺章末状态快照 | `novel state <pid> --no N --file s.json` |
| `manuscript_drift` | 磁盘正文改了没重登记 | `novel reindex <pid> --archive`（缺省全书；只修一章加 `--no N`）——不修则 lint 文体面读新稿、账目面读旧登记，两边不同源 |
| `manuscript_missing` | 登记了但文件不在 | 找回正文或删登记，别放着 |
| `manuscript_orphan` | 正文在盘上但没登记 | `novel save <pid> --no N --file …`——不登记则 brief/recap/lint 都看不见它 |
| `prose_markup` | 正文里有 markdown 排版 | 按 §3 铁律 6 清干净，加粗只留面板 |
| `ascii_quote` / `self_reference` | 半角标点 / 章号自指 | 上限 0，逐处改 |
| `arc_overlap` | 卷区间重叠 | `novel arc <pid> --no N --from … --to …` 改回不交叠 |

**B 档 · 必处置**（不一定是改正文，但必须有一个动作）

| code | 意思 | 处置 |
|---|---|---|
| `thread_expired` | 伏笔超期未回收 | 三选一：本批回收（`novel thread-pay --id … --in N`）／改期限（`thread-set --due`）／弃置（`thread-drop`）。**不许沉默跳过**——有期限就是承诺过 |
| `thread_stale` | 无期限伏笔长期挂起 | `novel thread-set <pid> --id … --tier short\|mid\|long` 定档。不填 due 正是让告警静音的那个动作 |
| `char_absent` | 角色长期未出场 | 真退场就 `character set <pid> --name X --status departed`；没退场就安排他回场 |
| `arc_uncovered` / `arc_gap` | 卷规划没排到当前章 / 中间有断档 | `novel arc` 立下一卷的纲。缺卷纲＝检查点第①门没有对照物 |
| `no_baseline` | `narrative_style.baseline` 为空 | 摘 2~3 段已认可正文 `novel style <pid> --add-baseline`。**这一门是空转不是通过**，第⑤门记 `unverified` |
| `no_baseline_metrics` | 有样本没数值基线 | `novel baseline <pid> --from N --to M` |
| `definition_sentence` / `parallel_triple` | 定义句 / 三连同起头超限 | 按工法四、工法二改；确有意为之（面板文本、仪式性排比）记进 C 档 |
| `pivot_rhetoric` | 抬价句式超限（每章 ≤1） | 按 §2 第 11 条改：把这句话真正要下的判断正面写出来，依据跟在后面。与 `definition_sentence` 分工——那条管「不是X，是Y／这叫」，本条管「不是…而是／你以为…其实／看似…实则」等其余外衣，同一处不出两条 |
| `nominalization` | 动词名词化超限（每章 ≤1） | 按 §2 第 12 条还原成动作。现代职场/公文题材里角色嘴里刻意说公文腔属人物塑造——把这一点写进他的 `speech_style` 再放行 |
| `style_drift` | 对自基线的 z 分 \|z\|>2 | 看是哪个分量在漂，回 baseline 段落并排读。若是有意变调（换卷换视角），`novel log --kind decision` 留痕后转 C 档 |

**C 档 · 先判是不是有意**（判过一次就在报告里写一行「已知可忽略 N 条」，往后不再逐条重述）

| code | 判「有意」的条件 |
|---|---|
| `prose_repeat` | **先分两类再说话**：① **专有名词与母题复现**——人名、地名、道具名、刻意的回响句（「灯又灭了」），长篇里主角名反复出现是正常的，**这类一律留**；② **句式复读**——同一个动作用同一句话写第三遍（「XX 深吸一口气，缓缓开口」），这类必改。分不清就看：换个人做这个动作，这句话还成立吗？成立＝套话，要改 |
| `prose_head_repeat` | 同上分两类。段首是主角名＝正常；段首是同一个副词/连接词（「而」「然而」「与此同时」）＝复读感来源，必改 |
| `prose_slop` | 该词是不是这本书的语域特征（如系统面板的固定措辞）。是＝留下并在报告里记成「已知可忽略」，往后不再逐条重述；不是＝按引擎给的物理化改写建议逐处改，决定往后彻底禁用就 `novel style <pid> --add-avoid "词,词"`（此后它改由 `style_avoid` 报）。lint 只报最狠 6 条，全表看 `novel recap` |
| `prose_bands` | **两侧带区，低于下限同样是问题**：`long40_ratio` <0.02＝从不写长句（工法三）；`simile_per_k` <0.30＝把「仿佛/似乎」当口癖禁光之后连正经比喻也一起没了（写出具体喻体的明喻不是套话，该补回来）；`simile_per_k` >6.0＝四字比喻套话堆积；`tri_list_per_k` >2.0＝三项式列举是最稳的 LLM 句法指纹；`mattr` <0.80＝同一批词反复用 |
| `prose_narration_heavy` | 对白占比 <8%。冷叙述是合法文体——**确认是有意为之**就留，且往后不再报读后感；不是有意就补对白 |
| `style_avoid` | 命中你自己设的忌讳词。要么改正文，要么承认这词该解禁（`novel style --rm-avoid`），不许两边都不动 |
| `arc_no_major` | 整卷没有一个 major 爽点。若该卷本就是铺垫卷且下一卷开篇即兑现，记一行理由放过 |

**D 档 · 只看本批窗口**（跨窗口的历史条目不重复处理；`--from N --to M` 已经把窗口框好）

| code | 看法 |
|---|---|
| `pacing_flat` / `pacing_flat_tail` | 连续 ≥3 章无 payoff。看是不是本批就该平推（卷首铺垫），否则下一批开头补一个小兑现 |
| `payoff_kind_repeat` | 同型爽点连用 3 章。下一批换型（打脸/升级/解谜/情感/反转） |
| `hook_monotone` | 同型断章连用 3 章。断章七型轮着来（决定/发现/误判/代价/险境/逼近/错位） |
| `long_chapter` / `short_chapter` | 相对**全书中位**的两倍/一半。单章超长常是没断章，单章过短常是没写完——都只看本批这几章，历史章不追溯 |
| `*_more`（`prose_slop_more` / `thread_stale_more` / `char_absent_more`） | 折叠余量行。只在本批处置完前几条后才展开，展开靠 `novel recap` |

**节奏账是 opt-in**：只有 `novel save` 时声明过 `--payoff/--payoff-kind/--hook` 才会有 D 档
前三行。要算第⑦门就从本批第一章起**每章都声明**——账算全了才有意义。

## §5 治已犯的四步

已经写下去的稿子按这个顺序改，一步一遍全稿，别混着改：

1. **说教对白 → 动作＋具体名物。** 凡角色在替作者讲道理的句子，删掉，换成他做的一件事，
   并给那件事一个名字（§2 第 10 条）。
2. **定义句 → 一件事例。** 搜「不是……，是……」「这叫」，每处问一句：能不能用一个场景
   让读者自己得出？能就换，不能才留（一章 ≤1）。
3. **删场景结尾的总结段，或换成实物镜头。** 直接砍掉最后一段往前收；舍不得就把它压成
   一个画面（一只没盖上的杯子、门缝里的光）。
4. **逐个配角问「这个人真会这么说吗」。** 答不上就重写他全部台词，并把答案回写进
   `character set <pid> --name X --speech-style "…"`——下一章的人设门才判得准。

改完重跑一次 `novel lint <pid> --from N --to M`，A 档归零、B 档每条有动作，才算这一门过。
