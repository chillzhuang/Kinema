# kn-anime3d · 3D 总入口（国漫年番｜爱死机 CG｜写实数字人与宠物｜虚拟制片｜黑色写实）

**3D 渲染质感恰是扩散模型的舒适区**，所以这里放的是五条各自成立的赛道，
从"风格化"到"以假乱真"排成一条谱系：

- **A 3D 国漫**——国产年番工业，国内平台追番体量最大。**这一档卖的是工业水准不是题材**：
  仙侠玄幻、武侠江湖、东方朋克、科幻星际、末世废土、都市异能、历史正剧共用同一套渲染 DNA；
- **B 爱死机 CG**——Netflix《爱，死亡和机器人》开创的写实 CG 科幻短片，
  Blur Studio 级渲染 + 高概念反转，全球短片美学天花板；
- **C 3D 写实**——MetaHuman 级数字人与《狮子王》级毛发的拟真生物，
  目标是让观众以为那是拍出来的；数字人 IP / CG 宠物 IP 的做法；
- **D 虚拟制片**——ILM StageCraft（《曼达洛人》）那套 LED 环幕机内合成，
  CG 场景配彻底的实拍摄影机语言；
- **E 黑色写实**——Fincher / Deakins 的布光语言，用单光源与大光比讲情绪。

选哪条**先读下面的「五条路线的边界」**——这五档在"写实度"上有重叠，
真正的判据是**功夫花在哪一层**（主体 / 环境与光 / 布光与情绪）。

## 直接启动整套流程（`/kn-anime3d <故事/主题>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律：
   建项目 → 文案分镜 → 设定单+设定图 → 生图先首镜 → 配音 → 合成 → 动态化）。
2. 按下方**路线选择协议**定 profile：建项目显式 `--profile <路线>` 并全流程绑定同一
   profile（设定图/分镜图/封面每次生图都经该 profile 的 `style_prefix` 注入画风前缀，
   这是全片风格统一的机制保障；逐镜混风格仍走 `shots[].profile` 例外）；
   分镜/提示词按对应路线的 DNA 写。
3. 默认横屏 16:9（云海/太空/废土横构图更震撼）；竖版投放用 `--aspect 9:16` 或 `--both` 双出。
   动态化：对白剧情推荐 `c`(dubbed 对口型)；飞行/太空/大场面空镜推荐 `b`(native)。

### 五条路线的边界（选错就白跑一遍全流程，先读这段）

| | 主体是什么 | 决定性的那一层 | 典型题材 |
|---|---|---|---|
| A `anime3d` | 风格化的东方人物 | **年番级工业水准**的国漫渲染（题材不限） | 仙侠/武侠/科幻/末世/都市异能/历史 |
| B `anime_ldr` | 写实 CG 人物 + 硬表面机械 | 成人向暗黑**科幻**美术 | 科幻选集剧 |
| C `photoreal3d` | **CG 造出来的人/生物** | **主体**与实拍难辨（毛孔/毛发） | 数字人口播、宠物短片、品牌 IP |
| D `virtual_production` | 真人演法的角色 + CG 环境 | **整场戏像在棚里拍的**（环幕交互光） | 科幻/异世界剧情、广告 TVC |
| E `cg_noir` | 写实 CG 人像 | **布光与情绪**（单光源大光比） | 悬疑、犯罪、心理剧、暗调访谈 |

两组最容易混的，判据钉死在这里：

- **C ↔ D**：C 的功夫花在**主体**（皮肤、毛发、眼睛），D 的功夫花在**环境与光**
  （LED 环幕把场景色光打到人身上）。要一只毛发以假乱真的猫 → C；
  要一场"飞船舱内的对手戏，看着像真的在棚里拍的" → D。
- **B ↔ E**：两者都暗都冷，但 B 是**科幻题材**的美术取向（机甲/太空/废土/暴力美学），
  E 去掉全部科幻元素，只留**黑色电影的布光与情绪**——人像、审讯室、雨夜车内。
  写机甲就走 B，写"一张脸在黑暗里"就走 E。

**写实档连带纪律（B/C/D/E 带 `image.identity_sheet: true`；路线A 不属）**：身份图纯文生图受信（t2i），改身份走 `project refs --only character:<名> --force` 而非 `refine`；生视频按镜 A/B/C 降级阶梯，预判近景正脸的镜写 `face_visibility: closeup`。详见 `docs/agents/photoreal-face.md`。照片级媒介另有三条写法纪律：道具 desc 涉及标志、印花或包装时显式写「标识为无文字的中性图形、不是任何真实品牌」（品类词会把模型拉向真实品牌，直出可辨认的仿标）；场景 desc 的状态用正向口径写画面里看到的东西（「两扇玻璃门合拢在画面中央」而不是「门关着」，否定句常被画反）；门口、街景、公共空间的镜在 `negative_prompt` 加「画面里没有其他人」（`characters` 只管设定图挂载，不构成画面里只有这几个人的约束）。

## 路线A · 3D 国漫（profile=anime3d）

**目标一句话**：**国产年番级的工业水准，题材不限**——仙侠玄幻、武侠江湖、东方朋克、
科幻星际、末世废土、现代都市异能、历史正剧，都在这一档里。

> **这一档卖的是"工业水准"而不是"仙侠"。** profile 前缀里**刻意只有渲染质感**
> （写实向东方建模 / 发丝布料解算 / 材质分层 / 体积光 / 电影级布光），
> **一个题材词都没有**——它注入每一次生图，混进「云海仙山宫阙」就会给科幻舰桥和
> 都市夜景强塞仙侠布景。题材由 `shots[].image_prompt` 承载，见下面的题材谱系。

### 一份渲染 DNA（所有题材共用；**已由前缀注入，正文不要复述**）

- **写实向建模，东方审美的脸**：不是皮克斯的卡通夸张，也不是照片级真人——
  是"比真人俊美一度"的东方面孔：剑眉、凤目、清晰下颌线。现代题材同理，
  只是换成通勤装与短发。**脸的稳定靠角色设定图**（三区两视，必做，铁律2）。
- **发丝与布料是工业水准的标尺**：长发逐缕解算、衣摆随步伐摆动、外套下摆在风里翻卷——
  每镜都写**动的头发与衣料**；静止的布料 = 廉价感。这条与题材无关，古装现代都吃。
- **材质分层是第二道标尺**：丝绸的柔光、金属的锐反射、皮革的粗粝、玻璃的通透、
  混凝土的哑光——**同一画面里至少写清两种不同材质的反应**，这是"贵"的来源。
- **电影级打光**：体积光、边缘光勾轮廓、大气透视（远景层层泛蓝）；
  夜戏用双色温（月光冷蓝 + 灯火暖橙 / 霓虹青 + 车灯暖白）。
- **运镜是 3D 的特权**：环绕（角色亮相）、俯冲（跟随飞行物）、拉升揭示
  （从人物拉到全景）——`video_prompt` 大胆写三维运镜，这是 2D 做不到的。

**跨档边界**（选错就白跑）：暗黑成人向科幻短片 → 路线B `anime_ldr`（那是选集剧美学，
低饱和 + 硬表面机甲 + 反转）；霓虹赛博画风本身 → `kn-cyberpunk`；
2D 国风古装（魔道祖师质感）→ `kn-anime` 的国漫仙侠画风。

### 分镜法则（年番演出文法，按题材分化）

- 开场 ≤2s：**大场面定场**或**主角亮相环绕镜**。定场的内容随题材换——
  云海宗门 / 雨夜码头 / 霓虹旧城 / 星舰舷窗 / 巨构灯塔 / 城市天际线 / 长安街市。
- **文武交替**：文戏（对话/密谋/情感）用正反打 + 中近景；"武戏"按题材换形态——
  仙侠斗法 / 江湖过招 / 机车追逐 / 舰队交火 / 变异体遭遇 / 异能对峙；
  一集至少一场，且至少一个"截图当壁纸"的高光镜。
- **动作三段式（通用骨架）**：**起手**（力量凝聚，环境先有反应：尘土浮起 / 引擎升压 /
  霓虹闪烁）→ **交锋**（对撞，冲击波外扩）→ **定胜负**（一方破防击飞，慢镜头）。
- **招牌运镜每集给一个**：御剑穿云 / 踏檐轻功 / 机车贴地追逐 / 舰桥拉升 /
  巨构俯冲 / 天台异能对峙的环绕——它是这一集的记忆点。

### 提示词公式（**正文只写题材与本镜差异，渲染质感交给前缀**）

- ✅ 仙侠：`环绕运镜起幅，青衫剑修立于悬浮剑冢之巅，数千柄古剑斜插云海如林，
  他抬手间一柄飞剑破空而至悬停掌前，剑身灵力流光映亮下颌线，长发与衣摆
  在罡风中向后翻卷，晨光穿透云层洒下金边`
- ✅ 科幻：`舰桥中景缓慢推近，指挥官立于全息星图前，蓝色投影的粒子在他掌心
  重组成航路，外骨骼肩甲的哑光陶瓷与身后舷窗的星云冷光形成冷暖对比，
  舱内薄雾让顶灯光柱可见`
- ✅ 现代都市异能：`低角度中景，天台边缘的少年抬手，气浪自掌心炸开掀翻整排雨棚，
  脚下地砖呈放射状龟裂，身后写字楼玻璃幕墙映出城市霓虹并随冲击泛起涟漪，
  外套下摆与短发被气流向后掀起`
- ✅ 末世废土：`大全景仰拍，锈蚀的巨构灯塔刺入尘霾，塔身爬满变异藤蔓，
  探照灯柱在扬尘里割出锐利光锥，废墟前一队幸存者的身影小如蚁群`
- ❌ `3D渲染的帅气修仙者站着发光`（无镜头 / 无物理感 / 无题材细节 / 复述了前缀已有的"3D渲染"）
- `negative_prompt` 常备：`卡通比例, 塑料质感, 面部僵硬, 手部畸形, 低多边形`；
  **现代/科幻题材另加** `仙侠元素, 古装, 云海仙山`（防旧素材惯性把古风带回来）。
- `image_prompt_en` 取词：cinematic 3D render / volumetric light / subsurface
  scattering / cloth simulation / hair strands / particle effects；
  科幻加 hard-surface mecha / holographic UI / energy shield，
  都市加 glass curtain wall reflection / neon city night。

### 声音设计

- 旁白声线描述（六槽位 40~80 字，写进 `voice custom --narrator --prompt … --adopt 1`）：宏大世界观「四十五岁男性，低音区偏厚，胸腔共鸣强、字尾沉稳，语速偏慢、句间停顿长，标准普通话播音腔，气质庄重」；都市/悬疑「三十五岁男性，中低音区偏暗，略带气声与颗粒感，语速中等、句尾收得干净，标准普通话，气质冷静克制」。
  角色按人设写 `voice_prompt`，`character add --voice-prompt` 即定制立档；要官方模版再 `voice audition` → `voice use`。
- BGM：cinematic。国风管弦/战鼓（仙侠武侠）｜合成器 + 弦乐（科幻末世）｜
  电子节拍（都市异能/东方朋克）——同一 mood 下由文案与画面定气质。
- 动作戏走 `b`(native) 可让模型原生生成剑鸣 / 引擎 / 气浪音效。

## 路线B · 爱死机写实 CG（profile=anime_ldr）

**目标一句话**：一集一个高概念，用 Blur Studio 级的写实 CG 把它砸进观众脑子。

### 工业参照（取词库）

| 面向 | 参照 | 可直接入词的术语 |
|---|---|---|
| 写实 CG 人物 | Blur Studio《隐藏的战争》、Netflix LDR 各集 | 皮肤毛孔与次表面散射 · 瞳孔环境反光 · 汗珠与油光 · 恐怖谷的正确一侧 |
| 硬表面 | 工业设计式机甲/枪械建模 | 液压管线 · 装甲分件与接缝 · 磨损划痕 · 褪色贴花编号 · 服役痕迹 |
| 大气与光 | 体积光渲染 | 光柱中的尘埃颗粒 · 沙尘/蒸汽/雨幕 · 硬阴影 · 霓虹只做点缀 |
| 调色 | teal-orange / 单色温冷调 | 低饱和 · 高对比 · 长焦压缩空间 · 手持微晃的纪实感 |

### 视觉语言 DNA（写提示词前逐条内化）

- **超写实 CG 人物，恐怖谷的正确一侧**：毛孔、汗珠、瞳孔里的环境反光、
  次表面散射的耳廓透光——是《隐藏的战争》《天鹰座裂隙之外》那种"差一步是真人"
  的 CG 质感，不是国漫的俊美化，也绝不是卡通。**脸的稳定同样靠角色设定图（三区两视）。**
- **硬表面科幻是第二主角**：机甲关节的液压管线、装甲的磨损划痕与贴花编号、
  枪械的加工纹路——机械细节密度就是本路线的"工业水准标尺"；写提示词时给机械
  **服役痕迹**（掉漆/油渍/弹痕），全新出厂感 = 廉价感。
- **体积光 + 尘埃是空气的质感**：光柱里悬浮的尘埃颗粒、废土的漫天沙尘、
  太空舱的冷白顶光——每镜都该有"空气中的介质"，干净的空气 = 游戏过场感。
- **冷峻电影调色**：低饱和、teal-orange 或单色温冷调、硬阴影；夜戏霓虹只做
  点缀不做主光。长焦浅景深压缩空间，手持感微晃增加纪实气质。
- **每集一个世界观（选集剧基因）**：爱死机的灵魂是"一集一个高概念"——
  末世废土、深空货船、赛博都市、雪原哨站……场景定场镜要一镜立住世界观。
- **暴力美学的克制表达（合规红线）**：原作是 R 级，平台发布必须降级——
  冲击用火花/烟尘/碎片与剪辑节奏表达，**提示词不写血腥裸露**（防字地板同款
  逻辑：负向意图写进正向提示词，如「无血腥画面」）。

### 分镜法则（选集剧演出文法）

- **冷开场 in medias res**：≤2s 直接切进事件中段（追击途中/警报响起/尸体特写的
  悬念镜），不做背景铺垫——世界观靠画面细节与一句旁白立住。
- **高概念一句话**：第 2~3 镜内让观众明白"这集的规则"（机器人有了信仰/
  飞船里多了一个人/雪原下有活物）。
- 动作戏三要素：**物理实感**（弹壳落地、液压驱动、烟尘弥漫）、**长焦压缩**
  （危险贴脸）、**声音留白**（爆炸前一拍静默——native 模式让模型自己配音效）。
- **反转收尾**：最后 1~2 镜完成语义反转（救援者才是猎手/信号来自自己），
  黑场收——爱死机式余味。
- 文戏少而狠：对白短句、正反打贴脸特写，沉默镜头比台词多。

### 提示词公式

- ✅ `长焦浅景深，废弃空间站走廊，佩戴外骨骼的女潜行者贴墙缓行，头盔灯
  光柱切开黑暗照亮悬浮尘埃，装甲肩甲的划痕与褪色编号清晰可见，
  远处舱门缝隙渗出红色警示灯光，冷蓝主色调，无血腥画面`
- ✅ `低角度仰拍，废土沙暴中一台四足机甲踏过锈蚀车骸，液压关节喷出蒸汽，
  装甲板油渍与弹痕斑驳，逆光沙尘让轮廓成剪影，teal-orange 电影调色`
- ❌ `很酷的机器人在打架`（无镜头/无材质细节/无世界观/无光线）
- `negative_prompt` 常备：`卡通渲染, 塑料质感, 干净无磨损的机械, 鲜艳饱和色,
  血腥, 裸露`
- `image_prompt_en` 用地道术语：hyper-realistic CG / hard-surface modeling /
  volumetric light with dust motes / desaturated cinematic grade / long lens
  shallow DOF / wear and tear details / photoreal skin shading。

### 声音设计

- 旁白声线描述（六槽位 40~80 字）走纪录片式抽离叙述：「四十岁男性，中低音区偏暗，气声略多、质感干净无鼻音，语速偏慢、句尾平收不上扬，标准普通话，气质冷静疏离」；
  对白角色按人设写沉稳成年声线的 `voice_prompt`，`character add --voice-prompt` 即定制立档；情绪标注克制（emotion_scale 1~3，爆发只留给反转镜）。
- BGM：cinematic（合成器低音铺底/工业氛围）；动作戏强烈推荐 `b`(native)——
  弹壳、液压、爆炸的原生音效是本路线的半条命。

### 重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 像游戏过场/塑料感 | `提升到 Blur Studio 级写实 CG：皮肤毛孔与次表面散射、机械磨损划痕、体积光尘埃颗粒` |
| 像国漫/卡通脸 | `脱离动漫审美：写实人体比例与皮肤质感，恐怖谷正确一侧的 CG 真实感` |
| 机械全新出厂感 | `给机械加服役痕迹：掉漆、油渍、弹痕、褪色编号贴花，管线外露` |
| 画面太干净 | `加空气介质：光柱悬浮尘埃、沙尘、蒸汽、雨幕，长焦浅景深压缩` |
| 色彩太艳 | `回归低饱和冷峻电影调色（teal-orange 或单色温），霓虹只做点缀` |

## 路线C · 3D 写实：数字人与拟真生物（profile=photoreal3d）

**目标一句话**：造一个不存在的人或一只会演戏的宠物，让观众以为那是**拍出来的**。

### 工业参照（写提示词时的取词库，都是有据可查的公开工艺）

| 面向 | 参照 | 可直接入词的术语 |
|---|---|---|
| 数字人 | Epic **MetaHuman**、Weta FX《阿丽塔》、Digital Domain《双子杀手》数字替身 | 逐根发丝（strand-based groom）· 次表面散射 SSS · 皱纹图 wrinkle map · 微法线毛孔 · 眼球焦散与角膜缘环 |
| 拟真动物 | Disney《狮子王》(2019)、《奇幻森林》(2016) 的 groom 系统 | 针毛 guard hair + 绒毛 undercoat 分层 · 结绺 clumping · 顺毛走向 · 湿毛 · 耳廓透光 |
| 渲染与光照 | Unreal Engine 5（Lumen GI / Nanite / path tracing）、ACES 色彩管线 | 全局光 · 路径追踪 · ACES 胶片曲线 · ARRI Alexa 调色 |
| 摄影 | 电影定焦体系 | 35/50/85mm 定焦 · T1.4~T2.8 · 180° 快门角运动模糊 · 变形宽银幕横向光斑 |

### 视觉语言 DNA（写提示词前逐条内化）

- **正文写摄影，不写渲染器**——这是本路线的头号纪律。扩散模型一读到
  "3D / CG / 渲染 / Unreal" 就往**光滑塑料**上靠，而我们要的正是反面。
  "写实 CG"这层意思**已经在 profile 的 `style_prefix` 里注入了**，
  `image_prompt` 正文只写：主体的**微观细节** + **真实器材的镜头语言**。
  （同「复述即漂移」：前缀已说过的，正文再说一遍只会打架。）
- **微观细节是真实感的总开关**。数字人写：毛孔、面颊绒毛、唇纹、眼睑边缘的
  湿润反光、鼻尖与耳廓的血色泛红、下巴的胡茬颗粒。宠物写：针毛的方向与光泽、
  底层绒毛的柔散、鼻头湿润的镜面高光与鼻纹、胡须的细弱反光、耳廓逆光透出的血管。**写不出微观细节的镜，出来必然是蜡像。**
- **不完美即真实**。轻微不对称的五官、几根飞散的碎发/杂毛、皮肤的色斑与油光、
  衣物的自然褶皱与轻微磨损、动物毛发被蹭乱的一块——**完美对称 = 假**。不完美指微观纹理与磨损，
  **不是疲态**：黑眼圈/眼袋/血丝/憔悴缺省不写、夜班题材也不推导；用户点名才写并登记进 `visual_requirements`（否则 `project refs` 不出设定图）。
- **光是主角，逆光是毛发的命**。大面积柔光（柔光箱/阴天窗光）打底 + **边缘光/
  侧逆光**把主体从背景剥离；宠物**必须给侧逆光或逆光**——毛边透光是绒毛质感最强的
  单一信号，顺光拍毛发一定像贴图。
- **浅景深 + 焦点钉在眼睛**。85mm T1.8 那种压缩感与虚化，是"这是电影"的即时读数；
  焦点落在眼睛（宠物落在近侧那只眼），眼神光必写。
- **中性调色不预设**。不像 B 路线锁死冷调——按内容走：宠物日常用暖阳自然光，
  都市情感用低对比柔调，纪实感加轻微胶片颗粒。

#### 数字人专项

- **脸的一致性靠设定图，别靠提示词**（铁律2）：`project refs` 出三区两视
  设定图，之后每镜只写**本镜差异**（表情/角度/光位），外貌交给设定图。
- 表情走**微表情**：眉尾的一点下压、嘴角的不对称牵动、眼轮匝肌的收缩——
  写"微笑"会得到假笑，写"眼角先弯、嘴角随后牵起"才有活人感。
- 说话镜走 `c`(dubbed) 对口型；口播/代言是数字人最成熟的落地场景。
- **合规**：不做真实公众人物的仿真替身；虚构人物需要时在文案里标注 AI 生成。

#### 拟真宠物 / 生物专项（用户点名要的那一档）

- **毛发分三层写**：针毛（长、亮、有方向性）→ 绒毛（短、柔、散射）→ 结绺与走向
  （顺着身体曲面，胸口与颈部最蓬）。风吹毛、湿毛、蹭乱的一撮都是加分项。
- **眼睛按物种给对**：猫是竖瞳、犬是圆瞳、鸟是侧置眼；角膜高光 + 虹膜的纤维纹理 +
  下眼睑的湿润反光。**死鱼眼是拟真动物最常见的失败点**。
- **鼻头与肉垫**：鼻头湿润的镜面高光与细密鼻纹；肉垫的粗糙颗粒与磨损。
- **拟人化要克制**——这是《狮子王》(2019) 被诟病的那条线：要的是"**有情绪的真动物**"，
  不是"顶着人类表情的卡通脸"。情绪一律靠**耳朵角度、尾巴姿态、眼神方向、体态重心**
  表达；**绝不写"露出微笑""挑眉"**这类人类面部动作。附设定图时正文只写本镜差异，
  不重复完整外貌。先在角色卡显式填写 `subject_kind=animal` 或 `creature`，再把无衣物、
  四足、禁止直立等硬约束写入 `constraints`；引擎会把它们送入 `negative_prompt`。
  `subject_kind=human` 的角色仍应把服装、配件、义体等登记为正向外观，不能套用动物禁穿规则。
- **视觉语义分层是硬规则**：`visual_requirements` 写必须保留的正向特征（如「左臂义体」），
  `constraints` 只写画面禁止项，`taboo_lines` 只写台词/行为人设禁区。不要把同一条正向要求
  塞进 `constraints`，也不要用 `taboo_lines` 驱动画面生成；如果某条行为禁区同时有视觉要求，
  视觉部分另登记到 `constraints`。
- **运动学要物种正确**：猫走路肩胛滑动、犬摇尾带动整个后半身、跳跃前的重心下沉。
  动态化走 `b`(native) 让模型自带动物运动与环境音，通常比对口型更自然。

### 提示词公式

- ✅ 数字人：`85mm 定焦浅景深半身，年轻女子在落地窗前侧身回望，柔和的窗光从左前方
  裹住面部，面颊绒毛在逆光下泛起细绒边，眼睑边缘湿润的反光与虹膜纤维清晰，
  鼻尖与耳廓透出淡淡血色，几缕碎发脱离发髻贴在颈侧，焦点钉在近侧眼睛`
- ✅ 宠物：`50mm 微距特写，橘猫趴在午后窗台，侧逆光让耳廓透出粉色血管与绒毛的金边，
  面颊针毛根根分明、底层绒毛柔散，竖瞳收成一线并映出窗格，鼻头湿润的高光与
  细密鼻纹清晰，胡须末梢挑起一点光，背景虚化成暖色光斑`
- ❌ `一只很可爱的3D宠物猫，超写实渲染`（复述了前缀已有的"3D/渲染"、
  零微观细节、无镜头语言、"可爱"是评价不是画面）
- `negative_prompt` 常备：`塑料质感, 光滑无毛孔, 蜡像感, 毛发像贴图, 死鱼眼,
  卡通比例, 大眼萌化, 人类表情, 过曝高光, 五官完美对称`
- `image_prompt_en` 取词：photoreal / skin pores and vellus hair / subsurface
  scattering / strand-based fur groom / guard hairs over undercoat / rim light /
  85mm prime shallow depth of field / catchlight in the eye / film grain。

### 分镜法则（纪录片式电影文法）

- **第一镜就立质感**：开场给主体大特写（看清毛孔或绒毛），观众在两秒内决定
  "这是真的还是假的"——把最强的一张放最前。
- 三段景别：**质感特写**（信任）→ **中景**（交代关系与动作）→ **环境全景**
  （交代世界与光）；每段之间给一个眼神/回头的**动机镜**串起来。
- **眼神特写是签名镜**：一集至少一个，焦点钉眼、眼神光清晰——这是本路线的
  "截图当壁纸"镜。
- 宠物片按"**观察**"而非"表演"组织：等待、发现、试探、放松四拍，
  比让动物做人类动作可信得多。
- 动态化：数字人说话 → `c`(dubbed)；宠物与空镜 → `b`(native)（原生动物运动 + 环境音）。

### 声音设计

- 旁白声线描述（六槽位 40~80 字）：纪录片式「四十岁男性，中低音区偏暗，质感干净略带气声，语速偏慢、句尾平收，标准普通话，气质冷静克制」；温情向换「三十岁女性，中音区偏暖，质感柔和略带气声，语速偏慢、句尾轻落，标准普通话，气质温和」；
  数字人自己说话按人设写 `voice_prompt`，`character add --voice-prompt` 即定制立档。
- BGM：cinematic；宠物日常向可换 calm。宠物片强烈推荐 `b`(native)——
  爪垫落地、呼噜、窗外鸟鸣的原生音效是沉浸感的半条命。

### 重做意见词典（路线C · review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 塑料感/蜡像感 | `加微观细节：皮肤毛孔与面颊绒毛、次表面散射的耳廓透光、轻微色斑与油光；去掉光滑均匀的皮肤` |
| 毛发像贴图 | `毛发改逐根分层：针毛有方向与光泽、底层绒毛柔散、加结绺与顺毛走向；改侧逆光让毛边透光` |
| 眼睛发死 | `眼睛给活性：角膜高光、虹膜纤维纹理、下眼睑湿润反光，焦点钉在近侧眼睛` |
| 宠物像卡通/表情太人 | `去拟人化：情绪只用耳朵角度、尾巴姿态、眼神方向与体态表达，不要人类面部表情` |
| 像 3D 渲染不像拍的 | `按实拍摄影写：85mm 定焦 T1.8 浅景深、柔光箱主光加边缘光、180° 快门运动模糊、细腻胶片颗粒` |
| 五官太完美 | `加不完美：轻微不对称、碎发飞散、皮肤纹理不均——完美对称是假的最强信号` |

## 路线D · 虚拟制片 LED 影棚（profile=virtual_production）

**目标一句话**：场景是 CG 造的，整场戏却像**实实在在在摄影棚里拍下来的**。

### 工业参照（取词库）

| 面向 | 参照 | 可直接入词的术语 |
|---|---|---|
| 影棚形态 | ILM **StageCraft**（《曼达洛人》）、UE5 nDisplay 机内合成（ICVFX） | LED 环幕 · 机内合成 · 视锥内实时渲染 |
| 光的来源 | 环幕即光源 | **交互式环境光** · 环幕色光投在皮肤与金属上 · 环境反射进眼球与漆面 |
| 现场实物 | 前景实景搭建 | 实景灯具入画 · 烟机薄雾 · 地面实体道具与演员脚下的真实接触阴影 |
| 摄影 | ARRI Alexa / 变形宽银幕 | 宽容度与胶片曲线 · 轻微镜头畸变与呼吸 · 变形横向光斑 · 手持微晃 |

### 视觉语言 DNA

- **环幕即光源，这是本路线唯一的"以假乱真开关"**。棚拍与绿幕的分水岭就在于
  背景的色光**真的打在人身上**：写"舱外星云的青蓝色光落在他左脸与肩甲上、
  在护目镜上映出一道弧形反光"，而不是"背景是星云"。缺了这层，画面立刻变成
  "人贴在背景板前"。
- **前景一定要有实物**。近处的操作台、栏杆、垂下的线缆、飘过的雾——它们是
  "这是一个真实空间"的证据，也天然给出景深层次。
- **薄雾是棚里的标配**：烟机雾让光柱可见、让远处环幕自然衰减（顺带遮住 LED 的
  锐利感）。每镜都该有一点空气。
- **摄影机是被人扛着的**。轻微手持晃动、焦点微呼吸、偶尔的重新构图——
  完美平滑的机位反而暴露"这是渲染的"。
- **别追求背景锐利**。真实拍摄里背景本就落在景深之外；把环幕拍虚一点，
  既符合物理也顺手掩盖 CG 感。
- **正文写现场，不写引擎**：与路线 C 同一条纪律，"LED/虚拟制片/UE5"已在前缀里，
  正文只写"光从哪来、什么落在什么上、镜头怎么摆"。

### 提示词公式

- ✅ `35mm 手持中景，飞船驾驶舱内，飞行员侧身回望舷窗，舷窗外星云的青蓝色光
  落在他左脸与肩甲上并在护目镜上映出一道弧形反光，前景垂下的线缆与操作台指示灯
  出虚，舱内薄雾让顶灯的光柱可见，背景落在景深之外`
- ❌ `虚拟制片风格的飞船驾驶舱里有个飞行员`（复述了前缀、没说光从哪来、无前景实物）
- `negative_prompt` 常备：`绿幕感, 人物与背景割裂, 背景过度锐利, 摩尔纹,
  完美平滑的机位, 塑料质感`
- `image_prompt_en` 取词：LED volume in-camera VFX / interactive lighting from
  the wall / practical haze / foreground set pieces / handheld 35mm / anamorphic
  flare / background falling out of focus。

### 分镜法则

- 开场给**广角定场**交代这个"棚内世界"的尺度与光；随后中景带足环境光在人身上的
  落点；情绪落在特写，但特写也要保留环幕色光的边缘光。
- 一集里给 1~2 个**穿越前景**的运镜（镜头从线缆/栏杆后摇出），这是棚拍最有说服力的一拍。
- 动态化：对白戏 `c`(dubbed)；空镜与移动镜 `b`(native)。

### 重做意见词典（路线D）

| 症状 | `--note` 建议写法 |
|---|---|
| 人像贴在背景板前 | `把环幕色光真实打到人身上：写清哪个方向的什么颜色落在脸/肩/金属上，并在眼球与漆面留环境反射` |
| 背景太锐利像壁纸 | `背景落到景深之外，加薄雾让远处自然衰减；前景补实体道具遮挡` |
| 像渲染不像拍的 | `改手持 35mm、轻微晃动与焦点呼吸，实景灯具入画，地面给真实接触阴影` |

## 路线E · 黑色写实人像（profile=cg_noir）

**目标一句话**：一张脸，一束光，其余全是黑——用光讲情绪，不靠台词。

### 工业参照（取词库）

| 面向 | 参照 | 可直接入词的术语 |
|---|---|---|
| 布光 | 古典肖像的伦勃朗光、明暗对照法（chiaroscuro） | 单一硬光源 · 伦勃朗三角 · 大光比但暗部留层次 · 眼神光 |
| 摄影导演 | Roger Deakins《银翼杀手2049》、David Fincher 的低照度控制 | 极简色彩 · 烟雾分离层次 · 光源入画 · 硬阴影边缘 |
| 黑色电影 | 百叶窗条纹光、雨夜车内、审讯室顶灯 | 条纹阴影 · 湿反光 · 顶光死角 · 逆光剪影 |

### 视觉语言 DNA

- **先想光，再想构图**。这一路线的每一镜都应能用一句话说清"光从哪来"：
  百叶窗的横条、桌上那盏台灯、门缝、烟头、车窗外扫过的车灯。**光源最好入画或
  暗示在画外某个确定位置**——不确定的光 = 平淡的光。
- **大光比但暗部必须有层次**。纯黑一片是欠曝不是黑色电影；写"暗部仍能读出
  肩线与墙面的轮廓"。这是业余与专业的分界线。
- **眼神光是命门**。整张脸可以只有 1/3 被照亮，但**瞳孔里那一点锐利高光必须在**——
  没有它，人物是死的。
- **烟与雾分离前后景**：薄烟让光成柱、让背景退远，是黑色电影的空气。
- **近单色**：低饱和到接近单色，只留一处点缀色（霓虹、血、一件红外套）作为视觉重音。
- **克制的暴力与情绪**：张力靠留白、沉默、光的压迫感，不靠血腥（同样走"负向意图
  写进正向提示词"的防线，如「无血腥画面」）。

### 提示词公式

- ✅ `85mm 特写，审讯室里男人只有右半张脸被顶灯照亮，伦勃朗三角落在左颊，
  暗部仍读得出肩线与身后墙面的轮廓，瞳孔里一点锐利眼神光，空气里薄烟让顶灯
  的光柱可见，近单色的冷灰调，无血腥画面`
- ✅ `低角度中景，雨夜车内，窗外扫过的车灯把百叶窗式的条纹光划过她的脸，
  湿玻璃的水痕在皮肤上投下流动的暗斑，仪表盘的暖橙是画面里唯一的点缀色`
- ❌ `黑暗中的神秘人物，很有氛围`（没说光从哪来 = 这一路线什么都没写）
- `negative_prompt` 常备：`平光, 暗部死黑无层次, 高饱和, 眼睛无高光,
  廉价噪点, 血腥`
- `image_prompt_en` 取词：single hard key light / Rembrandt triangle / high
  lighting ratio with shadow detail / catchlight in the eye / haze-revealed light
  shaft / near-monochrome desaturated palette / venetian blind shadow stripes。

### 分镜法则

- **暗部起幅**：开场从近乎全黑里显出一点轮廓或一个光斑，再推入——建立"这是一部
  用光说话的片子"。
- 台词少、沉默镜多；一场戏里**光位变化**（人走进光里 / 灯灭 / 车灯扫过）
  往往比切镜更有力。
- 收尾常用**逆光剪影**或**灯灭黑场**——留下人物的形状而非表情。
- 动态化：对白 `c`(dubbed)；氛围空镜 `b`(native)，让模型自带雨声与环境混响。

### 重做意见词典（路线E）

| 症状 | `--note` 建议写法 |
|---|---|
| 暗部死黑一片 | `暗部保留层次：仍要读得出肩线与墙面轮廓，这是欠曝与黑色电影的分界` |
| 光很平没情绪 | `改单一硬光源并说清光从哪来（百叶窗/台灯/门缝/车灯），落出伦勃朗三角` |
| 人物眼睛发死 | `瞳孔里补一点锐利眼神光——整脸可以只亮三分之一，眼神光必须在` |
| 太花太艳 | `压到近单色低饱和，只留一处点缀色作视觉重音` |
