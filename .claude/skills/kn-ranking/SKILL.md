# kn-ranking · 榜单 / 盘点 / TopN

**倒数揭晓的清单体**。完播率机器——观众为了看 No.1 必须撑到最后；
评论区天然吵架（"XX 居然不是第一？"），互动率白送。

## 直接启动整套流程（`/kn-ranking <盘点主题>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律）。
2. 全程 `profile=ranking`；无固定角色，`--skip-design`；序号徽章由字幕系统自动叠加
   （`subtitle.mode=ranking`：左上红徽章 + 条目标题 + 底部说明）。
3. 默认竖屏 9:16，立项汇报交代画幅；动态化通常不需要（快节奏 Ken Burns 已够）。

## 类型定位（榜单的三个杠杆）

- **悬念杠杆**：永远**从第 N 倒数到第 1**，钩子预告"第 1 名 99% 的人猜不到"。
- **争议杠杆**：榜单排序本身就是观点——把有争议的选择放 No.2/No.1 交界（评论区引爆点）；
  但每个排名给出**可辩护的理由**（数据/事实，联网检索核实，别硬编）。
- **信息杠杆**：每个条目至少一个"哦原来如此"的细节，不是百科复读。

## 工业参照（取词库）

| 面向 | 参照 | 可直接入词的术语 |
|---|---|---|
| 条目"证件照" | 商业静物摄影的棚拍语言 | 单一主体居中 · 深色渐变背景 · 45° 主光 · 底部微反光 |
| 高对比质感 | 产品海报的主体分离 | 边缘轮廓光 · 背景与主体明度拉开 · 主体占画面 2/3 |
| 加冕视觉 | 颁奖舞台的仪式语言 | 金色轮辉光效 · 顶光光柱 · 更近景别 · 微仰视角 |
| 模板一致性 | 系列卡牌/图鉴的版式纪律 | 同机位同景别 · 同背景色 · 同光位 · 仅换主体 |

## 视觉语言 DNA（图鉴美学）

- **每镜是该条目的"证件照"**：单一主体、居中、干净深色背景、高对比——观众在
  2 秒内认出"这是什么"，剩下的时间留给解说词。多主体 = 没重点。
- **条目模板一致性锁定**（全片不可漂移项，逐条钉死）：同景别、同机位高度、
  同背景色域、同主光方向——条目间**只换主体**。整齐划一的模板感是清单体的美学，
  跳来跳去反而廉价；这也是"系列图鉴"的收藏价值来源。
- **左上角 1/4 留空**是构图铁律：序号徽章由字幕系统叠加在左上，image_prompt
  里任何元素不得侵入该区（主体重心放中下）。
- **No.1 揭晓镜允许且应该破格**：金色轮辉光效、更近景别、微仰视角、顶光光柱——
  全片唯一一次模板破例，视觉上"加冕"。破格只此一镜，破两次就不叫破格。
- **抽象词兑现表**（写了左列的意图，正文必须落出右列的物理内容）：

| 想要的感觉 | 必须写出的物理内容 |
|---|---|
| 主体突出 | 单一主体居中占 2/3 + 深色渐变底 + 边缘轮廓光 |
| 高级质感 | 45° 主光 + 底部微反光 + 背景明度压暗 |
| 隆重加冕 | 金色轮辉 + 微仰视角 + 顶光光柱（仅 No.1 镜） |
| 图鉴系列感 | 与上一镜同机位同景别同背景色，仅换主体 |

## 分镜法则（倒数结构）

5~11 镜（Top5~Top10 最优），2~4s/镜：
1. **钩子镜**：总览 + 悬念（"这5个里，最后一个曾被全网嘲"）。
2. **条目镜 ×N**：每镜字段——`rank`（序号→红徽章）、`title`（条目名→徽章旁）、
   `narration`（解说词，含那个"哦"细节）、`caption`（底部一句话说明，可与解说不同）。
3. **No.1 镜**：揭晓 + 一句"为什么它配"。
4. **CTA 镜**：把争议还给观众——"不服？评论区排出你的第一"。

## 提示词公式

正文三段式：**主体与姿态 + 布光与背景 + 构图（居中/留空）**；
条目镜从第二镜起显式带"与上一镜同构图"语义：

- ✅ 首条目镜：`主体居中，一把发光的中世纪长剑插在石座上，深色渐变背景，45°主光加边缘轮廓光，底部微反光，左上角留空`
- ✅ 后续条目镜：`同前一镜构图与布光，主体换为一柄北欧战斧立于石座上，深色渐变背景，左上角留空`
- ✅ No.1 镜：`微仰视角近景，王者之剑悬浮于顶光光柱中，金色轮辉光效，深色背景压暗，左上角留空`
- ❌ `很多把剑摆在一起`（一镜一条目，多主体=没重点）
- ❌ `炫酷的排行榜大屏，列出前五名`（榜单结构由徽章字幕承载，画面画榜单=重复+错字风险）
- `negative_prompt` 常备：`多个主体, 杂乱背景, 左上角有元素, 画面内文字表格, 构图倾斜`
- `image_prompt_en` 取词：single centered subject / dark gradient backdrop /
  rim light / studio product lighting / subtle floor reflection / high contrast /
  golden glow(仅 No.1) / consistent framing across shots。

## 声音设计

- 音色：「解说男」「热血少年」（盘点要有起哄感），语速 +10；倒数到 No.2 后
  刻意放慢半拍再揭晓 No.1（`narration` 里写"而第一名——"停顿感）。
- BGM upbeat；旁白 `voice custom --narrator --prompt … --adopt 1` 定制立档为账号声纹，
  要官方模版音色再 `voice audition` → `voice use`。

## 重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 徽章被挡 | `左上角1/4区域完全留空，主体下移居中` |
| 条目间画风跳 | `与上一镜保持相同机位/景别/背景色，仅更换主体` |
| 主体不突出 | `单一主体居中放大占2/3，背景简化为深色渐变` |
| No.1 不够隆重 | `增加金色轮辉光效与更近景别，微仰视角，仪式感加冕` |
| 主体像贴图/塑料 | `补 45° 主光与边缘轮廓光，底部加微反光，主体与背景明度拉开` |
| 画面里出现榜单文字 | `去掉画面内的文字与表格元素，排名信息由徽章字幕承载` |
| 背景抢戏 | `背景压暗降饱和为纯色渐变，去掉背景内可辨识物件` |
