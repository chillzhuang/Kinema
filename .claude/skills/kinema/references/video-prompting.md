# 导演级视频提示词规范（video_prompt 写作真源）

> 本文是全集群写 `shots[].video_prompt` 的**强制规范**——所有视频生产 route Skill 共用，
> 与 `storyboard.md`「视频提示词」节互为索引。适用两家图生视频模型（Seedance 2.0/2.5、
> MiniMax Hailuo/H3），措辞示例以中文主字段为准（`video_prompt_en` 按同结构英译）。
>
> 立论只有一条：**图生视频的僵硬（动态漫画感）九成出在提示词**——动作只有一个抽象
> 动词、没有终点、没有物理、没有环境呼应，模型就只能在原图上插几帧匀速位移交差。

---

## 〇、先分清：引擎拼什么，你写什么

引擎（`pipeline/prompts.py`）在每条视频请求上**自动前置/追加**这些层，**你一个字都不要重写**：

| 引擎自动层 | 内容 |
|---|---|
| 播放速率地板 | 「动作以真实速度进行，不做整体慢放或快进」（点名了升格/慢放/延时/V2V 的镜不注） |
| 画面基准契约句 | 「以 @图片1（本镜画面）为…基准」按任务类型五分措辞（首帧/参考/首尾帧/V2V/全能参考） |
| @图片N 职责绑定 | 全能参考/dubbed 实附的板与角色/场景/道具设定图逐张点名职责（编号=附图顺序） |
| 板职责声明+板地板 | 附简笔板时的「板是脚本不是画面」双保险 |
| 结构锁 | 「一段连续拍摄、一个主导运镜」（V2V/擦镜/自写过的不注；附板与全能参考照发） |
| 运镜前置 | `camera` 字段提到创作正文首位（前位 token 权重最高） |
| 表演地板 | 负面串缺省压「叹气、深呼吸、明显的胸肩起伏、流泪」；本镜正文（动作/终态/拍点/情绪）明写了哪个就摘哪个，否定写法（不落泪）与台词文本不算 |
| 动力学地板（微动尾句） | 重量/惯性/起落缓冲/细微生命感微动与环境流动 + 随动附属物（名词按 `characters[].subject_kind` 选：human=发丝与衣料·animal=毛发·robot=线缆与配重，未登记则不发这半句）；写了运动设计的镜才注 |
| 人声句 | native 走「<角色><情绪动词>：“台词”，口型与台词同步」+ 音色绑定；dubbed 走对口型句 |
| 防字地板 | 「避免出现：字幕、画面文字、水印」——**恒是最后一句**（负面串之后不许再拼任何内容：`_zh_join` 用「，」续行，接上去的台词会被读成「要避免的东西」） |

所以 `video_prompt` **只写引擎给不了的东西：这一镜的动作设计本身**。
复述画面（主体长相、场景陈设）＝复述即漂移；
堆质量词（高清/大片感/电影级）＝零信息量还挤占动作 token。

## 一、动作链结构（video_prompt 正文的标准形状）

一条合格的 `video_prompt` = **「起 → 承 → 收」的连续动词链**，每拍具体到
**肢体部位 + 幅度/速度/力度**，最后一拍收在明确终态：

```
她先<动作A：部位+幅度+速度>，接着<动作B>，
<环境/物件对动作的反应>，最后<动作C>并停在<空间上的明确终态>。
```

实例（对照感受信息密度）：

- ✗ 僵硬写法：`她转身离开。`
- ✓ 规范写法：`她右肩先沉、带动上身缓缓转向门口，裙摆随转身荡开半拍后回落，
  脚步由慢到稳走出两步，在门框光影交界处停住，只留侧脸对着镜头。`

十条铁则（每条都对着一种僵硬形态）：

1. **只写增量**：模型看得见 @图片1，画面里已有的一个字不重述——token 全部留给运动。
2. **动词链 ≥ 2 拍**：单动词（走/看/笑）必僵硬；两到三拍连续动作才有「戏」。
3. **每个动作给终点**：「转身」不合格，「转到侧脸对窗后停住」合格——终点写进
   `end_state` 字段（引擎按 delta 骨架注入），不要复述末帧画面。
4. **具体到部位与力度**：手/肩/头/重心 ×「缓缓/猛地/轻轻/用力」×「幅度大/细微」。
5. **写物理与惯性**：动作要带动衣摆/发丝/液体/尘埃「跟随—回落」；落点要有缓冲
   （顿一下、晃半拍、重心下压）。
6. **补一条环境次级运动**：背景里恒有一样东西在动（云漂/人流/树影/霓虹闪/雾涌）
   ——这是「世界活着」与「贴图背景」的分界。
7. **用时间进程词造节拍**：先…接着…与此同时…最后…（模型按这些词排进程）。
8. **强动词换弱动词，但守住幅度上限**：人物近景/特写遵守「缓慢、轻柔、连贯」——
   狂奔大跳剧烈翻滚这类高爆发动作在特写上必崩，要爆发就把景别放到全景。
9. **动作要与 @图片1 的构图可行**：特写图别要求全身调度，坐姿图别要求起跑——
   解剖学不可行的指令模型只能自己另起一镜（切镜的头号来源之一）。
10. **纯风景/空镜也要有运动**：镜头缓移 + 介质流动（雾/水面/光斑），绝不留白。

## 二、运镜纪律（camera 字段）

- **一镜一个主导运镜**（引擎结构锁与此同源）：推/拉/摇/移/跟/升降/环绕选一个主行为，
  最多叠一个次级修饰（如「推近中带极缓上升」）；pan+zoom+tilt+shake 堆四个＝模型自己切镜。
- **运镜写成叙事而不是标签**：「镜头从她肩后缓缓推近到中近景，随她抬头微微上摇」
  优于「推镜头，仰拍」——模型理解时间顺序。
- **运镜与动作同向设计**：拉远配「主体缩成小点」、推近配「表情细节浮现」——
  运镜与画面内容互相印证，冲突（固定机位+环绕）是漂移与切镜的常见成因。
- 进阶技法照抄 `storyboard.md`「进阶运镜预设库」双语措辞，配额纪律不变
  （一集 2~4 个进阶档）。

## 三、多参考图（全能参考缺省档）的选图与绑定

引擎缺省附图 = **分镜图(@图片1) + 简笔板（在盘即附）+ 角色→场景→道具设定图**，
配额自动收敛（官方全图 ≤9：分镜图 1 + 板/设定图合计 ≤7），并逐张生成 @图片N
职责绑定句——**指挥层不手写绑定句，但要管好选图输入**：

- 出场角色**逐镜点名 `shots[].characters`**、道具场景用注册名措辞——挂载判据
  （`lineage.required_refs`）按它取材，点歪一张，绑定句就把错的图钉给错的人；
- 阵容超配额时角色优先、场景次之、道具殿后（引擎已按此裁剪）——十几人同框的
  大场面镜，用 `shots[].characters` 只点画面里真看得清脸的那几位；
- 参考图之间**不许打架**：分镜图是白天、提示词写雨夜＝身份漂移的邀请函。

## 四、时间轴分段（长镜/多拍动作）

≥8s 或多拍动作的镜**优先走简笔分镜板路径**（`kinema-sketchboard`：beats 拆拍 →
分段时间轴 + 板作参考）——逐拍先后排布的分段结构远胜一大段散文。
不出板也可以只写 beats（时间轴纯文本独立成立）。拍密度铁律照旧：每拍 ≥1.2s。

## 五、反模式清单（出现一条就打回重写）

| 反模式 | 后果 |
|---|---|
| 重述 @图片1 的画面内容 | 漂移指令 + 动作 token 被挤没 |
| 单个抽象动词（走/动/看） | 僵硬（动态漫画感的第一成因） |
| 质量词刷屏（8k/大片感/masterpiece） | 零信息量、画面过饱和 |
| 形容词写情绪（他很害怕） | 渲染不出——改写成身体力学（指尖微颤、重心后移半步） |
| 一镜堆 ≥3 种运镜 | 模型自行切镜 |
| 动作无终点、无节拍词 | 中段自由发挥、收尾漂移 |
| 特写图要求大调度/爆发动作 | 崩脸、幻觉肢体 |
| 4~5 秒塞多场景多事件 | 违反物理可行性，模型只能切镜 |
| 给动作写「总共 N 次」而不写频率 | N÷dur 常常算出慢放，且字面看不出来（第六点五节）|
| 动作自然时长 2 秒却订了 10 秒镜 | 模型只能放慢/循环/编填充物 |
| 负面串写否定句（"没有运动模糊"） | 改正向措辞；负面约束点名具体物 |

## 六、字段分工速查（一镜的运动设计落在哪）

| 字段 | 写什么 | 谁消费 |
|---|---|---|
| `video_prompt` | 动作链正文（本文一、二节） | 提示词正文 |
| `camera` | 主导运镜一句（叙事式） | 引擎前置到正文首位 |
| `entry_state` / `action` / `end_state` / `light_shift` | delta 骨架四件（开场承接/动作概要/终态/光变） | **恒注入，不是缺 video_prompt 时才用**（见下） |
| `sfx` | 环境音效（native 才发）：写可数事件，不写「底噪/垫底/声床」 | 引擎注入（时间轴带 sound 时让位） |
| `sketch.beats` | 逐拍秒段脚本（长镜） | 分段时间轴 + 简笔板 |
| `shots[].characters/props/scenes` | 参考图挂载白名单 | @图片N 绑定的取材真源 |

### delta 四件与正文的分工（**别把同一段动作写四遍**）

`entry_state`/`action`/`end_state`/`light_shift` 是**恒注入**的：引擎每次都把它们
拼在正文之前（去重只做朴素子串比对，两段话换个说法就都发出去）。所以：

- 四件写**概要**：一句话说清从哪接、做什么、停在哪、光怎么变；
- `video_prompt` 写**执行细节**：力学、物理反馈、次级动画、镜头执行；
- `sketch.beats` 写**时序**：第几秒到第几秒发生什么。

三层各说各的。同一个动作在四件里写一遍、正文里再展开一遍、beats 里再复述一遍，
就是同一段话发三份——一条 1311 字的提示词里，真正描述这 6 秒的内容占了三段
互相重复的位置，而运镜被挤到第 474 字（模型注意力集中在前 30~40% token）。

## 六点五、动作要符合物理，不许出现没人要的慢放

**铁律：正常动作一律按真实速度演。**要慢放/升格/子弹时间/延时，必须在
`video_prompt` 或 `camera` 里显式点名——引擎据此让开速率地板；不点名就是要真实速度。

**慢放多数不是模型主动加的，是被提示词算出来的。**同题对照里的两条真实错误：

| 写下去的话 | 隐含速率 | 真实速率 | 后果 |
|---|---|---|---|
| 10 秒镜 · 「前肢交替入水出水**各三个循环**」 | 0.3 步/秒 | 冲刺 2.5~3 步/秒 | 慢约 10 倍，看起来像滑行 |
| 8 秒镜 · 「一次完整的甩水…**全程约三秒**」 | 0.33 次/秒 | 抖毛全程 1~1.5 秒、摆动 4~5 Hz | 慢约 3 倍 |

两条都不是有意要慢放，而且从字面完全看不出来——它藏在「次数 ÷ 镜长」这个
除法里。**越听话的型号越会照着压慢**：mini 会自行回到常识速度、反而"看着正常"，
2.5 严格执行、慢放就现形了。

三条写法纪律：

1. **给动作写频率，不写总次数**。写「每秒两步半的步频」而不是「三个循环」；
   写「4~5 Hz 的高频抖动」而不是「全程约三秒」。
2. **写完做一次除法**：把你写的次数除以 `dur`，问一句「真实世界里它就是这个速度吗」。
3. **数不上来就不要写数**。只写「全速冲刺」比写一个错的次数好——模型对
   「全速」有常识先验，对「三个循环 ÷ 10 秒」只有算术。

常见动作的自然时长（定 `dur` 与写频率时对一眼）：

```text
四足动物全速过镜      2~4s      甩水抖毛      1~1.5s（摆动 4~5Hz）
人物走进画面并站定    3~5s      转身回望      1~2s
伸手取物到握住        1.5~3s    落座/起身     1.5~2.5s
一次挥击到收势        0.8~1.5s  一次呼吸      3~4s
开门并跨过门槛        2~4s      眨眼/视线移动 0.2~0.5s
```

## 七、镜长分档（**长镜承载叙事是缺省，短镜是例外**）

生成式片段镜间恒硬切，**每一次切换都是一次截断**：画面重新建立、动作归零、环境声
断一次。传统实拍靠动作衔接剪辑吃得住 3~5s 的平均镜长，生成式吃不住——所以设计
单位不是「一个动作一镜」，而是「**一个戏剧节拍串一镜**」：动作→说话→反应装进
同一镜，用 `sketch.beats` 分段时间轴排布（2~3 秒一拍），运镜在镜内完成发展
（推近收在反应上、横移带出第二人、前景擦镜换构图）。切镜只发生在**戏剧上该切**
的地方：换场、换视点、punch。

| 档 | 秒数 | 适用 |
|---|---|---|
| **主戏镜（缺省档）**：对白/表演/调度 | **8~12s** | 一个完整节拍串（3~5 拍）：起动作→说话→反应/收势；对白镜连人物的听与答都在同一镜里 |
| 揭示 / 环境 / 无清晰人脸 / 锁定或极慢运镜 | 10~15s | 风景、天气、缓慢揭示、背影跟拍——长镜最安全的一档 |
| punch 镜（**确有必要才用**）：特写冲击 / 反应插入 / 揭示瞬间 | 3~6s | 脸或手占画面大头、信息量在一瞬间的镜；密集使用即碎切（lint `montage_chop` 按 warn 拦） |
| 单条连续弧线（仅 2.5） | 12~30s | 按 stage 拆，每段 ≥3s、一段一个主动作 + 一个运镜 + 明确终态 |

**一致性预算不再用「缩短镜长」当第一手段。**误差确实随帧序号累积，但代价该由
镜头设计消化，不是把叙事剪碎：① 长镜里让正脸不满帧全程（侧面/背影/中景起，
推近收在关键拍——脸满帧的秒数短，漂移窗口就短）；② 全能参考的设定图恒在场，
身份有锚；③ 10s+ 的正脸表演镜接受重 roll 概率并写进报价注记——为省一次重 roll
把整场戏剪成 4s 碎片，省的是小钱、赔的是成片。

**镜长的硬约束只有一条：拍串的自然时长。**给一个真实只有 2 秒的动作订 10 秒，
模型只有三条路：放慢、循环、编填充物——但正解不是把镜订短，而是**把拍串写满**：
10s 不是一个动作抻长，是四个 2.5s 连续动作的串（beats 逐拍写）。定 `dur` 用：

```text
dur ≈ Σ拍时长（2~3s/拍） + 台词秒数（4.3 字/s） + 呼吸留白（0.5~1s）
```

拍串真的只有一拍（纯 punch）才落 3~6s 档；要撑长镜就补拍
（前置蓄势、后置反应、环境呼应），而不是把单拍抻长。

**一个动作塞不进一镜就拆两镜**：找到「结果已成定局」的那一瞬当切点，前一镜停在
切点上、动作仍在进行，后一镜从切点刚过开始、已经在动中；两镜角度至少差 30°，
同轴时景别至少跨两档，否则读起来是卡顿不是剪辑。

> 30~60s 短片切 5~10 镜那条是**静图幻灯片（kenburns）的节奏律**，不要照搬到
> native/dubbed：那两个模式按秒计费，镜数由内容与预算定，镜长按上表分档。

## 八、分镜图要停在动作中途

「PPT 感」有一半不在提示词而在首帧：**主体端坐、左右对称、重心均匀、没有任何
正在进行的动作**——这样的一帧没有「下一瞬间」，模型只能在它上面推一个镜头运动
交差。写 `image_prompt` 时把主体停在动作中途：手已经抬起一半、脚已经离地、
布料/毛发已经被带起、重心已经压向一侧。

**「中途」必须是真中途，不能是动作的终点。**一个「爪落石」的镜，分镜图画在
「肉垫刚接触石面」——那看着像动作瞬间，其实是这个动作的**终点**；首帧锁死在终点，
模型没有余量可演，会把爪子反向抬走。开了首帧锚定（`anchor_frame`，见
`docs/agents/anchor-frame.md`）之后这一点尤其要紧：缺省的全能参考允许模型漂移、
自己找回旋余地，锚定之后没有。自检一句：**从这一帧出发，写下的动作还有没有地方可去？**

配套的三层运动（`video_prompt` 里**至少写满两层**）：

```text
主体层   身体的发力与重心转移（哪怕只是一次重心变化，也比静止有生命）
附属层   毛发 / 衣料 / 水珠 / 尘土的滞后与回落
环境层   雨、雾、光斑、水面、人流——背景里恒有一样东西在动
```

**连抽 3 次仍不理想时，改镜头设计而不是改措辞**：更短、更近、更简、拆成两镜——
提示词救不了一个物理上不可拍的镜头。
