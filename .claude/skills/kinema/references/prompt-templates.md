# 提示词模板（阶段3 参考）

> **双语规范与字段全集见 `storyboard.md`**（image_prompt 中文主 / image_prompt_en 英文辅 /
> negative_prompt 负面约束 / 工业字段中英对照）。本文件是各模型的措辞模板速查。

## 图像提示词（image_prompt）

结构：**主体 + 动作 + 场景 + 风格块 + 构图 + 比例标注（按项目主比例）**

```
[主体，含 character_block 里的角色特征] + [动作/姿态] + [场景/道具] +
[美术风格：画风、配色（复用 style.palette）] + [居中构图，主体在安全区] + 比例标注
```

要点：
- **每镜都拼上 `style.character_block`**，保证角色/画风一致。
- 中文写作即可（Seedream/通义中文理解强）。
- **比例标注跟随项目主比例**：竖屏项目写"竖屏 9:16 / 竖版构图 / 居中"；横屏项目写
  "横屏 16:9 电影构图"；方形写"方形 1:1 居中构图"——避免出图与画布不符导致裁切。
- 需要文字上屏时靠 caption（字幕烧录），**别依赖模型在图里写字**——引擎给每条图像提示词
  缺省加了防字地板（「避免出现：字幕、画面文字、水印」），画面本体一律无字。
  例外只有 `game_sim`（HUD）· `explainer`（信息图）两个画风，它们在 models.yaml 里
  显式关掉了地板；榜单徽章/气泡/对话框的文字全是 ASS 后置烧录，同样要求图本体干净。

示例（番茄工作法·扁平插画）：
```
扁平插画风，一个戴眼镜的年轻上班族瘫在书桌前发呆，桌上堆满待办便签，
暖橙#FF7A45 与奶白#FFF7ED 配色，圆润几何形状，居中构图，主体在竖屏安全区内，竖屏 9:16
```

## 视频提示词（video_prompt）

跨模型通用公式：**Subject + Action + Scene + Camera + Lighting（Veo 另加 Audio）**

- **只写运动和运镜**，不重复已在图里的静态画面（首帧驱动图生视频的关键）。
- 运镜默认 **slow/smooth**；同一动作各模型措辞不同（Veo："camera orbits subject"；Runway："orbiting camera"）。
- kenburns 模式只需简单运镜意图；dubbed/native（Seedance 图生视频）按下方专业公式细写。

### Seedance 专业公式（dubbed / native 图生视频）

```
[主体动作·具体到肢体与幅度] + [次级运动·环境呼应（发丝/衣摆/尘土/水面）] +
[运镜节奏·一镜一主运镜] + [情绪氛围一词收束]
```

- **运镜从预设库选**：`camera` 字段优先取《storyboard.md·进阶运镜预设库》的
  「中文措辞」列——经典技法（希区柯克变焦/焦点转移/升镜揭示/缓慢环绕/FPV…）
  与大师签名（迈克尔·贝英雄环绕/斯皮尔伯格惊愕推近/库布里克对称推进/斯派克·李
  滑行/前景擦镜…）两表，按「镜型→运镜智能推荐」表配镜——一集 2~4 个▲进阶档
  做记忆点，■高危档用户点名才排。
- **≥10s 长镜拆拍表**（一镜到底/native 长镜必用）：把先后发生的画面事件写进
  `sketch.beats[]`（每拍一个新信息），段头由引擎按型号发——2.0 系列发不带时间的
  「第N段」（官方把精确秒段列为支持不稳），2.5 发整秒段。**不要在 `video_prompt`
  里手写「0-3秒：」一类秒段**：作者字段原样进请求体，会把引擎刻意不发的秒段绕回去。
- **native 模式必写声音设计**（官方："一定要写音频指导"）：环境音走 `sfx` 字段
  （引擎并入），台词由引擎追加——native 的音效丰富度直接决定成片质感。

- **动作要有幅度与方向**：❌「角色说话」→ ✅「角色边说边前倾半步抬手指向远处，
  衣摆随动作摆动」——首帧已定构图，视频提示词的职责是"让画面里的一切合理地动"。
  **注意这条与运镜侧的"幅度要收"不矛盾，两者作用域不同**，别互相套用：

  | 作用域 | 纪律 | 出处 |
  |---|---|---|
  | **运镜**（摄影机怎么动） | 幅度要**收**——手持纪实等档必须写「轻微」，否则糊 | `references/storyboard.md` 手持纪实预设 |
  | **表演**（人怎么动） | 幅度要**给足**——写不出幅度的表演等于没表演 | 本条 |

  一句话记法：**镜头收着走，人放开演。** 把运镜的"轻微"套到表演上，出来就是石像；
  把表演的"大幅"套到运镜上，出来就是糊。
- **微动是地板不是表演**：引擎会给写了运动设计的镜自动追加一句「全程保留细微的
  生命感微动与环境流动」（落兜底句的镜与链上镜除外，你自己写了呼吸/微动也不重复加）
  ——那只保证画面不死，**不替代**你写主体表演。**缺省不叹气、不深呼吸、不流泪**：
  引擎把三者压进每镜负面地板，本镜正文明写了才放开，否定写法不算。
- **次级运动是质感来源**：主体之外永远补一处环境运动（风吹发丝、烛火摇曳、
  雨滴划过窗）；静止的背景=PPT 感。
- **引擎自动并入的字段**（不必重复手写进 video_prompt）：**增量契约句**（绝对首句，
  声明「以所给首帧/参考图为画面基准，只描述变化」）、**首尾帧过渡句**（衔接链上的镜
  才有）、`camera` 运镜（并入为「运镜：…」前缀，位于创作正文首位）、`action`/`end_state`/
  `light_shift` delta 骨架（并入为「动作：/终态：/光线变化：」）、**结构锁**（连续拍摄声明，
  V2V 与擦镜镜自动不发，作者自写过的不重复）、`sfx` 环境音效（**仅 native，且本镜
  没有逐拍 `beats[].sound` 时才发**——逐拍版在场，镜级汇总版自动让位，同一套声音
  设计绝不发两遍）、`beats[].sound`（native 下随分段时间轴发出，编成「声：…」）、
  `negative_prompt`（并入为「避免出现：…」，且自动追加防字地板）、retake 意见
  （并入为「本次修正重点」）。
  英文 `video_prompt_en` 只在 camera/sfx 上例外（需自带地道术语）；契约句与 delta 骨架
  **两语种都发**——它们没有 `_en` 对位，丢掉会让整镜落到「基本别动」的兜底句上。
- dubbed 口型句、native 人声句由引擎自动追加，不要手写。**native 人声句按语态二分**
  （判据与 lint 的语态维度同源）：有具体角色开口 → 「<角色><情绪动词>：“台词”，
  口型与台词同步」，动词由 `emotion` 确定性查表（命中才换，否则就是「说」）；
  纯旁白（无具名说话人或说话人就叫「旁白」）→ 「画外旁白讲述，人物口唇保持闭合」，
  **不会**再要求角色给一句第三人称叙述配口型。

示例（dubbed，引擎注入后实际送出形如）：
```
以所给参考图为画面基准：同一个人、同一套衣服、同一个场景、同一画风，构图与机位按本镜运镜自然变化，以下只描述在此基础上发生的变化。
本镜是一段连续拍摄、只有一个主导运镜，画面自始至终由同一台摄影机不间断记录。
运镜：缓慢推近，老人抬手抚过剑柄，指腹沿剑脊滑到剑尖后收手握拳，
烛火被穿堂风压低又弹起，肃穆，避免出现：现代物品、字幕、画面文字、水印，
角色对口型说出所给音频内容…
```
（首句与末尾的防字串都是引擎加的——**你只需要写中间那段运动**。dubbed 说「参考图」、
native 说「首帧」，链上镜还会多一句首尾帧过渡铁律，措辞由引擎按模式选。）

**契约句锁身份、不锁构图**：它明说「构图与机位按本镜运镜自然变化」，所以你在 `camera`
里写拉远/环绕/升镜揭示不会被首句压住——**不要再手写「构图保持一致」这类句子**，那会把
引擎刚放开的东西重新锁死。第二句是**结构锁**（引擎自动加，肯定式）：它只保证"这一镜是
一次连续拍摄"，不限制机位随运镜移动。两种情况引擎会自动**不发**结构锁：走参考视频
（V2V）、点名了擦镜技法（`foreground_wipe` 一族的预设名或其运镜措辞）；你若自己在
`camera`/`video_prompt` 里写了「一镜到底/无跳切」，也不会重复发。

## 运镜词 → 引擎 Ken Burns 映射（kenburns 模式）

kenburns 模式引擎按镜号轮换四种运镜（此模式下 `camera` 字段只作标注，实际运镜由镜号决定）：
`slow push-in`（推近）/ `pan right`（右移）/ `pull-out`（拉远）/ `pan left`（左移）。
**dubbed/native 模式下 `camera` 字段会被引擎自动并入视频提示词**（「运镜：…」），
所以 camera 请写真实可执行的运镜语义（推近/环绕/跟拍/拉升），别写虚词。
