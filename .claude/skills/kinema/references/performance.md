# performance · 表演物理化与镜头文法（写分镜时与 storyboard.md 配套读）

> 分工：`storyboard.md` 管**分镜表怎么写**（字段全集、运镜库、连贯性自检、比例安全区），
> 本文件管**表演怎么落到可拍的身体上、镜头怎么讲权力与节奏**。两份互不重复：
> 那边是"表格与镜头"，这边是"戏"。lint 的 `emotion_abstract` / `prompt_pronoun` /
> `shift_gap` 三个维度是本文纪律的机器哨兵——词表与正则的单一真源在引擎
> `engine/kinema/pipeline/variation.py`，本文只讲纪律、绝不抄表（免两处分叉）。

## 一、表演物理化：情绪只能演，不能说

**第一纪律：画面描述里不许出现情绪名词。** 「愤怒/悲伤/紧张/绝望/委屈…」这类词
在提示词里是零信息——镜头拍得到下颌、指节和呼吸，拍不到"愤怒"这个概念。模型
接到情绪名词，只会退回训练集均值的那张脸（微皱眉＋抿嘴，什么情绪都长这样），
这正是"AI 感"的第一来源。lint 的 `emotion_abstract` 命中即逐词给身体化改写方向。

⚠️ 与 `emotion` **字段**无关：那是给 TTS 的情绪档（管声音），照写不误；本纪律
管的是 `image_prompt`/`video_prompt`/`action`/`end_state` 这四个画面字段。
台词里角色说「我怕」也不受此限——那是表演内容，不是描述缺陷。

### 身体六轴：情绪拆到哪里去

把要演的情绪拆到六个身体轴上写。**普通镜至少落 2 轴；情绪重镜**（近景/特写/
反应镜）**至少落 4 轴**——轴数不够的近景，出来就是一张没戏的脸。

**上界同样是硬的：一次情绪转折写 2~4 条线索就够，别把六轴全写满。**
线索之间会互相竞争注意力——把整张脸的每块肌肉都点一遍，模型只会各演一点、
哪一点都不到位，反而比写两条更平。所以这是一条**带**（2~4），不是一个下限：

| | 普通镜 | 情绪重镜（近景/特写/反应镜） |
|---|---|---|
| 至少 | 2 轴 | 4 轴 |
| 至多 | 3 条线索 | 4 条线索 |
| 超了会怎样 | — | 线索互相竞争，表演摊薄成"每样都做了一点" |

弱 → 强对照（同一场戏，只是把"结论"换成"可观察线索"）：

- ❌ 弱：`她舍不得他走`——这是剧情结论，镜头拍不出"舍不得"。
- ✅ 强：`她的视线从他脸上移开，落到他身侧的空处；眼睑垂下；嘴角短促地扬起又落回；
  胸口起伏一次，随后屏住` —— 四条线索、四个轴，每条都能在单帧上查证。

| 轴 | 写什么 | 示例措辞 |
|---|---|---|
| 视线 | 看哪、不敢看哪、焦点怎么移 | 「视线从信纸上抬起，停在门把手上没动」 |
| 面部微反应 | 肌肉级变化，不是表情名 | 「咬肌鼓了一下，唇线抿平，眼尾没跟着笑」 |
| 手部 | 手最诚实：攥、抵、抖、停 | 「指节在桌沿敲了两下，忽然停住」 |
| 重心体态 | 前倾/后撤/绷直/塌陷 | 「上身后撤半寸，肩却端着没垮」 |
| 生理应激 | 喉结、鼻翼、汗、耳根脸色 | 「喉结滚了一下，耳根泛红」 |
| 与物关系 | 他此刻注意到/攥住/放下的那件东西 | 「握着的杯子转了半圈，一口没喝」 |

**动作中间态是最贵的一拍**：话到嘴边咽了回去、手伸到一半停在空中、身子转过去
一半顿住、指尖碰到门环又松开——未完成的动作比完成的动作有戏。`video_prompt` 的动作链（起势→主动作→收势，见主
SKILL 分镜丰富度铁律）里**至少排一个中间态**；`end_state` 停在中间态上，下一镜
天然有戏可接。

### 四段现成的身体语法（按情境取用改写，**语法名绝不写进提示词**）

- **强忍**：面上维持原表情，泄露口只给一处——「笑意维持着，握杯的手背绷出一条筋；
  等对方转身，肩才塌下来半寸」。要点：表与里只许一处矛盾，两处就是演砸。
- **冷压**：动作幅度全面调小、速度放匀——「他把茶盖合上，声音很轻；视线抬起来，
  落点比刚才低了一寸」。要点：威胁感来自"过度受控"，不来自任何大动作。
- **破防前一秒**：秩序感的最后维持——「把袖口整了整，才发现手在抖；把手收进袖口，
  又硬压回去」。断在这里，破防本身留给下一镜或留给观众。
- **空心**：应激全部消失——「视线落在正前方，不聚焦；有人碰了他的肩，慢了两拍
  才转头」。要点：豁免其他五轴，但必须保留一个可见的"慢"，否则只是站桩。

## 二、点名铁律：画面描述里没有「他／她／它」

画面四字段（`image_prompt`/`video_prompt`/`action`/`end_state`）一律用**注册名**
点名角色与道具，不用第三人称代词。两层机制，一层比一层硬：

1. **模型层**：代词无指代——多人镜里「她转身」模型只能瞎猜是谁转身，张冠李戴
   是必然不是偶然。
2. **引擎层**：设定图自动挂载按 `name`/`keywords` 在提示词里**文本命中**
   （道具挂载、角色缺省推断都走这条路）。写「她拿起它」＝这一镜**既没点名角色也
   没锁定道具**，设定图挂不上，跨镜一致性直接掉——这不是文风问题，是挂载机制的
   命中率杠杆。

对白（`narration`/`lines[].text`）不受此限：台词里的代词是人话。合成词
（其他/其它/吉他）引擎已排除，放心写。lint 的 `prompt_pronoun` 命中即点名。

## 三、动作—反应文法（剧情镜的基本盘）

观众靠**反应**理解事件的分量：施压有多重，看被压者的脸；揭示有多炸，看听者的手。
剧情类分镜的默认文法是「动作镜 → 硬切 → 反应镜」，规则四条：

1. **五类事件必配反应**：关键施压（威胁/摊牌）、信息揭示（真相/名单/身份）、
   突然闯入（人/声/物）、道具触发（信物现身/机关启动）、权力翻转（见下一节）。
2. **反应镜三要素**：至少 2 个身体轴的可见反应（第一节六轴里取）＋ 景别比动作镜
   **收一档**（中景事件配近景反应）＋ 时长短（2~3s，反应是一拍不是一场戏）。
3. **反应不递归**：反应镜不再触发下一个反应镜——「A 说话→B 反应→A 看到 B 的反应
   又反应」两层就该回到事件推进，否则节奏原地打转。
4. **日常动作不配反应**：走路、倒茶、自然呼吸不切反应镜——反应镜是重音，
   到处都是重音等于没有重音。

**同镜替代**（不想切镜时）：焦点转移（rack focus，对白剧最优雅的第三选择）或
横移带到，在一镜内先后呈现动作与反应——措辞直接取 `storyboard.md`
《进阶运镜预设库》，不自创。

## 四、机位写权力（angle / lighting 的叙事用法）

对峙戏的核心信息是**谁压着谁**，这件事该由机位和光讲，不该由台词喊。写分镜时
按本表给对峙双方**成对**配 `angle`/`lighting`/构图措辞：

| | 压制的一方 | 被压的一方 |
|---|---|---|
| 机位高度 | 轻微仰拍（镜头抬着看他） | 轻微俯拍（镜头压着看他） |
| 画面占比 | 占画面大、头顶空间少 | 占画面小、负空间大（被空间吃掉） |
| 前景 | 他的肩/轮廓压进对方镜头的前景 | 隔着别人的肩被看到 |
| 光位 | 轮廓光清晰、面部受光完整 | 顶光压出眼窝阴影、或半张脸没入暗部 |
| 视线 | 可以不看对方（不需要确认） | 追着对方的脸（需要确认） |

**权力翻转是剧情类最贵的一拍**，用机位讲而不是用台词讲——翻转发生的那一镜起，
把上表**成对调换**：机位高度互换、前景遮挡换边、焦点归属移交、构图中心从旧强者
移到新强者。观众不需要一句台词就知道局面变了。

**光随剧情不随情绪**：变光必须有可见的光源事由（云遮日/灯亮了/门开了/火把逼近），
写进那一镜的 `light_shift`；没有事由的"情绪打光"会被观众读成穿帮。这与
storyboard.md 跨镜连贯性自检第 4 条（光位延续）同源——延续是默认，变化要有戏。

## 五、视觉换挡节律（每 15~30 秒一次）

观众的注意力靠**换挡**续命：过 30 秒没有一次明显的视觉刺激变化，再好的画面也会
被划走。写完分镜按时间轴自查一遍换挡分布，lint 的 `shift_gap` 会点名超 30s 的
空窗区间（info 级——它只认结构化位，判断权在你）。

**算换挡的**（前五项引擎看得见，落进对应字段才算数）：

1. 换取景地（`shots[].scenes` 变更）
2. 景别大跨（远景类 ↔ 近景类直切，如全景切特写的"揭示"一拍）
3. 机位角度改变（`angle`：平视 → 俯拍/仰拍/荷兰角）
4. 光线改变（`light_shift` 有内容的镜）
5. 转场镜（字卡/黑场/擦除，本身就是最强的换挡）——**在位才算，绝不为凑换挡去插一个**
   （转场只由用户主动插；换挡不够就用前四项解决）
6. 前后景权力逆转、焦点从人脸移交到道具/新角色（写进提示词，引擎看不见但观众看得见)

**不算换挡的四种假动作**：同一轴线上的对白正反打、什么都没变的硬切、构图挪半寸、
手持晃一晃——这些是剪辑的呼吸，不构成刺激更新。连续对白段落至少安排一次真换挡（插入手部/道具
特写、切一次大角度、或让光线动一下），不要指望正反打自己撑过 30 秒。

## 六、情绪的物理时间常数（`dur` 的决策依据，不是可选项）

情绪在真实身体上**要走完一段物理过程**才成立。把一场哭戏排进 3 秒的镜，模型只能
在有限帧里硬切到结果——观众看到的是"情绪瞬间到顶"，那是 AI 味最刺眼的一种。
**缺省不叹气、不深呼吸、不流泪**：引擎把这三样压进每镜的负面地板，只有本镜正文
（动作/终态/拍点/镜级与句级情绪）明写了才放开，否定写法（没落泪）不算。要它就直接写进
动作，不靠情绪词暗示——下表的「呼吸压住/变急/一滞」「流泪」都是点名写法，只在剧情固定
要求时用。

**先查这张表再定 `dur`**：镜长不够就改镜长，或把这段情绪拆成两镜。

| 情绪 | 最短镜长 | 必经的过程（按这个顺序写进 `video_prompt`） |
|---|---|---|
| 惊吓 | ≥1.2s | 瞳孔骤缩 0.2s → 身体微绷 0.3s → 表情变化 0.7s |
| 欲言又止 | ≥2s | 张口 0.3s → 停顿、喉结动 0.7s → 闭口低头 1s |
| 害羞脸红 | ≥2.5s | 眼神飘开 0.8s → 低头抿唇 0.5s → 耳根颧骨缓慢泛红 1.2s |
| 强忍怒火 | ≥2s | 咬肌先绷 0.4s → 呼吸压住 0.8s → 指节攥白 0.8s |
| 恍然明白 | ≥2s | 动作停住 0.5s → 视线聚焦到那件实物 0.7s → 表情松开 0.8s |
| 流泪 | ≥3s | 眼眶湿润反光 1s → 眼神颤抖、呼吸变急 1s → 一滴落下 1s |
| 崩溃 | ≥3.5s | 强撑 1s → 某处先垮（手/肩/嘴角）1s → 整体塌下去 1.5s |
| 从笑到冷 | ≥2.5s | 笑意在眼角先褪 0.8s → 嘴角撑住 0.7s → 落下、眼神空掉 1s |
| 认出对方 | ≥1.5s | 扫视停住 0.4s → 瞳孔放大 0.3s → 呼吸一滞 0.8s |

三条使用纪律：

1. **这是最短镜长，不是建议镜长**——排得比它短，写多细都演不出来。
2. **动漫 / CG 档不受此限**：一拍二与止め絵本来就用夸张的时间压缩演情绪，
   写实的时间常数搬过去反而钝（画风侧的时间语法见对应 `kn-*` SKILL）。
3. **打斗侧另有一套**：那边是「停—爆—停」的配拍表（蓄势 0.8~1.2s / 爆发
   0.4~0.6s / 亮相 0.8~1.2s），见 `references/action-direction.md`，
   **不要把两张表混用**——文戏的时间常数管的是情绪走完，打斗的配拍管的是招式读清。

## 七、非对称与中断：两条最便宜的去 AI 味写法

模型的默认表演是**对称且走完全程**的：两边脸一起动、动作从起点匀速走到终点。
真实表演恰恰相反，所以这两条写进去就是立刻见效的差异。

- **非对称**：只让半边动，并**显式写另一半不参与**。
  ✅ `右边嘴角先扬起来，左边没跟上；眼部完全不参与，眼神仍是冷的`
- **中断**：写被打断的过程，而不是完成的过程。
  ✅ `摇头启动后在第 10° 突然减速停住，头没有摆回正`
  ✅ `伸出的手在够到之前停了半拍，指尖收回半寸`

## 八、第七轴：物性与本能预动作

前六轴写的是人对情绪的反应；这一轴写的是人**对物**的反应——它几乎从不被写，
而它一出现，画面立刻不像摆拍。规则只有一条：**人碰到东西之前，身体会先做准备。**

| 物性 | 本能预动作 |
|---|---|
| 烫 | 端起来之前先吹一下；手指只捏杯沿不贴杯壁 |
| 大块 / 硬 | 咬之前先分口，或换个角度下嘴 |
| 湿滑 | 换握法，手指先在衣服上蹭一下 |
| 锋利 | 接过时缩肩、避开刃口，视线先落在刃上 |
| 重 | 拿之前重心先沉，抬起瞬间肩线被拽下去一点 |
| 响 | 落下前先眨眼或缩脖子（预期那一声） |
