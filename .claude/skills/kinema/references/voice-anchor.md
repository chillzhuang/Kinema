# 音色锚定 · native 生视频按选角发声

引擎实现详见 `docs/agents/voice-anchor.md`；本篇是创作与排查侧的操作真源。

## 何时生效（全自动，无需额外命令）

`motion: native` 的镜同时满足以下条件时，`gen-video` 自动把说话人的音色样本作为
`reference_audio` 随请求附发，模型用该嗓音念台词、口型同步：

1. 镜有台词（`narration` 或 `lines[]`）；
2. 说话人**已选角**：角色在章节 `voices` 表（或句级 `voice`）绑定了音色，
   旁白绑定了 `narrator_voice` 旁白锁——未选角的说话人在真发前被选角闸点名，
   `gen-video --no-auto-cast` 跳过闸时其嗓音交给模型、不锚定；
3. 该镜走全能参考缺省档（首尾帧衔接镜、V2V、scored 不参与）；
4. provider 有参考音位（seedance 2.0 系列 ≤3 条/合计 15s，2.5 ≤10 条/30s）。

整章关闭：章节顶层 `voice_anchor: false`。逐镜关闭没有开关——弃锚定的镜改写
台词归旁白（`motion` 是章级字段、无镜级覆盖，声源随之是章级制式）。

## 工作流要点

- **先选角再生视频**：角色 `character add --voice-prompt "<声线描述>"`、旁白
  `voice custom --narrator --prompt "<声线描述>" --adopt 1` 定制立档 → 角色进 `voices` 表、
  旁白进 `narrator_voice`；要官方模版音色再 `voice audition` → `voice use`。未选角的说话人
  真发前被闸点名（lint 维度 `voice_anchor_gap` 同源）；`--no-auto-cast` 跳过闸后那些
  说话人任模型每镜自选嗓音。换声：重跑 `voice custom` 换一条定制演绎，或显式换模版。
- **立档即预热**：定制档案直接以档案音作锚定样本（零请求）；模版 `voice use` 当场把
  锚定音合成落盘。此后章节页的「参考音频N」点开即可试听——听准了嗓音再决定要不要开
  按秒计费的生视频。预热失败只告警不阻断选角，真发那一刻会再试一次。
- **dry-run 必看锚定注记**：逐镜行的 `音色锚定=陈昭+画外旁白` 即实发清单；
  `(待预热)` 表示这把声音还没落盘——章节页点开该记号有「♪ 合成一句试听」，
  或重走一次 `voice use`；
  `（未选角:…）` 列出会漂移的说话人；`音色参考位已满=…` 是另一回事——那些人
  选过角，只是本镜参考音条数到了接口上限，再选角也不会附发，得减说话人或换
  条数上限更高的视频档。Studio 分镜卡的「♪ 音色锚定×N」chip 与 dry-run 同源。
- **音色一致性的层级**：锚定是"嗓音跟随样本"（声区/气质级，性别 100% 跟随；
  长锚定样本可到音高级贴合），不是 TTS 级零漂移。**对白上镜的内容一律
  native + 锚定**（烧录轨与模型口型两条时间轴不同源，口型对不上无解）；
  TTS 级零漂移只在全旁白解说章（dubbed）拿得到。

## 提示词纪律（措辞已定稿，引擎自动拼装，人工改写须知）

绑定句三要素缺一不可（措辞真源 `prompts.voice_anchor_clause`）：

1. 按编号点名：「陈昭的说话音色以 @配音1 为准，画外旁白的说话音色以 @配音2 为准」
   ——编号=音频附发顺序，错一位就是换声；一镜只有一把声音时不出编号，
   直接写「以所附参考音频为准」；
2. 「各自用与对应参考音频完全相同的嗓音、音色与音高说出台词」；
3. 「**参考音频只提供音色，不要复述参考音频里的内容**」——缺这半句模型可能把
   样本当对口型素材，复述试音句而不念台词。

定制音色另带一段括注（`（62 岁男性，嗓音低沉略带沙哑，语速偏慢）`），取自造这把声音
时写的那段声线描述。厂商把「音色参考不准」列为已知问题、第一条解法就是在提示词里
补音色特征描述——只发参考音等于让模型按画面猜这把嗓子多大年纪。**模版音色没有描述
可发**（官方别名是标签不是描述），这一条是定制路独有的。

多段镜自动带台词时间轴（`台词时间轴：0-3秒：陈昭说：“…”；3-6秒：…`，字数比例
估秒），旁白句自动附闭唇指令。台词写进中文双引号内（官方对白优化通道）。

## 排错速查

| 症状 | 处置 |
|---|---|
| 建任务 400 | 参考音合计超时长限额——引擎已自动裁剪，若手工换过样本先查单条 ≥2s、合计 ≤限额 |
| 念的是试音句不是台词 | 绑定句被人工改掉了第 3 要素——恢复默认拼装 |
| 某角色嗓音仍漂 | 未选角（查 lint `voice_anchor_gap`）或预热失败（控制台已点名） |
| 页面标锚定、成片没生效 | 该镜是否被 frame_chain/V2V 拉出了全能参考档（dry-run 注记为准） |

实测基线与 F0 判定口径（pyin，60~350Hz 取中位）见 `docs/agents/voice-anchor.md`
《实测基线》——性别对照、双音频分绑与锚定样本时长对照三组小样的结论都在那里。
