# 动作戏导演方法论（打斗 · 追逐 · 对峙爆发——写分镜前与 performance.md 配套读）

打斗是剧情片里最贵也最容易废掉的镜：**画面在动不等于戏在动**。本文把「导演层怎么想、
武指层怎么排、镜头层怎么拆」收成一份可执行工法——骨架取自香港动作片的工业方法论：
武术指导制度（动作导演与导演平级分工，1983 年起金像奖单设最佳动作设计）与
Bordwell《Planet Hong Kong》对港式动作的技术分析（**停—爆—停节奏**、**表现性放大**、
**构成式剪辑**三大结论）；落点全部映射到本工程的 beats 时间轴、双语提示词与
首尾帧/全能参考链路——不是影评，是能直接写进 `shots[]` 的操作规程。

**硬底线先立**：打斗镜的 `image_prompt`/`video_prompt`/beats **一两句话交差是硬违规**
（`prompt_thin` 警戒线之上，本文每一层都有「必须写出的物理内容」清单——写不出说明
这一层还没想，回去想，不是硬凑字数）。

## 〇、三层分工（像剧组一样想问题，逐层落笔）

| 层 | 剧组里是谁 | 想什么 | 落进哪 |
|---|---|---|---|
| **导演层** | 导演 | 这场打斗讲什么故事：力量关系曲线、赢法 | 分镜结构（拆几镜、各镜各讲什么） |
| **武指层** | 武术指导（动作导演） | 因人设招、排招、环境入招 | 每镜 `action`/beats 的招式内容 |
| **镜头层** | 摄影＋剪辑 | 拆镜、机位、节奏、打击感 | `camera`/`angle`/beats 的 `t`/升格措辞 |

三层是**顺序**不是并列：招式服务于故事、镜头服务于招式。跳过导演层直接排招，
出来的就是「打得很热闹但不知道为什么打」的废戏。

## 一、导演层：打斗即叙事（先想赢法，再想招）

- **每场打斗必须有力量关系曲线**：开局强弱设定 → **逆转点**（受挫后亮底牌/觉醒/
  借环境/换武器）→ 终结。曲线写不出来的交锋不配单独成场——并进别的戏或剪掉
  （`omt` 纪律同源：不推进关系、情绪或信息的交锋是节奏税）。
- **逆转点必须可见**：用身体和画面讲，不用台词喊——受压方从被动格挡转为第一次
  主动进攻的那一拍、兵器脱手后徒手夺械的那一拍。机位随之成对调换
  （performance.md「权力翻转」那张表在打斗里同样成立：仰拍/俯拍互换、前景遮挡换边）。
- **赢法即人物**：狡黠的角色借环境赢、刚猛的角色硬碰硬赢、隐忍的角色后发制人赢。
  终结方式与人物性格对不上，这场打斗就白打了——观众记住的永远是「他是怎么赢的」。
- **战局读数**：多镜打斗每 2~3 镜给一次全景「读数镜」（双方位置、伤势、环境变化
  一眼可读）——构成式剪辑的局部特写只有在观众心里有地图时才成立，全程特写等于
  让观众在黑箱里看烟花。

## 二、武指层：因人设招（袁和平法）＋ 环境即兵器（洪家班法）

- **动作签名从角色档案推导**（袁和平的核心方法：因人设招、把每个人的特长放大到
  极致）：写打斗前先给每个参战角色一行「动作签名」——体型/武器/身份/性格 →
  一套只属于他的发力方式与习惯动作。签名一旦定下，全片每场打斗复用并演化，
  跨集一致性靠它（对应 `characters[].required_actions` 登记）。
- **武器决定空间语法**（招式弧线定景别，不是反过来）：

  | 武器 | 交战距离 | 景别倾向 | 招式弧线 |
  |---|---|---|---|
  | 短刃/匕首 | 贴身 | 近景/特写为主 | 短促直线、缠斗绞杀 |
  | 长柄（戟/枪/棍） | 一杆之外 | 全景/中景为主 | 大开大合的弧线，扫压占空间 |
  | 拳脚 | 半步 | 中近景 | 发力链完整可见（转腰送肩到拳锋） |
  | 枪械 | 掩体间 | 中景+走位 | 停—爆—停最极端化（对峙静场→爆发） |

- **环境清单先行**（洪金宝/成龙工法：桌凳衣架皆兵器）：写打斗分镜前，把该场景
  `scenes[]` 里可入招之物列出来（栏杆/桌面/吊缆/蒸汽管/货架），**至少一件真的
  入招**——蹬墙翻越、扯缆横扫、踹桌阻敌。环境不入招的打斗放在哪个场景都一样，
  等于浪费了场景设定图。
- **群战焦点纪律**：同一时刻只有一组焦点交锋，其余人用走位、包抄、倒地、起身
  填画面（真实群战的节奏本就如此）；焦点每 1~2 镜移交一次。让所有人同时挥拳的
  提示词，模型只会生成一团粘连的肢体。

## 三、镜头层节奏：停—爆—停（Bordwell 节奏论 → beats 直译）

港式动作的签名节奏：**快招串 → 招被格住/命中瞬间的短暂静止（亮相，源自京剧
liang xiang）→ 再爆发**。它与好莱坞式连续乱剪的分界就在「亮相拍」——静止的
一瞬让观众读清刚才发生了什么、双方现在是什么局面，下一次爆发才有意义。

**文戏也吃这套节奏，但配拍表不通用**：情绪戏的"停—爆—停"是
`铺垫 → 转折的那一下 → 消化`，时长按情绪的物理过程走而不是按招式读清走
——那张表在 `references/performance.md`「情绪的物理时间常数」一节，
**不要把下面这张打斗配拍表搬去排文戏**（0.4~0.6s 的爆发拍排一场哭戏必然演不出来）。

映射到 beats（手写 `t`，**绝不均分**）：

```
蓄势拍 0.8~1.2s（对峙/绕步/换握兵器——静中有威胁）
爆发拍 0.4~0.6s × 2~3（一拍一个可辨识的招：突刺/格挡/回斩）
亮相拍 0.8~1.2s（招被架住的对峙定格 / 受击者飞退撞落——爆发的结算）
（循环，末拍收在 end_state）
```

- **每个打斗镜至少一个完整「蓄—爆—亮」循环**；7~10s 的镜装得下两个循环。
- 全爆发无停顿的时间轴，模型会自行丢拍只演主事件（`beats_density` 会告警）
  ——停顿拍不是浪费秒数，是爆发拍能被看清的前提。
- **升格纪律**：只给**决定性一击**（逆转点或终结拍），写法是把「慢动作」写进该拍
  `action`（如「回身重腿命中瞬间转为慢动作，受击者腾空后飞」——洪金宝式重击慢放
  ＋受击强调）；**一镜至多一次**，处处升格等于没有升格。
- **表现性放大的合法手段**（放大情绪冲击，不是加特效堆料）：变速（升格那一下）、
  受击位移（人被打得动起来）、环境反馈（碎屑/水花/火花/尘土应声而起）、
  `sound` 位的打击音效——四选二起步，全空的爆发拍是纸糊的。

## 四、镜头层拆分：构成式剪辑（关键交锋拆 2~3 镜）

港式打斗由**局部视图拼装**而非一镜看全（constructive editing）。一次关键交锋的
标准拆法：

1. **出招镜**（攻方视角，看清招从哪来）→
2. **命中/格挡特写**（兵器相击、拳入腹的那一帧）→
3. **受击反应镜**（受方全身＋空间位移：飞退、跪滑、撞穿货架）。

- **受击反应是打击感的一半**：只拍出招不拍落点＝没打。反应镜三要素沿用
  performance.md（身体轴反应＋景别收一档＋短时长），打斗特化再加一条——
  **必须有空间后果**（位移距离、撞击物、扬起的环境反馈）。
- **借位思维 → 机位措辞**：实拍靠机位角度让未触之拳看似命中，提示词里同理选
  强纵深机位——「拳锋直朝镜头」「越肩看刃光逼近」「低机位扫堂腿掠过镜头」。
  平行侧拍是打斗最弱的机位，只配给读数镜。
- **hit on the cut（切点选动作顶点）**：镜与镜的分界落在招的顶点——缺省档（全能
  参考·一镜一片）把下一镜 `image_prompt` 写成上一镜招式的**结算瞬间**，硬切点就是
  剪辑点；要两镜真正无缝相连时给上游镜写 `shots[].frame_chain: true`（结对首尾帧，
  前镜末帧 pin 到下一镜首帧图，链就是剪辑点）。
- **打斗重点镜优先出简笔板**：多主体、精确卡点正是板的用武之地（0.3 元/板）；
  dubbed 与 native 缺省档板在盘即附发直达模型；只有衔接章里板让位首帧任务，
  须逐镜 `sketch ref --shots N --state on` 切回参考孤岛（开一镜断一条接缝）。

## 五、提示词落地（把上面四层写成字——两条硬底线）

- **`image_prompt`（打斗帧）——瞬间选择优先**：选「将触未触」「力量顶点」
  「受击变形」的那一帧（与动作设定表「过程中间态」同一纪律——拔到一半的刀比
  拔完的刀有戏）。五要素齐备（对齐主 SKILL 五项清单，缺二即回炉）：
  ① 机位与纵深（谁的视角、什么角度切进来）② 双方身体力学（重心/扭转/发力链/
  肌肉与衣料的应力）③ 武器与光效轨迹（刃光拖尾、电弧、能量残影的走向）
  ④ 环境反馈（碎屑悬空、水花溅起、尘土应声）⑤ 表情与情绪（发力的狰狞、
  受击的错愕、亮相的凝定）。
- **`video_prompt`/beats（深度档必用）**：时间轴逐拍「谁＋什么招＋镜头怎么动」
  （停—爆—停配拍），全局层写跨拍的力学/物理反馈/次级动画/材质光响应/情绪质感
  ——分工详见 kinema-sketchboard「beats 快则」，厚度底线同一条。
- **空词兑现表**（写了左列的意图，正文必须落出右列的物理内容——与 kn-* 抽象词
  兑现表同范式）：

  | 空词（禁止单独出现） | 必须兑现成 |
  |---|---|
  | 激烈打斗/精彩交手 | 具体招式序列＋停爆停配拍＋至少一次受击位移 |
  | 势均力敌 | 攻防互换的具体回合（谁的哪招被谁怎么破） |
  | 一招制敌 | 那一招的完整发力链＋受击后果＋亮相 |
  | 打斗到高潮 | 逆转点的可见事件（夺械/借环境/亮底牌） |

- 中英同改：`image_prompt_en`/`video_prompt_en` 按同一口径对位（招式术语查
  storyboard.md 中英对照，运镜措辞取《进阶运镜预设库》原文）。

## 六、风格档速查（借哪家的思维——按项目画风与叙事基调选）

| 需求 | 借谁 | 提示词取向 |
|---|---|---|
| 拳拳到肉写实 | 刘家良（硬桥硬马）/ 袁和平实打线（《精武英雄》） | 招式连贯成套、发力链完整、少慢镜、地面走位清晰 |
| 飘逸写意武侠 | 程小东（《笑傲江湖》威亚美学） | 长弧线腾跃、衣袂与环境呼应、允许违反物理的悬停亮相 |
| 谐趣环境流 | 洪金宝/成龙班底 | 环境道具连锁反应、狼狈感与惊险并存、节奏带喜剧呼吸 |
| 枪火对峙 | 吴宇森（停—爆—停极端化） | 长静场对峙＋瞬间爆发、慢镜只给宿命一击、双雄构图 |

选定一档写进该场打斗的每一镜——**一场戏只借一家**，混搭（前半程小东后半刘家良）
出来的是风格噪音不是丰富。

## 七、重做意见词典（review retake 的 `--note` 建议写法）

| 症状 | `--note` 建议写法 |
|---|---|
| 打击感虚 | `重击拍补受击位移与环境反馈（飞退撞击+碎屑），升格只留终结一击` |
| 节奏糊成一团 | `按停爆停重配拍：蓄势0.8s+爆发0.5s×2+亮相1s，删掉多余爆发拍` |
| 看不清谁在打谁 | `插入全景读数镜（双方位置与伤势一眼可读），焦点交锋一次只留一组` |
| 招式与人不符 | `按角色动作签名重排：<角色>用<武器/风格>，删除通用挥拳` |
| 环境是背景板 | `至少一件场景陈设入招（蹬墙/扯缆/踹桌），环境反馈随招而起` |
| 机位平淡 | `换强纵深机位：拳锋朝镜头/越肩刃光/低机位掠过，平行侧拍只留读数镜` |
