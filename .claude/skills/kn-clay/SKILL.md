# kn-clay · 定格动画（四大质感总入口）

**让"东西"演戏。** 定格动画的魔力是**材质的诚实**——观众知道那是粘土/塑料/积木，
却愿意相信它活着。这是唯一"卡顿即风格"的形态：一顿一顿的运动不是缺陷，是灵魂。
本 skill 的职责：**选对材质传统，把该材质的物理规则演到骨子里**。

## 直接启动整套流程（`/kn-clay <故事/主题>` 即可）

被调用后**按此联动执行，不需要用户再调用任何其他 skill**：
1. **Read [`../kinema/SKILL.md`](../kinema/SKILL.md)**（完整节点工作流与铁律）。
2. **选定质感**（见下《质感选择协议》）→ 建项目显式 `--profile <质感>` 并全流程绑定
   同一 profile：设定图/分镜图/封面每次生图都经该 profile 的 `style_prefix` 注入画风
   前缀，这是全片风格统一的机制保障；逐镜混风格仍走 `shots[].profile` 例外。
3. 默认横屏 16:9（竖版投放用 `--aspect 9:16`）；动态化推荐 `c`(dubbed)——**video_prompt 必写"定格动画式一顿一顿的运动"**，
   低帧感是全体变体共享的风格签名。

## 质感选择协议

用户点名（"高达那种"/"粘土人"/"乐高感"）→ 直接选档；没点名 → **推荐缺省质感
`clay`（粘土定格，泛用第一档），并在立项前一句话二次确认**（立项唯一阻塞点：确认后由
引擎快照进 `project.style_prompt`，全片生图统一取用）；确认后开工，用户仍可
`project set --style-prompt` 换质感重做：

| Profile | 质感 | 一句话 DNA | 最适题材 | 配乐 |
|---|---|---|---|---|
| `clay` | 粘土定格 | 指纹捏痕+圆润手作 | 萌系治愈/寓言/热梗翻拍 | upbeat |
| `gunpla` | 高达模型定格 | 刻线渗线+战损涂装 | 机甲战斗/热血/男频怀旧 | cinematic |
| `figure` | 手办定格 | PVC光泽+球关节大头 | 二次元日常梗/宅文化小剧场 | upbeat |
| `brick` | 积木颗粒定格 | 圆凸点+纯色块拼装 | 物理喜剧/亲子/创意脑洞 | upbeat |

## 四大质感视觉 DNA（写提示词前逐条内化）

### clay · 粘土定格（阿德曼的手作温度）

- **材质即灵魂**：哑光黏土 + **可见的指纹与捏痕** + 轻微不对称——完美光滑=塑料玩具，
  瑕疵才是"手作"。提示词显式写"表面有细微指纹痕迹"。
- **造型语法**：一切圆润化——圆头圆手，眼睛是嵌进去的黑珠，嘴是刻出来的缝；2 头身墩实。
- **微缩影棚光**：柔光箱主光+暖补光；背景是手作布景（皱纹纸天空/棉花云/瓦楞纸房子）。
- **形变表演**：粘土的夸张是**形变**——惊讶时眼珠弹出、身体压扁拉长（材质允许的超现实）。
- ✅ `微距近景，圆滚滚的粘土小猫歪着头，表面有细微指纹痕迹，两粒黑珠眼睛，
  柔光箱布光，背景是皱纹纸橙色天空和棉花云，浅景深`
- `negative_prompt` 常备：`光滑塑料质感, 3D渲染, 真实毛发, 锐利边缘`

### gunpla · 高达模型定格（塑料的史诗）

模型宅的浪漫：桌面上的一年战争——
- **塑料的诚实**：注塑塑料质感、**分件色块的接缝**、刻线与渗线（panel lining）、
  水贴细节；高级感来自"看得出是模型，但做工顶级"。
- **战损美学**：掉漆做旧（边角银色露底）、烟熏渍、弹痕——崭新出厂色是玩具，
  战损才是"上过战场的机体"。
- **可动的极限**：机械关节的姿势有**模型可动范围**——起跳/跪射/持枪对峙是招牌 pose；
  动作不写人类柔性动作（模型摆不出）。
- **战场戏台**：微缩废墟布景、硝烟用棉絮、爆炸用橘色棉花+背光——**特效道具化**
  是定格的语法（不写真实爆炸火焰）。
- **摄影**：影棚微距+低机位仰拍（机体显高大）、`film_grain` 增加胶片战争片质感。
- ✅ `低角度仰拍微距，战损涂装的机甲模型单膝跪地举盾，肩甲刻线与渗线清晰，
  边角掉漆露出银色底漆，身后废墟布景中棉絮硝烟被背光染成橘色，影棚浅景深`
- `negative_prompt` 常备：`真实金属质感, 真实火焰烟雾, 人体柔性姿势, CG渲染感`

### figure · 手办定格（桌面上的二次元）

- **PVC 的光泽**：手办特有的半光泽塑胶质感、精致渐变涂装、**可见的球形关节**
  （粘土人/figma 的关节是身份标识，不要藏）。
- **大头比例**：粘土人 2 头身大头 Q 版为主（表情靠换脸件的固定表情：微笑/惊讶/泪眼）；
  写实比例手办用于"耍帅镜"。
- **桌面剧场**：场景就是桌面——键盘当地板、马克杯当建筑、便签纸当告示牌；
  **真实桌面物件与手办的尺度混搭**是本变体的戏眼。
- **宅文化语法**：亚克力立牌、痛包、抽卡、吃谷……题材自带圈层梗。
- **摄影**：环形灯影棚光、微距浅景深、略俯视（人看桌面的自然视角）。
- ✅ `微距略俯视，粘土人比例的大头手办坐在机械键盘上，手里抱着一颗巨大的草莓，
  球形关节可见，PVC 光泽涂装，背景虚化的显示器蓝光，环形灯打光`
- `negative_prompt` 常备：`真人皮肤质感, 布料真实褶皱, 藏起关节, 2D插画`

### brick · 积木颗粒定格（拼装世界的物理喜剧）

- **颗粒的纪律**：一切由积木件构成——**连火焰、水花、烟雾都是积木件**
  （橙色透明件火焰/蓝色圆板水花），这是本变体最重要的世界观纪律。
- **小人语法**：圆柱头、印刷表情、C 形卡扣手、直腿——动作僵硬感是喜剧资产。
- **色彩**：高饱和纯色块、无渐变；场景像官方套装盒照一样整洁。
- **招牌演出**：**拼装与散架**——建筑逐颗粒组装成形、角色被撞散成一地零件再重组；
  video_prompt 写"积木件逐块飞入拼合成塔"。
- **摄影**：影棚均匀布光（积木不吃阴影戏）、微距景深、正面或 45° 标准玩具机位。
- ✅ `微距45°，积木小人消防员站在积木消防车顶，用透明蓝色积木件组成的水柱喷向
  由橙色透明件拼成的火焰，全场景积木颗粒质感，高饱和纯色块，影棚均匀布光`
- `negative_prompt` 常备：`真实材质, 圆润有机形状, 渐变色, 真实火焰水花`

## 共通分镜法则（定格演出文法，四变体通用）

6~10 镜，2~4s/镜：
- **开场镜=材质特写**：让观众第一眼确认"这是粘土/模型/手办/积木"——材质即题材。
- **预备—动作—定住**（wind-up, action, hold）：定格喜剧的笑点在"定住"那一拍；
  每个动作镜都留半拍静止。
- **运动写法**：video_prompt 统一带"定格动画式一顿一顿的运动"；转头先眼珠后头、
  走路一格一格挪——**流畅=穿帮**。定格的 **on ones / on twos**（一拍一 = 每帧一摆，
  一拍二 = 每两帧一摆，越慢越有手作味）与 2D 手绘的一拍二同源，顿挫节拍、
  关键姿势停顿、"别写 smooth motion / motion blur" 这套写法直接照
  `kn-anime/SKILL.md` 的《2D 作画运动语法》一节（**别在此重复维护第二份**）；
  差别只在：定格是**实拍摆件**，故照常写物理光影与景深，不套 2D 的平涂二值光。
- 特效道具化：烟=棉絮、火=橘色透明件/棉花、速度=拉线残影——绝不写真实物理特效。
- 双语提示词按 [`../kinema/references/storyboard.md`](../kinema/references/storyboard.md)：英文术语用 stop motion / claymation /
  plamo model kit / PVC figure / brick-built。

## 声音设计

- 拟音是定格的灵魂：`sfx` 字段写足（"咔嗒"关节声/"啵"的吸附声/积木碰撞声），
  native 模式交给模型原生生成。
- 旁白描述用词：clay→「温柔文雅」，gunpla→「磁性男嗓/热血少年」（战报腔），
  figure→「元气甜妹/中二青年」，brick→「活泼女孩」——写进 `voice custom --narrator --prompt … --adopt 1`
  定制立档；角色按人设 `character add --voice-prompt`；要官方模版音色再 `voice audition` → `voice use`。

## 共通重做意见词典（review retake 用）

| 症状 | `--note` 建议写法 |
|---|---|
| 材质失真（像CG） | `强化<该变体材质词>：指纹捏痕/刻线渗线/PVC光泽/积木圆凸点，去掉CG渲染感` |
| 运动太流畅 | `改为定格动画式一顿一顿的运动，动作间保留静止帧` |
| 特效写实穿帮 | `特效道具化：烟改棉絮质感，火改橙色半透明件，去掉真实火焰` |
| 布景出戏 | `布景手作化/桌面化：<该变体布景语法>` |
| 关节/比例错 | gunpla`姿势限制在模型可动范围` / figure`露出球形关节` / brick`保持卡扣直腿` |

## 何时不用

水彩绘本安睡向 → `kn-storybook`；3D 卡通电影感 → `kn-anime`（pixar/disney3d 变体）；
真实微缩景观 → `kn-miniature`（那是移轴实景，不是玩具定格）。
