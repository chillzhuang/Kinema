# 引擎内置资产（`kinema/assets/`）

这里放的是**引擎运行时要读的文件**，随 Python 包分发（`pip install` 后必须在位）。

## 为什么不放进 `.claude/skills/<skill>/`

一句话：**这些图是引擎在生成时自动垫上去的，不是给人读的文档。**

| | `engine/kinema/assets/` | `.claude/skills/<skill>/` |
|---|---|---|
| 谁消费 | **引擎代码**（`sheets.templates_for` / `sketchboard.TEMPLATE_PATHS`） | Claude（指挥层读的文档） |
| 何时消费 | 每次生成请求，转 base64 塞进 `ref_images` | 会话开始时 Read |
| 随什么分发 | Python 包（`pip install kinema`） | 仓库工作区 |

样板图若搬进 skill 目录，`pip install` 的用户那里 `.claude/` 根本不存在，垫图会
**静默失效**（提示词照发、样板没附上——正是本工程反复强调的"声明了一个不存在的
参考"事故形态）。所以位置不动，但**出处与再生路径必须写清楚**，就是这份文件。

设计归属仍在 skill：版式契约由 `sheets.py` / `sketchboard.py` 定义，skill 文档
负责讲清怎么用；样板图只是那份契约的**可视化固化**。

## 清单

### `blueprints/` —— 版式蓝图（全部样板图的唯一居所）

设定图与简笔分镜板的**版面骨架真源**。生成时引擎自动把对应类别的蓝图垫在
参考图最前——三区怎么分、三视怎么站、细节框放哪，纯文字契约每次生成都是重赌
一次，垫图把方差钉死。

**第一铁律：只准参考布局。** 蓝图可供参考的只有**版面分区、各区的位置与比例
关系**；画风、笔触、配色、媒介质感、人物与物件都属于"内容"，一律不得进入产出。
这条不靠自觉——每次请求由 `sheets.template_role` / `sketchboard.board_prompt` 的
职责声明强制执行。

**每类一张素描线稿样板**：铅笔素描画在纯白纸面上，与简笔板样板同一素描语言。
主体去身份（角色是无五官的关节素体人台、道具是中性示意物），几乎没有内容可抄，
单张即可教版式。**媒介条款在素描样板下尤其要硬**：素描是强烈的 2D 手绘信号，
职责声明必须显式否掉「把成品画成线稿」这一维（真源 `sheets.template_role`）。

| 文件 | 内容（仅示范版式，绝不复制进产出） | 契约来源 | 比例 |
|---|---|---|---|
| `char_template.png` | 素描关节素体人台·三区两视（左 40% 锁骨以上正面头像特写｜中 30% 正面全身｜右 30% 背面全身，两全身像同地平线等高等比） | `sheets.char_rules` + `char_tail` | 16:9 |
| `prop_template.png` | 素描直剑三视·结构三视式（上 2/3 正/侧/背三视等高等大并列＋下 1/3 护手/缠柄/剑尖三个细节框；无色板槽位） | `sheets.PROP_LAYOUTS` | 1:1 |
| `sketch1_template.png` | 去身份素描人台·双人动作板（对峙/逼近/交错/收势，2×2 四拍） | `sketchboard.board_prompt` | 16:9 |
| `sketch2_template.png` | 去身份素描人台·单人走位板（水乡场景，近/中/全/远景别递进四拍） | 同上 | 16:9 |
| `sketch3_template.png` | 纯场景动效板（水乡空镜四拍，无人物） | 同上 | 16:9 |

改动 `char_rules` / `prop_rules` 的**分区结构**时必须同批重做对应蓝图——
画布比例守卫（`test_sheets`）校不出「契约写三区、蓝图画四栏」这种结构漂移，
结构对齐只靠本条纪律。

**角色设定图注意**：角色表不设细节格与色板槽位（武器与随身物件归独立的道具/武器
设定图；官方人物参考口径是「大头照 + 全身照即可，不建议人物多视图」，故不设侧视）。
写实档（`image.identity_sheet: true`）的角色设定图走**纯文生图**、连蓝图都不垫
（图生图产物不在视频侧受信范围内），版式全靠 `char_rules` 文字契约；非写实档
照常垫蓝图。两档产出**同一版式**。

简笔板三张为**铅笔素描+五色标注**，主体是无身份素描人台或空镜，覆盖双人动作/
单人走位与景别递进/场景动效三类调度题材；板底五色图例横条属版式的一部分，
产出照样板的位置与字号绘制——字号锚定拍号档，那是实测能画对的下限
（`sketchboard._LEGEND_ZH`）。

**设定图两侧都是纯图片**：蓝图上没有一个字，产出同样不生成标题、简介、信息栏、
编号、尺寸数字、色号、logo、水印或签名。名称、条目与色值全在 `project.json` 里，
画一遍只会引入一处永远对不上的信息；角色与道具都不设色板槽位（配色信息由主体
本身呈现，真源 `sheets.char_tail` / `prop_rules` 的负面禁令）。简笔板是例外——
它的五色图例与板头拍号本就是版式的一部分，走自己的 `sketchboard.board_prompt`。

**刻意没有场景蓝图**：场景设定图是单幅环境 key art（广角建立镜头），没有分区
结构可教，垫一张具体空间只会把它的陈设与光线污染进每一张场景图。

三条设计约束（缺一条就从"教版式"变成"教内容"，真源 `sheets.py` 同名注释）：

1. **蓝图是去身份线稿，不是标杆作品**——角色是无五官无毛发无服装的人台轮廓，
   道具是中性几何示意物轮廓。它教的是槽位骨架：分区在哪、占多大、彼此怎么对齐。
2. 生成时必须同时注入 `sheets.template_role(kind)` 职责声明——线稿消除了身份与
   材质继承面，画风/**媒介**维度的越界参考仍要靠它压（前缀无媒介词时，
   角色设定图会被样板带离项目媒介，同项目两种媒介并存）。
3. 蓝图自身**不带画风前缀**——画风由每次生成的 `style_prefix` 决定。

## 怎么重做样板图

**契约改了就该重做**——蓝图与契约同源是这套机制的立身之本（蓝图停留在旧版式，
等于每次生成都在教模型一个过时的骨架）。

现用两张由 seedream **纯文生图**直出（`watermark false`）。提示词的骨架三段式：
① 定性——「铅笔素描风格的版面骨架示意图，均匀石墨线条与细腻排线灰阶画在纯白
纸面上，无颜色、无背景环境」；② 按 `sheets.char_rules` / `prop_rules` 的分区结构
逐区描述（区宽比例、留白口径、对齐关系），主体写成「绘图用木质球关节素体人台，
面部完全空白，不可辨识性别年龄与身份」或「经典形制直剑：中脊线与浅血槽、微弧
十字护手、缠绳柄身、圆形配重头」；③ 收尾——「正交平视视角，无透视畸变、无投影、
无景深；全图不出现任何文字、编号、标注、尺寸线、箭头、色板、网格或水印」。
完整可复用的提示词版本在仓库工作区 `.claude/docs/video-final/REQUIREMENTS.md` §4.6。

出图后**必须逐张 Read 核对**（引擎无 OCR、无版式检测）——按该文件在上表里认领的
版式逐槽位点数，别只看"像那么回事"。注意 seedream 可能返回 JPEG 字节：落位前用
`ffmpeg -i in -pix_fmt rgb24 out.png` 转成真 PNG（画布比例守卫读 IHDR）。

| 蓝图 | 核对清单 |
|---|---|
| `char_template` | 三区宽度比目视 4:3:3 · 左区头像面部完全空白 · 中右两全身像底部对齐等高（中正面、右背面） · 主体是不可辨识身份的素体人台 · 无竖线无栏框 · 无文字无箭头 · 无色板无细节格 · 画布 16:9 |
| `prop_template` | 上 2/3 三视等高等大横向并列（每把竖直摆正）且底部对齐 · 下 1/3 三个细节框对齐同宽、框内为护手/缠柄/剑尖局部放大 · 无色板无颜色条带 · 无横向分隔线 · 无文字无箭头 · 画布 1:1 |

不达标就重滚，**别把不合格的蓝图留在包里**——它会把错误版式教给此后每一张
设定图。道具样板实测滚了四版才达标，失败形态已全部反哺进 `sheets.prop_rules`：
写实照片风 → 主体斜置出画被裁 → 版式混搭 → 色板带图案纹理。
成本：每张一张图价（Seedream 0.3 元）。

简笔板蓝图同理：用 `sketchboard.board_prompt` 契约生成或手工定稿，核对"网格分格
干净、五色标注与板头图例齐全、素描灰阶为绝对主体、色彩点缀只落在发光体上"。
